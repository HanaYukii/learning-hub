### [Q4. Minimum Cost Path With At Most K Turns](https://leetcode.com/problems/minimum-cost-path-with-at-most-k-turns/)
`dp` `狀態擴充` `分層圖` `LC~est2000`

::: info 題意
$m\times n$ 格子($\le75$),進入每格付 `grid` 值(起點也付;重複進入重複付),四方向移動,從 $(0,0)$ 到 $(m-1,n-1)$,**轉彎次數 $\le k$**($k<\min(m,n)$);轉彎 = 連續兩步方向不同。**求**最小花費,到不了回 $-1$。

例:`grid=[[2,7,3],[1,4,5]]`、$k=1$:下、右、右 → $2+1+4+5=12$,轉一次。$k=0$ 時 `[[1,9],[3,4]]` 到不了對角 → $-1$。
:::

::: tip 作法
狀態 (格子, 最後一步方向, 已轉彎數)。跟 [7 月 WC512 Q4](/cp/leetcode/2026-07#weekly-512-·-2026-07-26) 那題「DP 做不了、只能 Dijkstra」相反,這題**有天然的拓撲序**:每個轉移不是「同方向直走」(座標沿該方向嚴格前進)就是「換方向」(轉彎數 $+1$)。所以按轉彎數分層、層內每個方向照該方向掃格子:

$$\text{dp}[t][d][i][j]=\text{grid}[i][j]+\min\bigl(\text{dp}[t][d][\text{前一格}],\ \min_{d'\ne d}\text{dp}[t-1][d'][\text{前一格}]\bigr)$$

$O(k\cdot4\cdot mn)\approx1.7\times10^6$。用「至多 $t$ 次」定義,起點四個方向都給 `grid[0][0]`,答案取 $\min_d\text{dp}[k][d][\text{終點}]$。走回頭路(180°)也是轉彎、會掉到下一層,所以同一層同方向的掃描永遠無環。Dijkstra 也過(狀態才 $1.7\times10^6$、邊權非負),只是這裡連 log 都省了。

```cpp
// cur[d][i][j]:至多 t 次轉彎、最後一步朝 d 進入 (i, j) 的最小花費;prevL 是 t-1 層
for (int t = 0; t <= k; t++) {
    cur.assign(4, vector<vector<long long>>(m, vector<long long>(n, INF)));
    for (int d = 0; d < 4; d++)
        for (int a = 0; a < m; a++)
            for (int b = 0; b < n; b++) {
                int i = di[d] < 0 ? m - 1 - a : a, j = dj[d] < 0 ? n - 1 - b : b;  // 沿方向 d 掃:前一格已算好
                if (i == 0 && j == 0) {  // 起點:四個方向都可用
                    cur[d][0][0] = grid[0][0];
                    continue;
                }
                int pi = i - di[d], pj = j - dj[d];
                if (pi < 0 || pi >= m || pj < 0 || pj >= n) continue;
                long long best = cur[d][pi][pj];  // 直走不轉
                if (t > 0)
                    for (int e = 0; e < 4; e++)
                        if (e != d) best = min(best, prevL[e][pi][pj]);  // 在前一格轉彎
                if (best < INF) cur[d][i][j] = best + grid[i][j];
            }
    prevL = cur;
}
// ans = min_d cur[d][m-1][n-1];m = n = 1 時直接 grid[0][0]
```
:::
