### [Q4. Minimum Cost Path With At Most K Turns](https://leetcode.com/problems/minimum-cost-path-with-at-most-k-turns/)
`dp` `狀態擴充` `分層圖` `LC~2045`

::: info 題意
$m\times n$ 格子($\le75$),進入每格付 `grid` 值(起點也付;重複進入重複付),四方向移動,從 $(0,0)$ 到 $(m-1,n-1)$,**轉彎次數 $\le k$**($k<\min(m,n)$);轉彎 = 連續兩步方向不同。**求**最小花費,到不了回 $-1$。

例:`grid=[[2,7,3],[1,4,5]]`、$k=1$:下、右、右 → $2+1+4+5=12$,轉一次。$k=0$ 時 `[[1,9],[3,4]]` 到不了對角 → $-1$。
:::

::: tip 作法
狀態 (格子, 最後一步方向, 已轉彎數)。跟 [7 月 WC512 Q4](/cp/leetcode/2026-07#weekly-512-·-2026-07-26) 那題「DP 做不了、只能 Dijkstra」相反,這題**有天然的拓撲序**:每個轉移不是「同方向直走」(座標沿該方向嚴格前進)就是「換方向」(轉彎數 $+1$)。所以按轉彎數分層、層內每個方向照該方向掃格子:

$$\text{dp}[t][d][i][j]=\text{grid}[i][j]+\min\bigl(\text{dp}[t][d][\text{前一格}],\ \min_{d'\ne d}\text{dp}[t-1][d'][\text{前一格}]\bigr)$$

$O(k\cdot4\cdot mn)\approx1.7\times10^6$。用「至多 $t$ 次」定義,起點四個方向都給 `grid[0][0]`,答案取 $\min_d\text{dp}[k][d][\text{終點}]$。走回頭路(180°)也是轉彎、會掉到下一層,所以同一層同方向的掃描永遠無環。Dijkstra 也過(狀態才 $1.7\times10^6$、邊權非負),只是這裡連 log 都省了。

```cpp
// cur[d][i][j]:至多 t 次轉彎、最後一步朝 d 進入 (i, j) 的最小花費;prevL 是 t-1 層
for (int t = 0; t <= k; t++) {
    cur.assign(4, vector<vector<long long>>(m, vector<long long>(n, INF)));
    for (int d = 0; d < 4; d++)
        for (int a = 0; a < m; a++)
            for (int b = 0; b < n; b++) {
                int i = di[d] < 0 ? m - 1 - a : a, j = dj[d] < 0 ? n - 1 - b : b;  // 沿方向 d 掃:前一格已算好
                if (i == 0 && j == 0) {                                            // 起點:四個方向都可用
                    cur[d][0][0] = grid[0][0];
                    continue;
                }
                int pi = i - di[d], pj = j - dj[d];
                if (pi < 0 || pi >= m || pj < 0 || pj >= n) continue;
                long long best = cur[d][pi][pj];  // 直走不轉
                if (t > 0)
                    for (int e = 0; e < 4; e++)
                        if (e != d) best = min(best, prevL[e][pi][pj]);  // 在前一格轉彎
                if (best < INF) cur[d][i][j] = best + grid[i][j];
            }
    prevL = cur;
}
// ans = min_d cur[d][m-1][n-1];m = n = 1 時直接 grid[0][0]
```
:::

### [Q4. Count Subarrays with Distant Sums](https://leetcode.com/problems/count-subarrays-with-distant-sums/)
`BIT` `逆序對` `LC~est2050`

::: info 題意
給 `nums`(可為負,$n\le10^5$)、整數 `goal` 與 $k\ge0$。子陣列 distant $\iff|\text{sum}-\text{goal}|\ge k$。**求** distant 子陣列的個數。

例:`nums=[2,-1,3]`、goal $=2$、$k=2$。六個子陣列的和是 $2,1,4,-1,2,3$,跟 goal 差 $\ge2$ 的只有 $-1$(`[-1]`)和 $4$(`[2,-1,3]`)→ 2。
:::

::: tip 作法
數反面比較乾淨:「不 distant」$\iff\text{goal}-k<\text{sum}<\text{goal}+k$ 是**開區間**,$k=0$ 時自動為空,不用特判。prefix $P$,對每個右端 $j$ 數前面有幾個 $P[i]$ 落在 $(P[j]-\text{goal}-k,\ P[j]-\text{goal}+k)$:座標壓縮 + BIT,總數 $\frac{n(n+1)}2$ 減掉。跟 [WC513 Q4](/cp/leetcode/2026-08#weekly-513-·-2026-08-02) 同一套;值到 $10^{14}$,64 位。

```cpp
for (int j = 0; j <= n; j++) {
    if (j > 0) {                                                                // 前面的 P[i] 落在開區間 (P[j]-goal-k, P[j]-goal+k) 的個數
        int lo = upper_bound(v.begin(), v.end(), P[j] - goal - k) - v.begin();  // 第一個 > 下界 的名次
        int hi = lower_bound(v.begin(), v.end(), P[j] - goal + k) - v.begin();  // 第一個 >= 上界 的名次
        if (hi > lo) bad += bit.pre(hi) - bit.pre(lo);                          // k = 0 時 hi == lo,自然為 0
    }
    bit.add(rank(P[j]));
}
return (long long)n * (n + 1) / 2 - bad;
```
:::

### [Q4. Count Shadow Pairs II](https://leetcode.com/problems/count-shadow-pairs-ii/)
`分治` `BIT` `資料結構` `LC~est2500`

::: info 題意
給 `nums`($n\le5\times10^4$)。$(i,j)$ 是 shadow pair $\iff i<j$、$\text{nums}[i]<\text{nums}[j]$,且 $i,j$ 之間**沒有**值嚴格介於兩者之間的元素。**求**對數。

例:`nums=[3,1,4,2,5]`。$(0,2)$:$3<4$,中間的 $1$ 不在 $(3,4)$ 內 ✓;$(1,3)$:$1<2$,中間的 $4$ 不在 $(1,2)$ 內 ✓;$(2,4)$:$4<5$,中間的 $2$ ✓;$(1,2)$、$(3,4)$ 相鄰 ✓;$(0,4)$ 中間有 $4\in(3,5)$ ✗。共 5。
:::

::: tip 作法
分治,只算跨中線的 $(i,j)$。夾在中間的元素不是「左半、在 $i$ 之後」就是「右半、在 $j$ 之前」,兩邊各自只要看一個極值:令 $b[i]$ = 左半 $i$ 之後比 $\text{nums}[i]$ 大的**最小值**(沒有記 $+\infty$)、$c[j]$ = 右半 $j$ 之前比 $\text{nums}[j]$ 小的**最大值**(沒有記 $-\infty$),則

$$(i,j)\ \text{合法}\iff c[j]\le\text{nums}[i]<\text{nums}[j]\le b[i]$$

——「中間沒有夾在兩者之間的值」被拆成左右兩個獨立的單邊條件。$b,c$ 各用一個 ordered set 掃一遍即得。

計數:把右端點按 $\text{nums}[j]$ 升序處理,左端點在 $\text{nums}[i]<v$ 時啟用、$b[i]<v$ 時撤銷(兩個單調指標),BIT 上數啟用者中 $\text{nums}[i]\ge c[j]$ 的個數。每層 $O(n\log n)$,總 $O(n\log^2n)$。

```cpp
// 跨中線:右端點依 nums[j] 升序;左端點依 nums[i] 升序啟用、依 b[i] 升序撤銷
for (int j : byValR) {
    long long v = a[mid + j];
    while (pa < L.size() && a[l + L[pa]] < v) bit.add(rk(a[l + L[pa++]]), +1);    // nums[i] < nums[j]:啟用
    while (pd < byB.size() && b[byB[pd]] < v) bit.add(rk(a[l + byB[pd++]]), -1);  // b[i] < nums[j]:撤銷
    int lo = c[j] == -INF ? 0 : rk(c[j]);
    ans += bit.pre(vals.size()) - bit.pre(lo);  // 啟用者中 nums[i] >= c[j]
}
```
:::
