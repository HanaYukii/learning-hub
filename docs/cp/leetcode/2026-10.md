### [Q4. Count Good Strings](https://leetcode.com/problems/count-good-strings/)
`數學` `LC~2126`

::: info 題意
只含 `a`/`b` 的字串是 good $\iff$ 只有一種字元且長度為奇數,或能寫成 $s_1+s_2$,兩段都 good 且交界的兩個字元不同。**求**長度 $n$($\le10^{15}$)的 good 字串數 mod $10^9+7$。

例:$n=4$ 有 6 個:`aaab`、`abbb`、`baaa`、`bbba`、`abab`、`baba`——每個極大同字元段的長度都是奇數($1{+}1{+}1{+}1$、$1{+}3$、$3{+}1$)。
:::

::: tip 作法
遞迴定義只能在**段邊界**切(交界字元要不同),切到底每一段都是單字元段、必須奇數長;反過來奇數段序列逐段接回去就是 good。所以 good $\iff$ **每個極大同字元段長度都是奇數**。把 $n$ 寫成奇數的有序和:$f(1)=f(2)=1$,$f(n)=f(n-1)+f(n-2)$(最後一段長 $1$,或長 $\ge3$ 時砍掉 $2$),就是 Fibonacci;首字元兩種選法,答案 $2F(n)$。$n$ 到 $10^{15}$ 用 fast doubling $O(\log n)$。
:::

### [Q4. Minimize Inversions in a Prefix Tree](https://leetcode.com/problems/minimize-inversions-in-a-prefix-tree/)
`樹` `狀壓` `dp` `LC~2486`

::: info 題意
$n$ 個相異單字(字母 `a`–`j`,長 $\le20$,$n\le10^4$)建成 trie,單字結尾的節點標上它的 index。每個節點的**子節點順序可任意決定**,做 pre-order(走到標記節點先記下 index)得到 `traversal`。給 `target` 排列,`pos[i]` = $i$ 在 `target` 的位置。**求** traversal 中 pos 遞減的配對(逆序對)數的最小值。

例:`words=["ab","ac","ba","bc"]`、`target=[0,3,1,2]`(`pos=[0,2,3,1]`)。`a` 分支先、`ab` 前 `ac`;`b` 分支裡 `bc` 前 `ba` → traversal $[0,1,3,2]$,pos 依序 $0,2,1,3$,只有一個逆序對 $(2,1)$。
:::

::: tip 作法
每個子樹在 traversal 裡是**連續一塊**,塊內怎麼排不影響跨塊的逆序對,所以**每個節點獨立決定子節點順序**。節點的兩個子樹 $a,b$:$a$ 塊排在 $b$ 塊前面的代價 $\text{cost}[a][b]=\#\{u\in a,\ w\in b:\text{pos}[u]>\text{pos}[w]\}$。計算方式:**依 target 順序(pos 遞增)處理單字**,沿它的路徑在每個節點看它落在哪個子節點 $b$,其他子節點 $a$ 裡「已處理」的單字 pos 都比它小,所以 $\text{cost}[b][a]\mathrel{+}=\text{cnt}[a]$。子節點最多 10 個 → 子集 DP $O(2^c\,c)$ 排順序。另加固定項:標記節點本身排在所有後代前面,後代裡 pos 比它小的各算一個逆序對。

```cpp
// 依 target 順序處理單字 w(pos 遞增):沿路徑累 cost,再把 w 計入各層 cnt
for (int p = 0; p < n; p++) {
    int w = target[p], v = 0;
    for (char ch : words[w]) {
        int b = ch - 'a';
        for (int a = 0; a < 10; a++)                                            // 其他子樹裡已處理(pos 更小)的單字
            if (a != b && child[v][a] >= 0) cost[v][b][a] += cnt[child[v][a]];  // b 排前面就全是逆序對
        v = child[v][b];
    }
    fixedInv += cnt[v];  // 標記節點排在後代前面:後代裡 pos 更小的
    v = 0;
    cnt[0]++;
    for (char ch : words[w]) {
        v = child[v][ch - 'a'];
        cnt[v]++;
    }
}
// 每個節點:dp[mask | b] = min(dp[mask] + Σ_{a ∈ mask} cost[a][b]),答案 = fixedInv + Σ dp[full]
```

### [Q4. Prime Subset Selection II](https://leetcode.com/problems/prime-subset-selection-ii/)
`背包` `dp` `LC~2104`

::: info 題意
給 $n,s\le1000$。從 $\le n$ 的質數中選子集:和 $\le s$ 且**最大**;同和取**個數最少**;再同則取升序排列**字典序最小**者。**輸出**選到的質數(升序);選不到回空。

例:$n=15$、$s=18$:和為 $18$ 的子集有 $[5,13],[7,11],[2,3,13],[2,5,11]$;最少兩個的是 $[5,13]$、$[7,11]$;字典序取 $[5,13]$。
:::

::: tip 作法
三層字典序目標用**後綴 DP**一次搞定:$dp[i][t]$ = 只用第 $i$ 個以後的質數湊出 $t$ 的最少個數。最大可達的 $t\le s$ 就是和,$dp[0][t]$ 是個數。重建時**按升序掃質數,能選就選**($dp[i{+}1][t-p_i]=\text{need}-1$ 時選 $p_i$)——因為後綴表保證剩下的還湊得出來,先選小的就是字典序最小。$O(\pi(n)\cdot s)\approx168\times1000$。

```cpp
for (int i = m - 1; i >= 0; i--)  // 後綴 DP:dp[i][t] = 用 pr[i..] 湊 t 的最少個數
    for (int t = 0; t <= s; t++) {
        dp[i][t] = dp[i + 1][t];
        if (t >= pr[i] && dp[i + 1][t - pr[i]] < INF) dp[i][t] = min(dp[i][t], dp[i + 1][t - pr[i]] + 1);
    }
int t = s;
while (t > 0 && dp[0][t] >= INF) t--;  // 最大可達的和
int need = dp[0][t];
for (int i = 0; i < m && t > 0; i++)  // 升序掃:能選就選 → 字典序最小
    if (t >= pr[i] && dp[i + 1][t - pr[i]] == need - 1) {
        res.push_back(pr[i]);
        t -= pr[i];
        need--;
    }
```
:::

### [Q4. Minimum Interval Selection to Cover Target Intervals](https://leetcode.com/problems/minimum-interval-selection-to-cover-target-intervals/)
`貪心` `掃描線` `LC~est2100`

::: info 題意
兩組閉區間 `availableIntervals`、`targetIntervals`(端點為整數 $\le10^5$,各至多 $5\times10^4$ 個)。選最少個 available,使 target 聯集內的**每個實數點**都被某個選到的區間覆蓋。做不到回 $-1$。

例:available `[[1,2],[3,4]]`、target `[[1,4]]`:兩個都選,$2.5$ 仍沒被蓋 → $-1$。
:::

::: tip 作法
端點全是整數,所以**只要看整數點與半整數點**:座標 $\times2$,區間 $[l,r]$ 變成位置 $2l..2r$。差分標出需要覆蓋的位置,`far[x]` = 起點 $\le x$ 的 available 中最遠的右端。從左掃:遇到需要且還沒被蓋到的位置 $x$,`far[x] < x` 就 $-1$,否則選那個最遠的、覆蓋推到 `far[x]`。就是經典的區間覆蓋貪心,只是座標要加倍。$O(V+n)$。

```cpp
for (auto [l, r] : target) {
    need[2 * l]++;
    need[2 * r + 1]--;
}  // 差分:需要覆蓋的加倍座標
for (auto [l, r] : avail) far[2 * l] = max(far[2 * l], 2 * r);
for (int x = 1; x <= M; x++) {
    need[x] += need[x - 1];
    far[x] = max(far[x], far[x - 1]);
}  // far[x]:起點 <= x 的最遠右端
int cnt = 0, covered = -1;
for (int x = 0; x <= M; x++) {
    if (need[x] <= 0 || x <= covered) continue;  // 不需要、或已被蓋
    if (far[x] < x) return -1;                   // 沒有區間蓋得到 x
    covered = far[x];
    cnt++;  // 選最遠的那個
}
return cnt;
```
