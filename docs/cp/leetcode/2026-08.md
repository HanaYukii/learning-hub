### [Q4. Minimum Possible Maximum Waiting Time](https://leetcode.com/problems/minimum-possible-maximum-waiting-time/)
`dp` `狀態擴充` `LC~2499`

::: info 題意
兩台加油機,初始油量 `fuel[0]`、`fuel[1]`。車子依序 $0,\dots,n-1$:車 $0$ 在時間 $0$ 可以選機,車 $i$ 在**車 $i-1$ 開始加油的瞬間**變成可選。可選時必須挑一台剩油 $\ge$ `demand[i]` 的機器(兩台都夠就任選,不看誰先空),然後等該機空出、立刻開始加,加 `demand[i]` 秒並扣掉 `demand[i]` 油;兩台都不夠油則整個流程結束,後面的車都不服務。

等待時間 = 從可選到實際開始。**求**:在「服務車數最多」的所有分配裡,最大等待時間的最小值;一台車都服務不了回 $-1$。$n\le50$、`demand`$\le20$、`fuel`$\le50$。

例:`demand=[3,3,3]`、`fuel=[6,3]`。三台都服務 ⇒ 機 0 必須接兩台。不管怎麼排(0-0-1、0-1-0、1-0-0),第二次用機 0 的那台車可選時,機 0 都還要 3 秒才空——中間那台車沒等,時間根本沒前進——所以最大等待恆為 3。答案 3。
:::

::: tip 作法
難點只在**狀態怎麼取才不爆**。把「車 $i$ 可選的那一刻」當時間原點,記兩台機器「還要幾秒才空」$b_0,b_1\ (\le20)$ 與機 0 的剩油 $f_0$($f_1$ 由總消耗推回,不進 key)。選機 $j$:等待 $=b_j$;新狀態 $b_j\leftarrow$ `demand[i]`、另一台 $b\leftarrow\max(0,b-b_j)$(下一台車的原點往後移了 $b_j$ 秒)、$f_j$ 扣油。狀態 $50\times51\times21\times21\approx1.1\times10^6$,每個兩個轉移。

目標是字典序 (服務數 $\max$, 最大等待 $\min$)。**服務數只由油的分配決定、跟等待無關**,所以不存在「少服務一台換更小等待」的取捨,子問題的字典序最佳解可以直接組合:DP 值存 pair,合併成 $(c+1,\ \max(b_j,w))$ 再字典序比較。

```cpp
// 狀態 (i, f0, b0, b1):車 i 可選的瞬間,兩台「還要幾秒才空」b0/b1、機 0 剩油 f0(f1 可推回)
pair<int, int> go(int i, int f0, int f1, int b0, int b1) {  // (最多服務數, 其最小的最大等待)
    if (i == n) return {0, 0};
    if (auto it = memo.find(key(i, f0, b0, b1)); it != memo.end()) return it->second;
    pair<int, int> best = {0, 0};  // 兩台都沒油:流程在這裡結束
    if (f0 >= d[i]) {              // 選機 0:等 b0 秒;下一台車的原點往後移 b0
        auto [c, w] = go(i + 1, f0 - d[i], f1, d[i], max(0, b1 - b0));
        best = better(best, {c + 1, max(b0, w)});
    }
    if (f1 >= d[i]) {
        auto [c, w] = go(i + 1, f0, f1 - d[i], max(0, b0 - b1), d[i]);
        best = better(best, {c + 1, max(b1, w)});
    }
    return memo[key(i, f0, b0, b1)] = best;
}
// better:服務數大者;同數取最大等待小者。答案 = d[0] > max(fuel) ? -1 : go(0, fuel[0], fuel[1], 0, 0).second
```
:::

### [Q4. Count Subarrays With Even Odd Ratio II](https://leetcode.com/problems/count-subarrays-with-even-odd-ratio-ii/)
`BIT` `逆序對` `LC~2156`

::: info 題意
給 `nums` 與正整數 $a,b$。子陣列中偶數個數 $x$、奇數個數 $y$,合法 $\iff y>0$ 且 $x/y\le a/b$(精確比較有理數)。**求**合法子陣列數。$n\le10^5$、$a,b\le10^9$。

例:`nums=[2,2,1]`、$a=2,b=1$。偶 $\to+1$、奇 $\to-2$ 得 $[1,1,-2]$,prefix $0,1,2,0$;prefix$[3]=0$ 小於等於前面三個 prefix → 3(對應 `[2,2,1]`、`[2,1]`、`[1]`)。
:::

::: tip 作法
$x/y\le a/b\iff b\,x-a\,y\le0$:**偶數換成 $+b$、奇數換成 $-a$,合法 $\iff$ 區間和 $\le0$**。$y=0$ 的子陣列和 $>0$,自動被排除,不用另外處理。

之後是 prefix $P$ 上數 $l<r$ 且 $P[r]\le P[l]$ 的對數:座標壓縮 + BIT 從左掃,每個 $r$ 數前面有幾個 $\ge P[r]$。$O(n\log n)$;和到 $10^{14}$,64 位。

```cpp
for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + (nums[i] % 2 == 0 ? b : -(long long)a);  // 偶 +b、奇 -a
for (int r = 0; r <= n; r++) {
    int k = rank(pre[r]);                           // 座標壓縮後的名次
    if (r > 0) ans += inserted - bit.query(k - 1);  // 前面 >= pre[r] 的個數
    bit.add(k);
    inserted++;
}
```
:::

### [Q4. Peaks in Array II](https://leetcode.com/problems/peaks-in-array-ii/)
`BIT` `貢獻` `資料結構` `LC~2516`

::: info 題意
長度 $n$ 的 `nums`,兩種操作:查詢 $[l,r]$ 內「峰子陣列」個數——長度 $\ge3$、且存在**內部** index $k$($i<k<j$)使 `nums[k]` 同時大於左右鄰居;單點改值。$n,q\le10^5$。

例:`nums=[1,3,2,4,1]`、查 $[0,4]$。峰在 index $1$、$3$。長度 $\ge3$ 的子陣列 6 個,只有 $[1,3]$(即 `[3,2,4]`)內部沒有峰 → 答案 5。用下面的公式:$a=1,b=3,q=0$,$W=1\cdot(1-0)+3\cdot(3-1)=7$,$r(b-l)-W+a(l-q)=4\cdot3-7+0=5$。
:::

::: tip 作法
峰的判定只看三個相鄰值,改一點最多動 $x-1,x,x+1$ 三個峰位——峰的集合放 `set` 維護。查詢時只有**嚴格在 $(l,r)$ 內**的峰 $a=p_1<\dots<p_t=b$ 算數;把每個子陣列**歸給它最左邊的峰**去重:歸給 $p_i$ 的子陣列左端 $\in[\max(l,p_{i-1}),\,p_i)$、右端 $\in(p_i,\,r]$,共 $(p_i-\max(l,p_{i-1}))\,(r-p_i)$ 個。

把總和展開:

$$\text{ans}=r\,(b-l)\;-\;\sum_{i}p_i\,(p_i-p_{i-1})\;+\;a\,(l-q)$$

($q$ 是 $a$ 前一個峰,沒有就記 $0$。)只有中間那項跟區間內容有關,而它是**每個峰自己的量** $\text{value}[p]=p\,(p-\text{prev}(p))$,丟 BIT 做區間和。改值時對受影響的三個位置先 remove 再 insert,每次順手修正後繼峰的 value(它的 prev 變了)。$O((n+q)\log n)$。

```cpp
// value[p] = p * (p - prev(p)) 存在 BIT;peaks 是 set<int>
auto it = peaks.upper_bound(l);               // 第一個 > l 的峰
if (it == peaks.end() || *it >= r) return 0;  // 沒有嚴格在 (l, r) 內的峰
long long a = *it, q = prevOf(it);            // q:a 的前一個峰,沒有就 0
long long b = *prev(peaks.lower_bound(r));    // 最後一個 < r 的峰
long long W = bit.range(a, b);
return r * (b - l) - W + a * (l - q);
// 改值:x-1, x, x+1 先 remove 再依新值 insert;insert/remove p 時重算後繼峰的 value
```
:::

### [Q4. Elevator Requests II](https://leetcode.com/problems/elevator-requests-ii/)
`區間dp` `貢獻` `LC~2280`

::: info 題意
樓層 $0..n-1$($n\le10^9$),電梯從 `start` 出發;時間 $0$ 同時有 $m$ 個相異樓層的請求($m\le1500$)。每秒移動一層;到達請求樓層即時完成(`start` 本身若被請求算時間 $0$ 完成)。每個請求在時間 $t$ 完成就罰 $t$ 分。**求**罰分總和最小值。

例:$n=10$、`start=5`、`requests=[0,2,9]`。走 $5\to2\to0\to9$:$5\to2$ 花 3 秒、三個都沒完成 → $3\times3=9$;$2\to0$ 花 2 秒、剩兩個 → $2\times2=4$;$0\to9$ 花 9 秒、剩一個 → $9$。合計 22,是最佳。
:::

::: tip 作法
排序後,電梯**走過的樓層集合永遠是連續區間** $[l,r]$(從 `start` 那格長出去),而且人在區間某一端。把「每個請求完成時間的總和」換個算法:**每秒有幾個未完成請求就罰幾分**——從 $[l,r]$ 往外多走 $d$ 層,花費 $=$(區間外請求數)$\times d$,費用只跟目前區間有關,不用記時間。`dp[l][r][在左/右端]`,轉移各兩個(往 $l-1$ 或 $r+1$),$O(m^2)$。`start` 本身不是請求時,把它插進排序陣列當一個「不計數」的點。64 位。

```cpp
// x:排序後的樓層(含 start);s = start 的位置;rem(l, r) = 區間外還沒完成的請求數
dp[s][s][0] = dp[s][s][1] = 0;
for (int len = 1; len < M; len++)
    for (int l = 0; l + len - 1 < M; l++) {
        int r = l + len - 1;
        for (int side = 0; side < 2; side++) {
            long long c = dp[l][r][side], pos = side ? x[r] : x[l], k = rem(l, r);
            if (l > 0) dp[l - 1][r][0] = min(dp[l - 1][r][0], c + k * (pos - x[l - 1]));      // 往左擴:每秒罰 k
            if (r + 1 < M) dp[l][r + 1][1] = min(dp[l][r + 1][1], c + k * (x[r + 1] - pos));  // 往右擴
        }
    }
return min(dp[0][M - 1][0], dp[0][M - 1][1]);
```
:::

### [Q4. Elevator Requests III](https://leetcode.com/problems/elevator-requests-iii/)
`狀壓` `dp` `LC~2201`

::: info 題意
樓層 $0..n-1$,電梯從 `start` 出發,每秒可上一層、下一層或停留。`requests[i] = [arrival_i, floor_i]`(至多 16 個):從 `arrival_i` 起,電梯只要在該層(任何時刻)就算完成。**求**全部完成的最早時間。

例:`start=0`,請求 $(t{=}0,\text{樓}8)$、$(t{=}6,\text{樓}5)$:先去 5(時間 5 到、等到 6 完成)再上到 8 → 9;反過來先 8 再 5 要 $8+3=11$。答案 9。
:::

::: tip 作法
16 個請求就是 `dp[mask][i]` = 完成 `mask`、最後停在 $\text{floor}_i$ 的最早時間;轉移 $\text{dp}[\text{mask}\cup\{j\}][j]=\max(\text{dp}[\text{mask}][i]+|\text{floor}_i-\text{floor}_j|,\ \text{arrival}_j)$——「等到請求出現」就是那個 $\max$。$O(2^m m^2)$。

「順路經過先完成」不用特別處理:任何真實走法照完成順序拆段,每段耗時 $\ge$ 距離、完成時刻 $\ge$ arrival,所以 DP 值不會比真實走法差,而 DP 的走法本身又做得到。

```cpp
for (int j = 0; j < m; j++) dp[1 << j][j] = max((long long)abs(start - fl[j]), (long long)arr[j]);
for (int mask = 1; mask < (1 << m); mask++)
    for (int i = 0; i < m; i++) {
        if (dp[mask][i] >= INF) continue;
        for (int j = 0; j < m; j++)
            if (!(mask >> j & 1))  // 走去 j,必要時等它出現
                dp[mask | 1 << j][j] = min(dp[mask | 1 << j][j], max(dp[mask][i] + abs(fl[i] - fl[j]), (long long)arr[j]));
    }
```
:::

### [Q4. Valid K-Unique Subarrays I](https://leetcode.com/problems/valid-k-unique-subarrays-i/)
`XOR` `離線` `BIT` `LC~2314`

::: info 題意
給 `nums`、$k$ 與 $q$ 個區間查詢 $[l,r]$。子陣列合法 $\iff$ 相異值**恰** $k$ 種,且每種值出現次數皆為**偶數**。回傳每個查詢的 bool。$n,q\le10^5$。

例:`nums=[1,2,2,1]`、$k=2$:$[0,3]$ 兩種值各 2 次 → true;$[1,2]$ = `[2,2]` 只有一種 → false;$[0,1]$ = `[1,2]` 各一次 → false。
:::

::: tip 作法
兩個條件拆開各有 $O(\log)$ 做法,不必 Mo。

- **全偶**:每個值配一個隨機 64 位 key,做 prefix XOR $H$;區間內每種值都出現偶數次 $\iff H[r+1]=H[l]$(誤判機率 $2^{-64}$ 級)。
- **恰 $k$ 種**:經典離線區間相異數——查詢按 $r$ 排序,掃到 `nums[r]` 時在 BIT 上把它上一次出現的位置 $-1$、現在的位置 $+1$,區間和就是相異數。

$O((n+q)\log n)$。官方解是 Mo's algorithm $O(n\sqrt q)$ 維護「出現奇數次的值有幾個」,也過;但這題本質是兩個互不相干的計數,拆開反而乾淨。

```cpp
for (int i = 0; i < n; i++) H[i + 1] = H[i] ^ key[nums[i]];  // 隨機 64 位 key 的 prefix XOR
// 查詢依 r 排序後離線掃
for (auto [l, r, id] : queries) {
    while (nxt <= r) {  // 離線相異數:每個值只保留最後一次出現
        if (last.count(nums[nxt])) bit.add(last[nums[nxt]], -1);
        bit.add(nxt, +1);
        last[nums[nxt]] = nxt++;
    }
    ans[id] = (H[r + 1] == H[l]) && bit.range(l, r) == k;  // 全偶 && 恰 k 種
}
```
:::

### [Q4. Maximum Valid Split Positions II](https://leetcode.com/problems/maximum-valid-split-positions-ii/)
`數論` `貢獻` `LC~2372`

::: info 題意
給 `nums`($n\le10^5$、值 $\le10^9$),可刪**至多一個**元素得到 `arr`。切點 $i$ 合法 $\iff\gcd(\text{arr}[0..i])=\gcd(\text{arr}[i+1..])$($0\le i<m-1$)。**求**所有刪法中合法切點數的最大值。

例:`nums=[10,30,15,10]`。不刪:prefix gcd $10,10,5,5$、suffix gcd $5,5,5,10$,三個切點都不相等 → 0。刪掉 15 得 `[10,30,10]`:切在 $10\mid30,10$ → $10=10$;切在 $10,30\mid10$ → $10=10$,兩個都合法 → 2。
:::

::: tip 作法
prefix gcd $P$、suffix gcd $S$。刪 $j$ 之後切點分兩側:切在 $j$ 左邊(位置 $i<j$)時左段 $=P[i]$,右段 $=\gcd(g(i{+}1..j{-}1),\,S[j{+}1])$;右側鏡像。對每組 $(j,i)$ 硬算是 $O(n^2)$。

兩件事救回來。**(1) 固定右端的區段 gcd,隨左端移動只變 $O(\log V)$ 次**:對每個 $j$ 維護「以 $j-1$ 結尾的所有後綴 gcd」分段表(每加一個元素:全表跟新值取 gcd、合併相同值、補上新段,總長 $O(n\log V)$);同一段內右段 gcd 是定值 $t=\gcd(\text{段值},S[j+1])$。**(2) $P$ 單調(後者整除前者),所以 $P[i]=t$ 的 $i$ 是連續一段**:預存每個值的 $[\text{first},\text{last}]$,跟本段的 $i$ 範圍取交集就是這段的合法切點數。右側用前綴 gcd 分段 × $S$ 查表鏡像處理,再加上「切在 $j$ 原本位置」那一個($P[j-1]$ vs $S[j+1]$),跟不刪的情況取 $\max$。$O(n\log V)$ 段、每段查表 $O(1)$。

```cpp
// L:以 j-1 結尾的後綴 gcd 分段表 (值, 最左起點 s);cntP(lo, hi, t) = [lo, hi] 內 P[i] == t 的個數(P 單調 → 查表)
for (int j = 0; j < n; j++) {
    long long Sj = S[j + 1];
    if (j >= 1) score[j] += (P[j - 1] == Sj);  // 切在 j 原本的位置
    for (size_t k = 0; k < L.size(); k++) {
        int sLo = L[k].second, sHi = (k + 1 < L.size() ? L[k + 1].second : j) - 1;
        score[j] += cntP(max(sLo - 1, 0), sHi - 1, gcd(L[k].first, Sj));  // 切點 i = s - 1;右段 gcd 在段內是定值
    }
    vector<pair<long long, int>> NL;  // 加入 nums[j]:全表取 gcd,相同值合併,補新段
    for (auto [v, st] : L) {
        long long g = gcd(v, (long long)nums[j]);
        if (NL.empty() || NL.back().first != g) NL.push_back({g, st});
    }
    if (NL.empty() || NL.back().first != nums[j]) NL.push_back({(long long)nums[j], j});
    L = NL;
}
// 右側鏡像(前綴 gcd 分段 × S 查表)後,score[j] 再與不刪的情況取 max
```
:::

### [Q4. Minimum Operations to Form Subset Sum II](https://leetcode.com/problems/minimum-operations-to-form-subset-sum-ii/)
`背包` `dp` `LC~2100`

::: info 題意
給 `nums`(至多 100 個、值 $\le500$)與 $\text{sum}\le5000$。一次操作把某元素 $x$ 換成 $2x$ 或 $\lfloor x/2\rfloor$,順序不限。**求**最少操作次數,使某個子集合的和恰為 sum;不可能回 $-1$。

例:`nums=[6,3]`、sum $=8$:$3\to1\to2$(先除後乘,2 次),$6+2=8$。Q3 版(乘法必須全在除法之前)則做不到,回 $-1$。
:::

::: tip 作法
單一元素的最佳操作序列裡**不會出現「先乘、後來又除」**:從那次乘之後看第一次除,兩者之間全是乘,所以除的時候值是偶數、恰好抵消最後那次乘——刪掉這一對更省。因此每個元素的最終值只有 $\lfloor x/2^d\rfloor\cdot2^m$ 這種形(先除 $d$ 次再乘 $m$ 次),cost $d+m$;$\le$ sum 的候選每個元素不到 100 個,同值取最小 cost。剩下是「每個元素選一個 (值, cost) 或不選」的分組背包,$O(n\cdot\text{sum}\cdot\text{候選數})\approx5\times10^7$。Q3 只是把候選限制成純乘或純除,同一份 DP。

```cpp
for (int x : nums) {
    unordered_map<int, int> best;  // 值 -> 最少操作:先除 d 次再乘 m 次
    for (int d = 0, v = x; v > 0; d++, v /= 2)
        for (int m = 0; (long long)v << m <= sum; m++)
            best[v << m] = min(best.count(v << m) ? best[v << m] : INF, d + m);
    vector<int> nd = dp;  // 不用 x
    for (auto [w, c] : best)
        for (int s = sum; s >= w; s--)
            if (dp[s - w] < INF) nd[s] = min(nd[s], dp[s - w] + c);  // 每個元素至多選一個值(分組背包)
    dp = nd;
}
```
:::
