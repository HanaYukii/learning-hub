### [E. Quiz Competition: Qualifiers](https://atcoder.jp/contests/abc475/tasks/abc475_e)
`字串` `資料結構` `AtC~1750`

::: info 題意
$N$ 位參賽者、$K$ 題二選一($N\le3\times10^4$、$K\le200$),最多 $M$ 人晉級。流程:對 $k=1..K$ 依序,若「已晉級人數 + 未定者中第 $k$ 題答對的人數」$\le M$,未定者中答對的全部晉級;否則未定者中答錯的全部淘汰。跑完後仍未定者淘汰。$Q$ 次詢問($\le5\times10^4$):把某人某題的答案翻轉(永久),然後**回答**此人是否晉級。

例:$T=$`oo`、$S=($`oo`$,$`ox`$,$`xo`$)$、$M=2$:錯誤向量 `00`、`01`、`10`,字典序前兩名晉級,$S_3$ 的 `10` 排第三、不晉級。把 $S_1$ 第二題改錯後變成 `01`,跟 $S_2$ 並列,「$\le$ 自己的人數」是 $2\le M$,仍晉級。
:::

::: tip 作法
把每個人寫成長度 $K$ 的 01 向量 $X_i$($X_{i,k}=1$ 表示第 $k$ 題答錯)。流程每一輪都是「答對的那群優先」,等於**依 $X$ 的字典序排名**:$N>M$ 時,$i$ 晉級 $\iff$ 字典序 $\le X_i$ 的人數(含自己與相同向量者)$\le M$。$N=M$ 時例外:只有全錯的向量不晉級。

於是每次詢問就是 trie 上三個 $O(K)$ 的操作:刪掉舊向量、插入翻轉後的向量、數「$\le X_i$」的個數(沿 $X_i$ 往下走,自己這一位是 $1$ 就把 $0$ 子樹的計數整個加進來,最後加上與自己相同的)。$O((N+Q)K)$。也可以把向量當大整數丟 ordered multiset。

```cpp
int countLE(const string& x) {  // trie 上數字典序 <= x 的向量個數
    int v = 0, res = 0;
    for (char c : x) {
        int b = c - '0';
        if (b == 1 && ch[v][0] >= 0) res += cnt[ch[v][0]];  // 這一位是 1:整棵 0 子樹都比我小
        if (ch[v][b] < 0) return res;
        v = ch[v][b];
    }
    return res + cnt[v];  // 跟我完全相同的也算
}
// 查詢:tr.add(X[i], -1); X[i][j] ^= 1; tr.add(X[i], +1);
// 答案 = (n == m) ? (X[i] 非全 1) : (tr.countLE(X[i]) <= m)
```
:::

### [F. Rectangle Filling](https://atcoder.jp/contests/abc475/tasks/abc475_f)
`組合計數` `貢獻` `AtC~1900`

::: info 題意
$H\times W$ 的黑白格($HW\le2\times10^5$)。最多做一次操作:選一個矩形把裡面全部塗黑。**求**能得到的**相異盤面**數。

例:`.#` / `..`:7 種——原圖、塗掉某一個白格(3 種)、塗左欄、塗下列、全塗黑。
:::

::: tip 作法
不同矩形可能給同一個盤面,所以要挑代表:對每個有變動的盤面取**達成它的最小矩形**,特徵是**上下左右四條邊界線各至少含一個原本的白格**;反過來這種矩形兩兩對應到不同盤面。答案 $=$ 這種矩形的個數 $+1$(原圖)。

計數:預處理 $f_{i,j}$ = 第 $i$ 列從第 $j$ 欄起的第一個白格欄、$g_{i,j}$ = 第 $j$ 欄從第 $i$ 列起的第一個白格列。枚舉左右邊界 $(l,r)$:列 $i$「在 $[l,r]$ 內有白格」記 $A_i=[f_{i,l}\le r]$;矩形 $(u,d)$ 合法 $\iff A_u,A_d$ 成立且 $d\ge\max(g_{u,l},g_{u,r})$(左右邊界欄在 $[u,d]$ 內要有白格)。對每個 $A_u=1$ 的 $u$,用 $A$ 的後綴和一次數完所有 $d$。$O(HW^2)$;$H>W$ 時轉置,總 $O(HW\min(H,W))\approx9\times10^7$。

```cpp
long long ans = 1;  // 原圖
for (int l = 0; l < W; l++)
    for (int r = l; r < W; r++) {
        suf[H] = 0;
        for (int i = H - 1; i >= 0; i--) suf[i] = suf[i + 1] + (f[i][l] <= r);  // A_i:列 i 在 [l, r] 內有白格
        for (int u = 0; u < H; u++)
            if (f[u][l] <= r) {
                int d0 = max(g[u][l], g[u][r]);  // 左、右邊界欄在 [u, d] 內都要有白格
                if (d0 < H) ans += suf[d0];
            }
    }
```

### [G. Has Many Divisors](https://atcoder.jp/contests/abc475/tasks/abc475_g)
`數論` `AtC~2350`

::: info 題意
給 $N$、$D$($2\le D\le N\le10^{18}$,$T\le10$ 組)。在 $\le N$ 且**不是 $D$ 的倍數**的正整數中,**找**一個約數個數最多的,輸出任一個。

例:$N=100$、$D=2$:只能是奇數,$45=3^2\cdot5$、$63$、$75$、$99$ 都有 6 個約數,任一皆可;$D=6$ 時答案是 $80=2^4\cdot5$(10 個);$D=4$ 時是 $90=2\cdot3^2\cdot5$(12 個)。
:::

::: tip 作法
高合成數的老招是「指數沿質數 $2,3,5,\dots$ 非遞增」,理由是交換論證:$q<r$ 而 $v_q<v_r$ 時,把 $r$ 的指數搬給 $q$,約數個數不變、數字變小。這題多了「不被 $D$ 整除」,所以最小的最優解 $x$ 一定有某個質數 $p$ 滿足 $v_p(x)<v_p(D)$,而**除了 $p$ 之外**交換論證照樣成立:指數序列**非遞增,只准一個位置凹陷**(凹陷處不超過它前一個,後面的元素仍以凹陷前的值為上限)。

這種序列在 $10^{18}$ 以內只有 28 萬個,直接 DFS 枚舉(帶著乘積與約數個數),過濾 $x\bmod D\ne0$ 取最大。凹陷可以在第一個位置($v_2$ 任意、之後非遞增),像 $D=2$ 時的 $45=3^2\cdot5$ 就是 $(0,2,1)$。

```cpp
void dfs(int idx, int maxE, bool dip, long long x, long long cnt) {
    if (x % D != 0 && cnt > bestC) {
        bestC = cnt;
        bestX = x;
    }
    if (idx == 15) return;  // 前 16 個質數之積已超過 1e18,最多用到 15 個
    long long p = P[idx], y = x;
    for (int e = 1; e <= maxE; e++) {  // 正常步:指數 <= 前一個;e = 0 就結束(後面全 0)
        if (y > N / p) break;
        y *= p;
        dfs(idx + 1, e, dip, y, cnt * (e + 1));
    }
    if (dip) return;
    y = x;
    for (int e = 0; e < maxE; e++) {  // 凹陷步(至多一次):之後的上限仍是 maxE
        if (e > 0) {
            if (y > N / p) break;
            y *= p;
        }
        dfs(idx + 1, maxE, true, y, cnt * (e + 1));
    }
}
```
:::
