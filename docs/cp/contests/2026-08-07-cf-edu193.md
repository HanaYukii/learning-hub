### [A. The Best Card](https://codeforces.com/contest/2253/problem/A)
`數論` `~800`

::: info 題意
$n$ 張牌,值 $2,3,\dots,n+1$。兩張牌比大小:一方整除另一方時**小的贏**,否則大的贏。**求**是否存在一張牌贏過其他所有牌。

例:$n=4$:牌 $2..5$,$5$ 是質數 → YES;$n=5$:$6$ 被 $2,3$ 整除 → NO。
:::

::: tip 作法
每張 $x$ 都輸給 $x+1$,所以只有 $n+1$ 有機會;它贏全部 $\iff$ 不被 $2..n$ 任何一個整除 $\iff$ $n+1$ 是質數。
:::

### [B. Hypercarp and the Control Panel](https://codeforces.com/contest/2253/problem/B)
`分類討論` `貪心` `~1100`

::: info 題意
序列 $a$($n\le2\times10^5$),可刪任意元素,刪完後**至多一次**交換相鄰兩個。**求**最多能留幾個,使相鄰皆不同色。

例:$[1,2,2,1]$:不刪,交換前兩個變 $[2,1,2,1]$ → 4。$[1,2,2,3,3,1]$:交換第 3、4 個變 $[1,2,3,2,3,1]$ → 6。
:::

::: tip 作法
壓成同色區塊,共 $m$ 個。不交換就是每塊留一個,得 $m$。**一次交換最多拆開兩對相鄰同色**,所以答案 $\le m+2$,三種情況:有兩個**相鄰**區塊長度都 $\ge2$ → $m+2$($[1,1,2,2]\to[1,2,1,2]$);否則某個長度 $\ge2$ 的區塊 $i$ 能把多留的那個跟鄰塊交換——往右要 $i+1$ 存在,且 $i+2$ 不存在或顏色 $\ne$ 自己(往左對稱)→ $m+1$;否則 $m$。$O(n)$。

```cpp
for (int i = 0; i + 1 < m; i++)
    if (b[i].cnt > 1 && b[i + 1].cnt > 1) return m + 2;  // 相鄰兩塊都多一個:一次交換拆兩對
for (int i = 0; i < m; i++) {
    if (b[i].cnt > 1 && i + 1 < m && (i + 2 >= m || b[i + 2].color != b[i].color)) return m + 1;  // 往右換
    if (b[i].cnt > 1 && i > 0 && (i - 2 < 0 || b[i - 2].color != b[i].color)) return m + 1;       // 往左換
}
return m;
```
:::

### [C. Sum of Distinct Values in a Matrix](https://codeforces.com/contest/2253/problem/C)
`貪心` `分類討論` `~1500`

::: info 題意
$n\times m$ 全 $0$ 矩陣。操作:選 $a$ 中的數塗滿某一列,或選 $b$ 中的數塗滿某一欄,次數不限、順序任意。成本 = 矩陣中**相異數**之和,**求**最大值。$a,b$ 嚴格遞增、值 $\le n+m$,$\sum n,\sum m\le10^5$。

例:$n=m=2$、$a=\{1,4\}$、$b=\{2,3\}$:先塗兩欄 $2,3$、再塗第一列 $4$ → 含 $2,3,4$ → 9。四條線都用的話最早那條的數一定被蓋掉,所以最多留 3 個數。
:::

::: tip 作法
每列、每欄只有**最後一次**操作算數 → 至多 $n$ 個數來自列、$m$ 個來自欄;而且列與欄全都用到時,最早的那條線一定被後來的另一方向蓋滿,**總數 $\le n+m-1$**,反過來「$n$ 列 + $m-1$ 欄」一定做得到。麻煩的是兩邊都有的數:拆成 $c$(共有)、$d$(只在 $a$)、$e$(只在 $b$),取 $d$ 最大的 $n$ 個、$e$ 最大的 $m$ 個、$c$ 全部,合起來取最大的 $n+m-1$ 個相加。$O((n+m)\log(n+m))$。

```cpp
// two pointers 拆成 c(共有)、d(只在 a)、e(只在 b)
vector<long long> res = lastK(d, n);  // 列最多 n 個
auto t = lastK(e, m);
res.insert(res.end(), t.begin(), t.end());  // 欄最多 m 個
res.insert(res.end(), c.begin(), c.end());  // 共有的哪邊都行
sort(res.begin(), res.end());
answer = sum(lastK(res, n + m - 1));  // 總數最多 n + m - 1
```
:::

### [D. Hypercarp and Interdimensional Jumps](https://codeforces.com/contest/2253/problem/D)
`數學` `貪心` `構造` `~1800`

::: info 題意
從 $(0,0)$ 出發,跳躍向量 $(a,b)$ 初始 $(0,0)$;每一步先把 $a$ 或 $b$ 加 $1$、再跳 $(a,b)$。任何時候都不能離開 $[0,x]\times[0,y]$,可隨時停。**求**停點與 $(x,y)$ 平方距離最小的操作字串(X/Y)。$x,y\le10^8$。

例:$(5,4)$:走 3 步時座標和是 $6$,線 $p+q=6$ 上最接近 $(5,4)$ 的整點是 $(3,3)$ 或 $(4,2)$,距離都是 $5$;`XYY` 的權重 $3,2,1$ 讓 X 拿到 $3$ → $(3,3)$。
:::

::: tip 作法
$k$ 步後座標和固定是 $1+2+\dots+k=\frac{k(k+1)}2=d$,而且**線 $p+q=d$ 上每個非負整點都到得了**:第 $i$ 步選 X 就是把權重 $i$ 給第一座標,$1..k$ 的子集和覆蓋 $0..d$。座標和越大離目標越近,所以取最大的 $k$ 使 $d\le x+y$。再在線上找離 $(x,y)$ 最近的整點:$(x,y)$ 往線的投影是 $P_1=(d-y,y)$ 與 $P_2=(x,d-x)$ 的中點,檢查中點兩旁的整點(負座標截成 $0$)。重建時權重由大到小,放得進剩餘的 $p$ 就給 X。$O(k)$,$k\le2\times10^4$。

```cpp
long long k = 0;
while ((k + 1) * (k + 2) / 2 <= x + y) k++;  // 最大的 k:座標和 d = k(k+1)/2 <= x + y
long long d = k * (k + 1) / 2;
// 候選:線 p + q = d 上、投影中點 ((d - y) + x) / 2 兩旁的整點,座標截到 [0, x] × [0, y],取距離最小者 (p, q)
string ans(k, 'Y');
for (int i = 0; i < k; i++)
    if (p >= k - i) {
        ans[i] = 'X';
        p -= k - i;
    }  // 權重 k..1 由大到小,放得進就給 X
```
:::

### [E. Diameter Intersections](https://codeforces.com/contest/2253/problem/E)
`樹` `分類討論` `根號` `~2100`

::: info 題意
$n$ 點樹($\sum n\le10^6$),直徑長度保證是奇數。$k$ 是 beautiful $\iff$ 能選兩條直徑(可相同)使交集恰有 $k$ 條邊。**輸出**所有 beautiful 的 $k$。

例:6 點樹,邊 $1$-$2,1$-$3,1$-$4,2$-$5,2$-$6$。直徑長 3(如 $5$-$2$-$1$-$3$),中心邊 $(1,2)$。拆掉它之後兩側各有「深度 0 的分叉點」與「深度 1 的葉」,交集長度 $a+b+1\in\{1,2,3\}$。
:::

::: tip 作法
任兩條直徑必有公共點;**直徑長度為奇數時更強:所有直徑共用同一條中心邊** $(x,y)$——拆掉它之後兩側離 $x$、$y$ 的最遠距離都是 $d$,任何直徑都得跨過這條邊、兩側各走滿 $d$。所以交集一定是 $u\to x\to y\to v$,$u,v$ 分別在兩側。

兩側各自找 $u$ 的候選:子樹裡有 $\ge2$ 個深度 $d$ 的葉且分在不同孩子(分叉點),或自己就是深度 $d$ 的葉。真正要的只是候選的**深度集合**,而**相異深度只有 $O(\sqrt n)$ 種**:把深度 $d$ 的葉依 DFS 序排好,相鄰兩葉 LCA 的深度 $m_i$ 就是候選深度,每個新的 $m_i$ 至少多花 $d-m_i$ 條邊,$q$ 種相異深度至少要 $1+2+\dots+q$ 條邊。兩側深度兩兩相加 $O(n)$,整體 $O(n)$。

```cpp
// 一側:從 x 出發 BFS(不走 y),md = 最深深度;把每個最深葉到根的路徑標成 has_end
for (int k : order)
    if (d[k] == md)
        for (int cur = k; !has_end[cur]; cur = p[cur]) has_end[cur] = true;
for (int k : order) {
    if (!has_end[k]) continue;
    int c = 0;
    for (int w : g[k])
        if (w != p[k] && has_end[w]) c++;
    if (c != 1) depths.push_back(d[k]);  // 0 個:最深葉本身;>= 2 個:分叉點
}
// 去重後,答案 = { a + b + 1 : a 在 x 側、b 在 y 側 }
```
:::
