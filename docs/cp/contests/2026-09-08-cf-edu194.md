### [B. Monocarp and Projects](https://codeforces.com/contest/2260/problem/B)
`數學` `不變量` `~1300`

::: info 題意
第 $i$ 個月（從 0 開始）有 $x+i$ 位員工與 $y+i$ 個專案；每位員工分到相同數量的專案，老闆處理無法平均分配的餘數。

給定 $1\le x\le y\le10^6$、$1\le k\le10^{12}$，**求前 $k$ 個月老闆處理的專案總數** $\sum_{i=0}^{k-1}(y+i)\bmod(x+i)$；各測資 $y$ 總和不超過 $10^6$。

例：$x=2,y=7,k=5$，各月餘數為 $1,2,1,0,5$，總和是 9。
:::

::: tip 作法
**分子、分母同時加一，差 $d=y-x$ 不變**，因此 $(y+i)\bmod(x+i)=d\bmod(x+i)$。當分母大於 $d$，餘數永遠等於 $d$，整段尾巴可以直接乘上月份數。

需要逐月計算的只有 $c=\min(k,\max(0,d-x+1))$ 個月；時間 $O(c+1)$，所有測資總計 $O(\sum y+T)$，不必上整除分塊。

```cpp
long long d = y - x;
long long count = min(k, max(0LL, d - x + 1));
long long answer = (k - count) * d;
for (long long i = 0; i < count; i++) {
    answer += d % (x + i);
}
cout << answer << '\n';
```

分母恰好等於 $d$ 時餘數為 0，仍須放在枚舉段，所以個數有 `+1`。$x=y$ 時 $d=0$，整體答案自然為 0。乘積最大接近 $10^{18}$，使用 64 位元。
:::

### [C. Maximize XOR, Minimize Operations](https://codeforces.com/contest/2260/problem/C)
`位元` `XOR` `貪心` `~1500`

::: info 題意
給定 $0\le x,y<2^{29}$。一次操作把 $x$ 減 1、$y$ 加 1，且不能讓 $x$ 變成負數。

**先最大化最後的 $x\oplus y$，再最小化達成該最大值的操作次數**，輸出這兩個數。測資數不超過 $10^4$。

例：$x=5,y=6$，總和為 11（二進位 `1011`）。不超過 5 的最大 submask 是 3，所以做兩次變成 $(3,8)$，XOR 為 11。
:::

::: tip 作法
令 $S=x+y$，利用 $u+v=(u\oplus v)+2(u\mathbin{\&}v)$，可知 **XOR 上限為 $S$，而把 $x$ 移到 0 一定能達成**。要用最少操作達成上限，則要找最大的 $u\le x$，使 $u\mathbin{\&}(S-u)=0$；這等價於 $u$ 是 $S$ 的 submask。

從高位到低位選 $S$ 的 1-bit，只要不超過剩餘額度就拿。高位權重大於所有更低位總和，所以這是最大可行 submask；最後剩餘額度正好是操作數。

```cpp
long long total = x + y;
long long remaining = x;
for (int bit = 30; bit >= 0; bit--) {
    long long value = 1LL << bit;
    if ((total & value) && remaining >= value) {
        remaining -= value;
    }
}
cout << total << ' ' << remaining << '\n';
```

本地程式用的是等價的「保持與 $x$ 的高位前綴相同，首次能變小時把可用低位全取走」寫法；上面改寫成官方程式同樣的額度貪心，較容易看出不變量。時間 $O(\log(x+y+1))$。
:::

### [D. Signs of Prefix Sums](https://codeforces.com/contest/2260/problem/D)
`分類討論` `dp` `構造` `~1900`

::: info 題意
給定長度 $N\le3\times10^5$、只含 `+`、`-`、`0` 的字串 $s$，分別指定整數陣列的每個前綴和為正、負或零。

陣列每個元素都必須非零。**求符合符號序列的陣列之最小 $\max_i|a_i|$**，無解輸出 $-1$；各測資 $N$ 總和不超過 $3\times10^5$。

例：`+--+` 可取前綴和 $(1,-2,-1,1)$，對應陣列 $(1,-3,1,2)$，成本為 3；成本 2 做不到。
:::

::: tip 作法
把問題改看成從 $p_0=0$ 出發、**每一步不能停在原地的整數路徑**。本地實作依序判斷以下情況：

| 條件（位置從 1 開始） | 答案 | 原因 |
| --- | --- | --- |
| 第一個字元是 `0`，或出現 `00` | $-1$ | 必有某一步 $a_i=0$ |
| 沒有相鄰的異號非零字元，且所有 `0` 都在偶數位置 | $1$ | $\pm1$ 步長只能在偶數步回到 0，也不能直接跨過 0 換符號 |
| 不符合上列，且出現 `+--+` 或 `-++-` | $3$ | 成本 2 跨號時只能在 $1,-1$ 之間跳，中間兩個同號前綴都被迫為同一值 |
| 其餘 | $2$ | 同號段可安排小幅往返，避開兩步同值的障礙 |

成本 1 的充分性可用同號段的絕對值 $1,2,1,2,\ldots$ 構造。成本 2 的障礙只在「夾於異號之間、長度恰為 2」的同號段：長度 1 或奇數長可用 $1,2,1,\ldots,1$；偶數長至少 4 可用 $1,2,3,1$ 起步，再加兩步往返。

若不想手列所有分支，可以採官方的 **7 狀態 minimax DP**：只保留 $p_i\in[-3,3]$，轉移代價取舊成本與本步距離的最大值。

```cpp
const int inf = 1e9;
array<int, 7> dp = {inf, inf, inf, 0, inf, inf, inf};
for (char sign : s) {
    array<int, 7> next;
    next.fill(inf);
    for (int from = -3; from <= 3; from++) {
        for (int to = -3; to <= 3; to++) {
            char actual = to == 0 ? '0' : (to > 0 ? '+' : '-');
            if (to != from && actual == sign)
                next[to + 3] = min(next[to + 3], max(dp[from + 3], abs(to - from)));
        }
    }
    dp = next;
}
```

最後取 `dp` 最小值，若仍是 `inf` 則無解。有效字串一定能以成本至多 3 構造：每個非零同號段從 $\pm1$ 起，在同號的 $\pm1,\pm2$ 間交替，跨號最多跳 3。因此有限狀態足夠，不需要開到前綴和的 $O(N)$ 值域。兩種寫法都是 $O(N)$；本地分類已與完整可達前綴 DP 對拍長度 1–8 的全部 9,840 種字串。
:::

### [E. Cyclic Balance](https://codeforces.com/contest/2260/problem/E)
`字串` `數學` `構造` `~2300`

::: info 題意
01 字串首尾相接，把相鄰對分成 `00`、`01`、`10`、`11` 四種；四種數量相同時稱為循環平衡。長度 1 的字串也有一對，即自己接回自己。

給定長度 $N\le3\times10^5$ 的字串與 $Q\le3\times10^5$ 個區間，每次**求對子字串最少插入多少字元，才能變成循環平衡**；不能刪除、替換或改變原字元順序。

例：`0011` 的四種相鄰對各一個，成本為 0；`0101` 可插成 `00110011`，成本為 4。
:::

::: tip 作法
令區間長度為 $L$，0、1 的個數為 $c_0,c_1$，循環中的 `01`、`10` 各有 $t$ 個。假設最後四種相鄰對各有 $g$ 個，最終長度就是 $4g$，答案為 $4g-L$。

原本 `00`、`11` 的數量分別是 $c_0-t,c_1-t$。**拆掉一個多餘的同號相鄰對，至少要插入一個異號字元，並新增一組 `01`、`10`。** 官方解法二分最小 $g$，判斷：

$$
\max(0,c_0-t-g)+\max(0,c_1-t-g)+t\le g.
$$

本地實作把這個分段不等式拆成四個下界，得到每次查詢 $O(1)$ 的閉式：

$$
\boxed{g=\max\left(t,\left\lceil\frac{c_0}{2}\right\rceil,
\left\lceil\frac{c_1}{2}\right\rceil,
\left\lceil\frac{L-t}{3}\right\rceil\right).}
$$

這四項分別來自：不拆同號對、只拆 `00`、只拆 `11`、兩類都要拆。等價地，對 $A=c_0-t-g,B=c_1-t-g$ 使用 $\max(0,A)+\max(0,B)=\max(0,A,B,A+B)$，即可一次得到全部下界。

建立 1 的個數前綴和，以及相鄰字元不同的次數前綴和。下面使用 1-based 字串：`ones[i]` 統計 $s_1\ldots s_i$ 的 1；`changes[i]` 統計 $2\le j\le i$ 中 $s_j\ne s_{j-1}$ 的個數。

```cpp
int length = r - l + 1;
int c1 = ones[r] - ones[l - 1];
int c0 = length - c1;
int cross = changes[r] - changes[l];
cross += (s[l] != s[r]);
int t = cross / 2;
int groups = max({t, (c0 + 1) / 2, (c1 + 1) / 2,
                  (length - t + 2) / 3});
cout << 4 * groups - length << '\n';
```

**區間內部的邊從 $l+1$ 才開始，最後再補 $s_r\to s_l$ 的封口邊。** 本地程式多算了左邊界外的一條轉換邊，但完整循環的轉換數一定是偶數，多出的 0 或 1 會被整數除以 2 捨掉，因此不影響答案；文章改用精確的區間計數，避免倚賴這個巧合。單字元時 $t=0,g=1$，答案為 3，也不需特判。

總時間 $O(N+Q)$、空間 $O(N)$。已對照官方可行性判定，並枚舉長度不超過 5 的所有原字串及足夠長的循環平衡超序列核對最少插入數。
:::
