# ABC469 — 學習重點

> A–D 熱身略過(D 為 AtC~1100);收 E、F;G(AtC~2800)超過收錄上限不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc469/editorial)整理,兩題都以暴力對拍過。

### [E. Pro Exam Eligibility](https://atcoder.jp/contests/abc469/tasks/abc469_e)
`二分` `數學` `AtC~1550`

::: info 題意
長 $N$ 的 o/x 字串($N\le10^6$),至少含 $K$ 個 o。選區間 $[l,r]$ 使其中**至少 $K$ 個 o**,**求**該區間勝率(o 的比例)的最大值,誤差 $10^{-6}$。

例:$S=$`oxooxo`、$K=3$:$[1,4]=$`oxoo` 與 $[3,6]=$`ooxo` 都是 $3/4$,整串是 $4/6$。答案 $0.75$。
:::

::: tip 作法
分數規劃:勝率 $\ge p\iff$ 把 o 記 $1-p$、x 記 $-p$ 後區間和 $\ge0\iff$ 前綴和 $S_r\ge S_{l-1}$。固定 $r$,滿足「至少 $K$ 個 o」的 $l$ 是一段前綴 $[1,l_r]$,$l_r$ 隨 $r$ 單調(雙指標),所以只要 $\min_{j<l_r}S_j\le S_r$ 就可行,前綴 min $O(1)$。二分 $p$ 約 50 輪,$O(N\log\frac1\varepsilon)$。另一條路:o、x 換成點 $(1,0)$、$(0,1)$ 的前綴點列,對候選 $l$ 維護上凸包,勝率在凸包上單峰,三分。

```cpp
auto ok = [&](double p) {  // 存在至少 K 勝、勝率 >= p 的區間?
    for (int i = 0; i < N; i++) Sm[i + 1] = Sm[i] + (S[i] == 'o' ? 1 - p : -p);
    int jp = -1;
    double mn = 1e18;
    for (int r = 1; r <= N; r++) {
        while (jp + 1 <= r - 1 && pre[r] - pre[jp + 1] >= K) {
            jp++;
            mn = min(mn, Sm[jp]);
        }  // 合法左端的前綴 min
        if (jp >= 0 && mn <= Sm[r]) return true;
    }
    return false;
};
```
:::

### [F. GCD Maximum Spanning Tree](https://atcoder.jp/contests/abc469/tasks/abc469_f)
`數論` `貪心` `AtC~1550`

::: info 題意
相異正整數 $A_1<\dots<A_N$($N\le2\times10^5$、$A_i\le10^6$),完全圖上邊 $(i,j)$ 的權重是 $\gcd(A_i,A_j)$。**求**最大生成樹的權重和。

例:$A=(2,3,4,6)$:$\gcd$ 只有 $(3,6)=3$、$(2,4)=(2,6)=(4,6)=2$ 兩種非 1 的值。取 $3$-$6$、$2$-$4$、$4$-$6$ → $3+2+2=7$。
:::

::: tip 作法
Kruskal 不能列舉 $N^2$ 條邊,改成**從 $g=\max A$ 往下掃**:每個 $g$ 列舉 $A$ 裡 $g$ 的倍數(反查表),把還沒連通的依序 union,每次成功 union 就加 $g$。正確性:兩個 $g$ 的倍數的 $\gcd$ 若不是 $g$ 就更大,那早在更大的 $g$ 時就連起來了,所以成功的 union 權重恰好是 $g$。列舉倍數是調和級數 $O(V\log V)$,union 恰 $N-1$ 次。

```cpp
for (int g = V; g >= 1; g--) {
    int prev = -1;
    for (int m = g; m <= V; m += g) {  // A 裡 g 的倍數(pos 反查)
        if (pos[m] < 0) continue;
        if (prev >= 0 && dsu.unite(prev, pos[m])) ans += g;  // 成功合併的邊 gcd 恰為 g
        prev = pos[m];
    }
}
```
:::
