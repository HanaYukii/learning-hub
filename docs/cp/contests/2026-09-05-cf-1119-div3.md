### [B. Minus Two](https://codeforces.com/contest/2259/problem/B)
`不變量` `數學` `~900`

::: info 題意
給定 $N\le2\times10^5$ 個正整數 $a_i\le10^9$。每次操作必須對**全部元素同時**套用 $a_i\leftarrow|a_i-2|$。

可以操作任意非負次，**求最終某個數字的最大出現次數**；各測資 $N$ 總和不超過 $2\times10^5$。

例：$(1,3,2,6,4)$ 最後兩類偶數分別在 0、2 之間交換，奇數都停在 1，最多同值的個數為 2。
:::

::: tip 作法
**兩數一旦相等，以後就永遠相等**，所以最大頻率不會隨操作減少，只看長期終態即可。奇數最終全停在 1；偶數最終在 $0\leftrightarrow2$ 震盪，其中原本 $0\bmod4$ 與 $2\bmod4$ 的相位相反，永遠不會合流。

答案就是「奇數、4 的倍數、餘 2 的偶數」三類個數的最大值。時間 $O(N)$、額外空間 $O(1)$。
:::

### [C. 101](https://codeforces.com/contest/2259/problem/C)
`貪心` `掃描線` `構造` `~1300`

::: info 題意
給定長度 $N\le2\times10^5$、元素屬於 $\{-1,0,1\}$ 的陣列，把每個 $-1$ 改成 0 或 1。

一段子陣列若兩端都是 1、中間全是 0，其長度就是候選分數；單獨一個 1 的分數為 1，沒有 1 則為 0。**輸出使最大候選分數最大的完整陣列**；各測資 $N$ 總和不超過 $2\times10^5$。

例：$(-1,0,1,-1,0,0,1)$ 可改成 $(0,0,1,0,0,0,1)$，取最後五格，分數為 5。
:::

::: tip 作法
0 不能當端點，$-1$ 可以當端點或內部，**原本固定的 1 則是不能跨過的內部障礙**。從左往右維護當前最早可用左端點 `left`；遇到非零位置 `i`，先用 `[left,i]` 更新答案，再在 `a[i]==1` 時把 `left` 重設成 `i`。

```cpp
int left = -1, best = 0, ansL = -1, ansR = -1;
for (int i = 0; i < n; i++) {
    if (a[i] == 0) continue;
    if (left == -1) left = i;
    if (i - left + 1 > best) {
        best = i - left + 1;
        ansL = left;
        ansR = i;
    }
    if (a[i] == 1) left = i;
}
```

最後只把最佳區間的未知端點填 1，其餘 $-1$ 全填 0，原本固定值不動。先更新再重設，才能讓固定 1 當前一段的右端點；全零與單一端點也自然涵蓋。時間 $O(N)$。
:::

### [D. MEX Multiset](https://codeforces.com/contest/2259/problem/D)
`構造` `貪心` `~1300`

::: info 題意
把 $3\le N\le2\times10^5$ 個非負整數 $a_i\le10^9$ 分到三個可為空的 multiset $A,B,C$，每個元素恰好放一處。

**判斷並構造**使三個 MEX 的總和至少為最大 MEX 兩倍的分配，輸出 YES/NO 與每個元素所屬的 A/B/C。各測資 $N$ 總和不超過 $2\times10^5$。

例：$(0,0,1,1,2)$ 分成 $A=\{0,1\},B=\{2\},C=\{0,1\}$，MEX 為 $(2,0,2)$，符合條件。
:::

::: tip 作法
若恰好只有一個 0，只有一組 MEX 為正，必定無解。沒有 0 時三組 MEX 都是 0，任意分即可。其餘情況**做出兩組相同 MEX、第三組 MEX 為 0**就夠了。

令 $m$ 為第一個出現次數不足兩次的非負整數。每個 $x<m$ 的第一份丟 A，剩餘份丟 C；所有 $x=m$ 丟 B，其餘丟 C。於是 A、C 都恰好缺 $m$，而 B 沒有 0，三組 MEX 是 $(m,0,m)$。用雜湊表計數，期望時間 $O(N)$。
:::

### [E. Treasure Map Destruction (Constructive Version)](https://codeforces.com/contest/2259/problem/E)
`差分` `構造` `~1700`

::: info 題意
一條直線有 $N\le2\times10^5$ 個位置，至少一處放寶藏。原陣列 $a_i$ 表示位置 $i$ 到最近寶藏的距離 $\min_{j\text{ 有寶藏}}|i-j|$。

給定部分毀損的距離陣列 $b$，$b_i=-1$ 表示未知，其餘介於 0 到 $N-1$。**輸出任一符合所有已知距離的寶藏位置位元字串**，無解則輸出 $-1$；各測資 $N$ 總和不超過 $2\times10^5$。

例：$b=(-1,1,-1,1,-1)$ 可在位置 1、3、5 都放寶藏，得到 `10101`。
:::

::: tip 作法
每個已知正距離 $d=b_i$ 會禁止寶藏出現在 $[i-d+1,i+d-1]$，同時要求距離恰好 $d$ 的端點至少有一處寶藏。**先用差分求禁區聯集，再把所有不被禁止的位置都放寶藏**；多放只會縮短距離，而禁區已排除「過近」，所以這是最容易滿足剩餘要求的候選。

```cpp
vector<int> delta(n + 1), treasure(n);
for (int i = 0; i < n; i++) {
    if (b[i] <= 0) continue;
    int l = max(0, i - b[i] + 1);
    int r = min(n - 1, i + b[i] - 1);
    delta[l]++;
    delta[r + 1]--;
}
for (int i = 0, cover = 0; i < n; i++) {
    cover += delta[i];
    treasure[i] = (cover == 0);
}
```

最後必須驗證：至少一處寶藏；每個已知 $b_i$ 都等於實際最近距離，**包含 $b_i=0$**。如果候選不滿足，刪掉更多寶藏也不可能補出缺少的距離端點。

本地程式用有序位置陣列與二分驗距離，時間 $O(N\log N)$；也可以左右各掃一次取得最近寶藏，把整題降到 $O(N)$。即使某處原本標 0，只要落入其他限制的禁區，也不能跳過矛盾檢查。
:::

### [F. Binary Bubble Sort Inversions](https://codeforces.com/contest/2259/problem/F)
`逆序對` `貢獻` `~1900`

::: info 題意
給定長度 $N\le5\times10^5$ 的 01 陣列與長度同為 $N$ 的操作字串。操作 `1` 從左到右掃相鄰對，把 `10` 交換為 `01`；操作 `0` 則從右到左掃，規則相同。

**輸出初始與每次完整掃描後的逆序對數，共 $N+1$ 個數字**。各測資 $N$ 總和不超過 $5\times10^5$。

例：`1100` 配上操作 `1010`，陣列依序為 `1001 → 0101 → 0011 → 0011`，逆序對為 $4,2,1,0,0$。
:::

::: tip 作法
把每個 0 的貢獻記為「它前面有幾個 1」，得到非遞減陣列 $c$，逆序對總數就是 $\sum c$。**正向掃描等價於移走最左邊的 1，讓所有正貢獻減 1；反向掃描等價於移走最右邊的 0，刪掉最大貢獻。**

略過初始貢獻 0 的項，以 `[l,r]` 維護還有效的貢獻，`offset` 表示已整體減去多少。

```cpp
if (op == '1') {
    inversions -= r - l + 1;
    offset++;
    while (l <= r && c[l] <= offset) l++;
} else if (l <= r) {
    inversions -= c[r] - offset;
    r--;
}
cout << ' ' << inversions;
```

每個貢獻只會被左右指標移除一次，總時間 $O(N)$、空間 $O(N)$。逆序對可達 $\lfloor N^2/4\rfloor$，使用 64 位元。
:::

### [G. Index Removal](https://codeforces.com/contest/2259/problem/G)
`貪心` `二分` `貢獻` `~1900`

::: info 題意
給定原本非遞減的陣列 $a$，且相鄰差不超過 $k$；$2\le N\le2\times10^5$，$1\le a_i,k\le10^9$。

對每個位置 $i$ **獨立刪除 $a_i$**，之後只能把任一元素減 1。**求恢復非遞減且相鄰差不超過 $k$ 的最少操作次數**，輸出 $N$ 個答案；各測資 $N$ 總和不超過 $2\times10^5$。

例：$a=(1,3,5,7),k=2$，刪掉 3 後得到 $(1,5,7)$，需改成 $(1,3,5)$，總共減 4；刪端點則不用調整。
:::

::: tip 作法
刪除內部位置 $i$ 只會讓 $a_{i-1}$ 到 $a_{i+1}$ 的間隙可能過大。左邊不動，右邊逐項取可行的最大值；降低左邊只會讓右邊的上界更低。對 $j>i$，所需減量為

$$\max\bigl(0,a_j-a_{i-1}-(j-i)k\bigr).$$

定義 $P_1=0$、$P_j=P_{j-1}+k-(a_j-a_{j-1})$。原本每個相鄰差都不超過 $k$，所以 **$P$ 非遞減；減量變成 $\max(0,P_{i-1}+k-P_j)$**。二分第一個 $P_j\ge P_{i-1}+k$ 的位置，再用 $P$ 的前綴和一次算完正減量。

```cpp
// a、p、prefix 均為 1-based，prefix[j] = p[1] + ... + p[j]。
for (int i = 2; i < n; i++) {
    long long target = p[i - 1] + k;
    int r = lower_bound(p.begin() + i + 1, p.begin() + n + 1,
                        target) - p.begin();
    long long count = r - i - 1;
    answer[i] = count * target - (prefix[r - 1] - prefix[i]);
}
```

端點答案為 0，時間 $O(N\log N)$、空間 $O(N)$。`p`、前綴和及乘法都要用 64 位元；二分範圍從刪除位置的下一項開始，避免把刪掉的元素算入成本。
:::
