# ABC478 — 學習重點

> A–D 熱身略過;收 E、F;G(AtC~2600)超過收錄上限不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc478/editorial)整理,E 以枚舉所有序列對拍、F 以 Prüfer 序列枚舉全部帶標號樹對拍。

### [E. lt and le](https://atcoder.jp/contests/abc478/tasks/abc478_e)
`圖論` `構造` `AtC~1400`

::: info 題意
長 $N$、值域 $[1,N]$ 的序列 $A$,$Q$ 條約束 $A_u\le A_v$ 或 $A_u<A_v$($N,Q\le2\times10^5$)。**判定**是否存在並**構造**一組。

例:$A_1\le A_2$、$A_2\le A_1$、$A_1<A_2$:前兩條逼 $A_1=A_2$,第三條矛盾 → No。
:::

::: tip 作法
把兩種約束都當有向邊 $u\to v$。**同一個 SCC 裡的點必須相等**(互相可達 ⟹ $\le$ 雙向)。所以 SCC 內若有一條 $<$ 邊 → No;否則把 SCC 依拓撲序編號 $1,2,\dots$ 當作值:跨 SCC 的邊都從編號小指到編號大,$\le$ 與 $<$ 同時成立。$O(N+Q)$。

```cpp
// Tarjan 先完成的 SCC 是 sink,所以 comp 編號反過來就是拓撲序
for (int v = 0; v < N; v++) ans[v] = numSCC - comp[v];  // 值域 [1, numSCC] ⊆ [1, N]
for (auto [t, u, v] : cons)
    if (t == 1 && ans[u] == ans[v]) return No;  // 嚴格邊落在同一 SCC
```
:::

### [F. Min-First Search](https://atcoder.jp/contests/abc478/tasks/abc478_f)
`組合計數` `貪心` `AtC~1600`

::: info 題意
對 $N$ 點樹 $T$,$f(T)$ 是這樣得到的排列:$S=\{1\}$,每次取出 $S$ 的最小值接到 $P$ 後面,再把它的鄰居中還沒進 $P$ 的丟進 $S$。給排列 $Q$($Q_1=1$),**數**有幾棵樹 $f(T)=Q$,mod $998244353$。

例:$Q=(1,3,2,5,4)$:$2$ 的父節點只能是 $3$(若接在 $1$ 下,取完 $1$ 後 $S$ 同時有 $2,3$,會先取 $2$);$5$ 可接在 $1,3,2$ 任一個下;$4$ 只能接 $5$ → $1\cdot1\cdot3\cdot1=3$ 棵。
:::

::: tip 作法
以 $1$ 為根。若 $u>v$ 且 $u$ 在 $P$ 裡排在 $v$ 前面,那在 $p_v$ 進 $P$ 之前 $u$ 就得被取走,否則 $v$ 會先被選。翻成條件:令 $m_i$ = 最大的 $j<i$ 使 $Q_j>Q_i$(沒有則 $0$),則 **$Q_i$ 的父節點必須是 $Q_{m_i},\dots,Q_{i-1}$ 之一**;反過來這樣選父節點就一定得到 $Q$。各 $i$ 的選擇互不干涉,答案 $\prod_{i\ge2}(i-m_i)$。$m_i$ 用「跳 $m$ 鏈」$O(N)$ 求(與單調堆疊等價)。

```cpp
long long ans = 1;
vector<int> pg(N, 0);  // pg[i] = 前一個更大者的位置(沒有則 0)
for (int i = 1; i < N; i++) {
    int p = i - 1;
    while (p && Q[p] < Q[i]) p = pg[p];  // 沿 pg 鏈往前跳,整體 O(N)
    pg[i] = p;
    ans = ans * (i - p) % MOD;  // 父節點可選 Q[p..i-1]
}
```
