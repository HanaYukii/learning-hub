> 懶人包:每題「**題意 + 核心作法**」。收 A–D;E1/E2(歷史最大子段和的 lazy tag)、F(NTT 加二階遞推)都在 ~2900 以上,不收。難度 `~` 為官方 rating。作法依[官方題解全文](https://codeforces.com/blog/entry/155840)整理;A 對過全部樣例,B、D 以暴力對拍,C 用隨機圖與隨機變換模擬兩次執行驗過。

### [A. Hot Potatoes at the Fairy Warehouse](https://codeforces.com/contest/2255/problem/A)
`博弈` `貪心` `~1200`

::: info 題意
$2n$ 人圍成圈,奇數號紅隊、偶數號藍隊,$s_i=1$ 的人一開始拿著馬鈴薯。$k$ 回合,每回合所有持有者**同時**決定留著或傳給順時針下一位,但只有「回合開始時下一位手上沒有」才能傳。結束後手上有馬鈴薯的人出局,對方隊伍得一分。**求**雙方最佳策略下兩隊得分。$n\le10^5$、$k\le10^9$。

例:$n=2$、$s=$`1000`:1 號傳給 2 號,藍隊 2 號出局 → 紅 1、藍 0。$s=$`0011`:4 號傳給 1 號,3 號被 4 號擋住傳不了 → 紅 0、藍 2。
:::

::: tip 作法
零和,總分固定是馬鈴薯數。把 `1` 切成極大連續段,每段只有**最後一顆**動得了。早傳沒好處:傳出去後空出的位置讓對方的前一顆能動,對方下一回合就能把這分抵回來——所以每段最後一顆都等到最後一回合才傳,$k$ 的大小無關;整圈全滿則沒人能動。掃一圈:$s_i=1,s_{i+1}=0$ → $i$ 的隊伍得分;$s_i=s_{i+1}=1$ → 對方得分。$O(n)$。
:::

### [B. A Ribbon for Tomorrow](https://codeforces.com/contest/2255/problem/B)
`組合計數` `不變量` `~1600`

::: info 題意
01 字串($n\le10^6$),操作:選 $s_l=s_r$ 的 $l\le r$,翻轉 $[l,r]$。**求**能得到幾種相異字串,mod $998244353$。

例:`00110` 只有 `00110`、`01100` 兩種;`001010` 有 `001010`、`010010`、`010100` 三種。
:::

::: tip 作法
兩端字元相同的翻轉不改變**極大同色段的段數**(內部相鄰關係只是反過來,兩端的邊界字元不動),也不改變第一個字元,所以段的顏色順序完全固定。反過來任何「各色段長的正整數分配」都到得了:在 $x^a\,y^b\,x^c$ 裡各取兩個 $x$ 段的一端翻轉,可以把 $a+c$ 任意重分配。所以答案 $=\binom{\text{cnt}_0-1}{\text{seg}_0-1}\binom{\text{cnt}_1-1}{\text{seg}_1-1}$,某色不存在就當 $1$。$O(n)$。
:::

### [C. Even If the World Turns](https://codeforces.com/contest/2255/problem/C)
`數論` `構造` `互動` `~2100`

::: info 題意
run-twice 題。$n\times n$ 黑白圖(黑格數 $w$ 與 $n$ 互質)與目標格 $x$。第一次執行(Chtholly)看到圖與 $x$,**交換兩格的顏色**(可同一格)。接著裁判對圖做任意次循環平移、旋轉 $90^\circ$、左右翻轉、黑白反轉($x$ 跟著移動,反轉不動它)。第二次執行(Willem)只看到變換後的圖,**要答出** $x$ 現在的位置。$n\le800$。

例:$n=2$、只有 $(1,1)$ 是黑($w=1$)、$x=(2,2)$:Chtholly 把黑格搬到 $(2,2)$;之後不管怎麼轉、怎麼反色,Willem 算出的「質心」就是那個黑格,也就是 $x$。
:::

::: tip 作法
座標當 $\mathbb Z_n$。令 $S$ 為黑格座標和、$C=w^{-1}S$:平移 $d$ 讓 $S$ 變 $S+wd$,$C$ 變 $C+d$,**跟一個普通格子一樣動**;旋轉、翻轉是仿射映射 $p\mapsto Mp+t$,$C$ 同樣變成 $MC+t$;黑白反轉時 $w'\equiv-w$、$S'=-S$(整張圖的座標和 $\equiv0$),$C$ 不變。所以 $C$ 是一個「跟著圖走」的虛擬格子。

Chtholly 只要讓 $C=x$:需要 $S$ 增加 $\delta=wx-S$,找一個黑格 $p$ 使 $p+\delta$ 是白格,交換。存在性:否則黑格集合在平移 $\delta$ 下不變,每條軌道長度 $L>1$ 且 $L\mid n$、$L\mid w$,與互質矛盾。Willem 重算 $w,S$ 輸出 $w^{-1}S$;逆元 $n\le800$ 暴力找就好。$O(n^2)$。

```cpp
// 第一次:delta = w * x - S (mod n);找黑格 p 使 p + delta 是白格,交換兩者
for (int r = 0; r < n && !done; r++)
    for (int c = 0; c < n && !done; c++)
        if (g[r][c] == '#' && g[(r + dr) % n][(c + dc) % n] == '.') {
            swap(...);
            done = true;
        }
// 第二次:重算 w、S,答 (w^{-1} S_r, w^{-1} S_c) mod n(再 +1 轉回 1-indexed)
```
:::

### [D. How Long Until Nothing Remains?](https://codeforces.com/contest/2255/problem/D)
`貪心` `二分` `位元` `~2300`

::: info 題意
$n$ 個正整數($\le10^9$),每秒選一個 $p$:$a_p\leftarrow\lfloor a_p/2\rfloor$,其他全部 $\leftarrow\lceil a_i/2\rceil$。**求**全部變 $0$ 的最少秒數。

例:$[5,2]$:選 1 得 $[2,1]$、選 2 得 $[1,0]$、選 1 得 $[0,0]$ → 3。$[1,1,1]$:$1$ 只有被選到那秒才會變 $0$,所以 3。
:::

::: tip 作法
固定每秒選誰,倒著看單一位置:若 $T$ 秒後能歸零的值上界是 $x$,往前一步「被選」允許 $y\le2x+1$、「沒被選」允許 $y\le2x$。展開後,位置 $i$ 在被選的秒數集合 $S$ 下能歸零 $\iff a_i\le\sum_{s\in S}2^{s-1}$——問題變成**把容量 $1,2,4,\dots,2^{T-1}$ 分給各個需求**,每個需求拿到的總和 $\ge a_i$。

可行性貪心:容量從大到小,看目前最大的剩餘需求 $x$:$x>p$ 時 $p$ 必須給 $x$(更小的容量全加起來只有 $p-1$);否則讓 $p$ 直接把 $x$ 做完(交換論證)。每個正數至少被選一次 → $T\ge n$;$a_i<2^{30}$ → $T=n+30$ 必夠,二分 $T$。$\ge2^{30}$ 的容量各自解決一個最大的需求,剩下至多 30 個需求用 heap 模擬 $2^{29},\dots,1$。$O(n\log n)$。

```cpp
bool check(vector<long long> a, int T) {  // 容量 2^0..2^{T-1}
    sort(a.rbegin(), a.rend());
    int big = max(0, T - 30);  // >= 2^30 的容量:各自解決一個最大的需求
    priority_queue<long long> pq;
    for (int i = big; i < (int)a.size(); i++) pq.push(a[i]);
    for (int e = min(T, 30) - 1; e >= 0 && !pq.empty(); e--) {
        long long p = 1LL << e, x = pq.top();
        pq.pop();
        if (x > p) pq.push(x - p);  // 更小的容量全加起來只有 p-1,p 只能給它
    }
    return pq.empty();
}
```
:::
