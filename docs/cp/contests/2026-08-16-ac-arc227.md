# ARC227 — 學習重點

> 收 A–D;E(AtC~2700)、F 超過收錄上限不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/arc227/editorial)整理,四題都以暴力對拍過(A 用 BFS 算真實交換距離、C 用狀態 BFS 驗最小島數與構造、D 用多數決閉包)。

### [A. Fermat Point of Binary Strings](https://atcoder.jp/contests/arc227/tasks/arc227_a)
`數學` `AtC~600`

::: info 題意
長 $2N$、含 $N$ 個 `0` 與 $N$ 個 `1` 的字串稱為 good;$\operatorname{dist}(S,T)$ 是用相鄰交換把 $S$ 變成 $T$ 的最少次數。給三個 good 字串 $A,B,C$,**求** good 的 $X$ 使 $\operatorname{dist}(A,X)+\operatorname{dist}(B,X)+\operatorname{dist}(C,X)$ 最小,輸出最小值與 $X$。$N\le2\times10^5$。

例:$A=$`1100`、$B=$`1010`、$C=$`0011`:`1` 的位置分別是 $(1,2),(1,3),(3,4)$,逐項取中位數得 $(1,3)$ → $X=$`1010`,總距離 $1+0+3=4$。
:::

::: tip 作法
相鄰交換只會讓某個 `1` 移一格,而 `1` 之間不會互相跨越,所以 $\operatorname{dist}(S,T)=\sum_i|p_i-q_i|$($p,q$ 是兩串第 $i$ 個 `1` 的位置)。三個序列**逐項取中位數**就是一維 Fermat 點;三個嚴格遞增序列逐項取中位數仍嚴格遞增,所以自動是 good 字串,最優解唯一。$O(N)$。
:::

### [B. Know Your Place](https://atcoder.jp/contests/arc227/tasks/arc227_b)
`貪心` `構造` `AtC~1050`

::: info 題意
給 $A$($N\le5\times10^5$、$0\le A_i<N$)。**求** $A$ 的一個排列 $B$,使每個 $i$ 都有 $B_i=\#\{j<i:B_j<B_i\}$;不存在輸出 No。

例:$A=(0,0,1,2)$:長度 $0$ 時放 $0$(另一個 $0$ 壓進 stack)、長度 $1$ 放 $1$、長度 $2$ 放 $2$、長度 $3$ 沒有 $3$,從 stack 拿 $0$ → $B=(0,1,2,0)$,最後那個 $0$ 前面確實沒有比它小的。
:::

::: tip 作法
從前往後決定 $B$。某個值 $v$ **第一次**出現只能在長度恰為 $v$ 時放(前面 $v$ 個全都比它小);同值的其餘副本先壓進 stack,之後任何時候都能放——中間放進來的值都比它大(不是當時的長度就是更晚壓進去、更大的值),不會改變「前面比它小的個數」。所以貪心:長度 $L$ 時有 $L$ 就放 $L$(其餘 $L$ 壓 stack),否則彈 stack 頂,兩者都沒有就 No。等價於「有解 $\iff$ 每個 $A_i$ 至少有 $A_i$ 個更小的元素」,而且解唯一。$O(N)$。

```cpp
vector<int> B, st;  // st:已經出現過、還沒放完的值(由小到大壓入)
while ((int)B.size() < N) {
    int L = B.size();
    if (C[L] > 0) {  // 值 L 第一次出現,只能現在放
        B.push_back(L);
        for (int k = 1; k < C[L]; k++) st.push_back(L);
        C[L] = 0;
    } else if (!st.empty()) {
        B.push_back(st.back());
        st.pop_back();
    } else
        return No;
}
```
:::

### [C. Follow the Letters](https://atcoder.jp/contests/arc227/tasks/arc227_c)
`不變量` `字串` `構造` `AtC~2100`

::: info 題意
$N$ 座島環狀排列($N\le1000$),島 $i$ 寫著字母 $S_i$,每島一人。一次操作選一個出現過的字母 $c$:所有人同時出發順時針走,直到抵達**下一座**寫著 $c$ 的島(自己站的島是 $c$ 也要出發)。**求**最終有人的島數最小值 $K$,並輸出達成它的操作序列(長度 $\le10^6$)。

例:$S=$`abcdabcdabcd`:循環移位 $0,4,8$ 都得到自己,$K=3$。島 $1,5,9$ 的人每次走的距離相同,永遠隔 4 座島;做一次 `abcd` 之後,島 $1$–$4$ 的人都走到 $8$、$5$–$8$ 到 $12$、$9$–$12$ 到 $4$,剛好 3 座。
:::

::: tip 作法
**$K$ = 讓 $S$ 循環移位後仍等於 $S$ 的位移數**($=N/\text{最小週期}$)。下界:相差一個週期的兩個人看到的環一模一樣,每次走的距離相同,永遠合不起來。

上界構造:把 $S$ 本身當操作序列,**重複 $N$ 次**。做一輪 $S$ 時,站在週期末尾那些島的人剛好繞一圈回到原位,其他人至少前進 $N+1$ 格;而且**沒有人會超車**(同時出發、同樣的停止規則)。所以每輪至少有一個人被追齊,$N$ 輪後全部集中在週期末尾的島。長度 $N^2\le10^6$。官方另提到最短操作序列可以 $O(26N^2)$ 求出,而 $\Omega(N^2)$ 的例子存在。

```cpp
int K = 0;
for (int d = 0; d < N; d++) {  // 位移 d 後仍是 S 的個數
    bool same = true;
    for (int j = 0; j < N && same; j++) same = S[j] == S[(j + d) % N];
    K += same;
}
// 輸出 K、N*N,以及 S 重複 N 次
```
:::

### [D. Median of Binary Strings](https://atcoder.jp/contests/arc227/tasks/arc227_d)
`分類討論` `構造` `AtC~2300`

::: info 題意
黑板上有 $N$ 個長 $M$ 的 01 字串($N,M\le500$)。操作:任選三個(可重複)$A,B,C$,寫下**逐位取多數決**的 $D$。$Q\le500$ 個詢問:字串 $T$ 能不能被寫出來。

例:$S=\{$`110`,`011`,`101`$\}$:$T=$`111` 每一對位置都有某個 $S$ 同時符合,三個一起取多數決就出來;$T=$`000` 在位置 $(1,2)$ 需要 `00`,沒有任何 $S$ 符合 → No。
:::

::: tip 作法
必要條件:**對每一對位置 $(i,j)$,存在某個 $S$ 在這兩位上跟 $T$ 一樣**——湊 $T_i,T_j$ 時三個字串裡至少兩個在位 $i$ 對、至少兩個在位 $j$ 對,鴿籠給出一個同時對的;多數決不會創造出原本沒有的位置對,所以條件往上傳遞。

**這也是充分的**:歸納做出「前 $k$ 位都對」的字串——要前 $k+1$ 位對,拿「前 $k$ 位對」「前 $k-1$ 位加第 $k+1$ 位對」「前 $k-2$ 位加最後兩位對」三個(各自遞迴可得)取多數決,每一位都至少兩個對。預處理每對位置出現過的 $(T_i,T_j)$ 組合 $O(NM^2)$,每個詢問 $O(M^2)$。

```cpp
// ok[i][j][bi][bj]:有沒有某個 S 在位置 i、j 分別是 bi、bj
for (auto& s : S)
    for (int i = 0; i < M; i++)
        for (int j = i; j < M; j++) ok[i][j][s[i] - '0'][s[j] - '0'] = true;
// 詢問:所有 i <= j 都要 ok[i][j][t[i]-'0'][t[j]-'0']
```
:::
