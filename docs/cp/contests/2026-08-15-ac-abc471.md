# ABC471 — 學習重點

> A–E 熱身略過(E 為 AtC~1000);只收 F;G(AtC~2450)超過收錄上限不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc471/editorial)整理,以枚舉子集與排列的暴力對拍過。

### [F. Concat (maximize)](https://atcoder.jp/contests/abc471/tasks/abc471_f)
`貪心` `字串` `分類討論` `AtC~1900`

::: info 題意
$N$ 個數字字串($N\le10^5$、長度 $\le10$,可能有前導零),恰選 $K$ 個、任意順序接起來,**求**能得到的最大整數(去掉前導零後比較)。

例:$S=\{$`05`,`04`,`9`$\}$、$K=2$:照(長度, 數值)排序前兩名是 `05`、`04`,最好接成 `0504`$=504$;但把第二名換成剩下數值最大的 `9`,`9`+`05`$=905$ 更大。前導零讓「長度優先」不再等於「數值優先」,這就是要多看第二種候選的原因。
:::

::: tip 作法
分兩層。**選定 $K$ 個之後怎麼接**:總長固定,所以最大整數等於字典序最大,用比較子 $a+b>b+a$ 排序即可(它是全序:等價於比 $\frac{\mathrm{INT}(a)}{10^{|a|}-1}$)。**選哪 $K$ 個**:把 $S$ 依(長度, 數值)降序排好,答案只可能是**前 $K$ 個**,或**前 $K-1$ 個加上其餘裡數值最大的那一個**——固定放最前面的 $S_x$,後面接的 $T$ 貢獻 $\mathrm{INT}(S_x)\cdot10^{|T|}+\mathrm{INT}(T)$,所以 $T$ 一定取長度優先、數值其次的前幾名;$x$ 若不在前 $K$ 名,剩下的 $K-1$ 個就是前 $K-1$ 名,$x$ 則取數值最大者。兩種候選各 $O(NL\log N)$。

```cpp
sort(S.begin(), S.end(), [](auto& a, auto& b) { return a.size() != b.size() ? a.size() > b.size() : INT(a) > INT(b); });
auto build = [](vector<string> v) {  // 選定集合後:a+b > b+a 排序再接
    sort(v.begin(), v.end(), [](auto& a, auto& b) { return a + b > b + a; });
    string r;
    for (auto& s : v) r += s;
    return stripLeadingZeros(r);
};
string best = build({S.begin(), S.begin() + K});  // 候選 1:前 K 名
if (K < N) {                                      // 候選 2:前 K-1 名 + 其餘裡數值最大者
    vector<string> c2(S.begin(), S.begin() + K - 1);
    int bi = K - 1;
    for (int i = K; i < N; i++)
        if (INT(S[i]) > INT(S[bi])) bi = i;
    c2.push_back(S[bi]);
    best = maxNum(best, build(c2));
}
```
:::
