# ARC230 — 學習重點

> 這場是 ARC++(加難場):只收 A;B(AtC~2650)、C、E 超過上限,D(AtC~2400,容斥 + Lagrange 插值)也略高且非模板,不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/arc230/editorial)整理,A 以枚舉所有子集與會場對拍過。

### [A. Meeting on Tree](https://atcoder.jp/contests/arc230/tasks/arc230_a)
`樹` `組合計數` `貢獻` `AtC~900`

::: info 題意
$N$ 點樹($N\le3\times10^5$),每點一隻松鼠。選一個非空子集開會,會場任選一點,費用 = 被選松鼠到會場的距離和(取最小)。**求**所有 $2^N-1$ 個子集的最小費用總和 mod $998244353$。

例:兩點一邊:單點子集費用 $0$,$\{1,2\}$ 費用 $1$ → 1。公式:$2^{1}\cdot1-G(1)=2-1=1$($G(1)=\sum_{d\le1}(1-d)\binom2d=1$)。
:::

::: tip 作法
固定子集後,把每條邊**指向被選松鼠較多的那一側**(相等不指),從根沿有向邊走到底就是最佳會場;最小費用 $=$(在根開會的費用)$-\sum_{\text{走過的邊}}(b-a)$,$b,a$ 是遠側、近側的被選數。對所有子集加總:第一項 $2^{N-1}\sum_v\text{dep}_v$;第二項按邊算,遠側子樹大小 $s$ 時貢獻

$$\sum_{0\le a<b}\binom{s}{b}\binom{N-s}{a}(b-a)=\sum_{d=0}^{s}(s-d)\binom{N}{d}$$

(Vandermonde 把 $\binom sb\binom{N-s}a$ 收成 $\binom N{\cdot}$),對 $\binom Nd$ 做兩次前綴和就能查所有 $s$。$O(N)$。

```cpp
for (int d = 0; d <= N; d++) P1[d] = (d ? P1[d - 1] : 0) + C(N, d);  // 二項式前綴和
for (int s = 1; s <= N; s++) G[s] = G[s - 1] + P1[s - 1];            // G[s] = Σ_d (s-d) C(N,d)
for (int v = 1; v <= N; v++) {
    A += dep[v];
    if (v != root) B += G[sz[v]];
}
ans = pow2(N - 1) * A - B;
```
