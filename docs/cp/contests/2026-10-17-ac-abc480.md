### [E. Product-Bounded Arithmetic Sequences](https://atcoder.jp/contests/abc480/tasks/abc480_e)
`數學` `二分` `AtC~1350`

::: info 題意
正整數等差數列,長度 $\ge3$、公差 $>0$,全部元素乘積 $\le N$($N\le10^{18}$)。**求**這種數列的個數。

例:$N=60$:首項 $1$ 長 $3$ 有公差 $1..4$(乘積 $6,15,28,45$)、長 $4$ 只有 $(1,2,3,4)$;首項 $2$ 長 $3$ 有公差 $1,2$;首項 $3$ 有 $(3,4,5)$ → 8。
:::

::: tip 作法
乘積對公差單調,所以**枚舉首項 $a$ 與長度 $m$,二分最大公差**。首項 $a\le N^{1/3}$(三項至少 $a^3$),長度 $m$ 受 $m!\le N$ 限制只有 $O(\log N)$ 種,整體 $O(N^{1/3}\log^2N)$。判「乘積 $\le N$」用 $N$ 連續整除各項、看有沒有變 $0$,避免溢位。

```cpp
for (long long a = 1; a * (a + 1) * (a + 2) <= N; a++)
    for (int m = 3;; m++) {
        long long s = N;
        for (int i = 0; i < m && s; i++) s /= (a + i);  // 公差 1 都放不下就停
        if (!s) break;
        long long lo = 1, hi = N;  // 二分最大公差
        while (lo < hi) {
            long long mid = lo + (hi - lo + 1) / 2, t = N;
            for (int i = 0; i < m && t; i++) t /= (a + i * mid);
            if (t)
                lo = mid;
            else
                hi = mid - 1;
        }
        ans += lo;
    }
```
:::

### [F. Cake Cutting](https://atcoder.jp/contests/abc480/tasks/abc480_f)
`狀壓` `dp` `AtC~1850`

::: info 題意
$N\le20$ 塊蛋糕(大小 $A_i$)分給 $M\le100$ 人,總和 $S$ 是 $M$ 的倍數。一次操作把一塊切成兩塊(大小任意實數)。**求**最少切幾次,使每人拿到的總大小恰為 $S/M$。

例:$A=(3,3,2)$、$M=2$,每人 $4$:排成 $3,3,2$ 倒進容量 $4$ 的桶,第一桶在第二塊中間滿 → 切 1 次;沒有不切的分法(只有全部才是 $4$ 的倍數)→ 1。
:::

::: tip 作法
令 $T=S/M$,$f(A)$ = 把蛋糕分成最多幾組、每組和是 $T$ 的倍數。**答案 $=M-f(A)$**:一次切割最多讓 $f$ 增加 $1$(新的兩塊同組就合回去;不同組就把兩組併成一組),達成目標時 $f=M$,所以至少切 $M-f(A)$ 次;反過來每組排成一列、在 $T$ 的倍數處切開,恰好切 $M-f(A)$ 次。$f$ 用子集 DP:$W[\text{mask}]$ = 子集和 mod $T$(由 mask 唯一決定,不用進狀態),$dp[\text{mask}]$ = 最多組數,加入一個元素時若 $W$ 歸零就多一組。$O(N2^N)$。

```cpp
for (int s = 0; s < (1 << N); s++)
    for (int k = 0; k < N; k++)
        if (!(s >> k & 1)) {
            int t = s | 1 << k;
            W[t] = (W[s] + A[k]) % T;                 // 子集和 mod T 由 mask 決定
            dp[t] = max(dp[t], dp[s] + (W[t] == 0));  // 歸零 → 多一組
        }
return M - dp[(1 << N) - 1];
```

### [G. Zonal Score Minimization](https://atcoder.jp/contests/abc480/tasks/abc480_g)
`dp` `線段樹` `AtC~2100`

::: info 題意
長 $N$ 的正整數序列($N\le2\times10^5$),切成若干段、每段長 $\ge2$,每段得分是段內 max $-$ min。**求**總分最小值。

例:$A=(1,5,2,4)$:整段 $5-1=4$;$(1,5)+(2,4)=4+2=6$ → 4。
:::

::: tip 作法
$dp_i=\min_{j\le i-2}\bigl(dp_j+\max A[j{+}1..i]-\min A[j{+}1..i]\bigr)$。線段樹第 $j$ 格存目前的 $dp_j+\max-\min$;$i$ 往右推一格時,**$\max A[j{+}1..i]$ 隨 $j$ 單調,用單調堆疊存等值區間**:新的 $A_i$ 把堆疊頂端所有 $\max\le A_i$ 的區間吃掉,每吃一個就對那段 $j$ 區間加上 $A_i-\text{舊 max}$;$\min$ 鏡像處理。每個 $i$ 只推入一個區間,總共 $O(N)$ 次區間加,配區間 min 查詢 $O(N\log N)$。

```cpp
for (int i = 1; i <= N; i++) {
    int nl = i - 1;  // 新區間 [nl, i-1],max = A[i]
    while (!mxs.empty() && mxs.back().v <= A[i]) {
        auto t = mxs.back();
        mxs.pop_back();
        seg.add(t.l, t.r, A[i] - t.v);
        nl = t.l;
    }
    mxs.push_back({A[i], nl, i - 1});
    nl = i - 1;  // min 鏡像:值變小,-min 變大
    while (!mns.empty() && mns.back().v >= A[i]) {
        auto t = mns.back();
        mns.pop_back();
        seg.add(t.l, t.r, t.v - A[i]);
        nl = t.l;
    }
    mns.push_back({A[i], nl, i - 1});
    long long dpi = (i >= 2) ? seg.min(0, i - 2) : INF;  // 段長 >= 2
    seg.set(i, dpi);                                     // 之後它會被當作 j 用
}
```
