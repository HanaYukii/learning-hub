# ABC473 — 學習重點

> A–E 熱身略過(E 為 AtC~950);收 F、G。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc473/editorial)整理,F 的判準對長度 $\le7$ 的所有字串枚舉驗過,G 對 $N\le6$ 的全部排列對拍過。

### [F. A/AB Insertion](https://atcoder.jp/contests/abc473/tasks/abc473_f)
`字串` `線段樹` `不變量` `AtC~1300`

::: info 題意
長 $N$ 的 A/B 字串($N\le5\times10^5$),$Q\le2\times10^5$ 個操作:單點改字元;或問子串 $T=S[l..r]$ 能否由空字串反覆「任意位置插入 `A`」或「插入 `AB`」得到。

例:`AAB` 可以(先 `A` 再插 `AB`);`ABB` 不行(第二個 `B` 沒有 `A` 可配);`BA` 不行。
:::

::: tip 作法
`A` 記 $+1$、`B` 記 $-1$。插入 `A` 或 `AB` 都不會讓任何前綴和變負;反過來**前綴和全非負就一定做得到**——倒著想成刪除:第一個 `B` 前面全是 `A`,刪掉那組 `AB` 不影響其他前綴和,重複到只剩 `A`,再逐個刪掉。所以判定就是「區間內相對前綴和的最小值 $\ge0$」,即 $\min(\text{pre}[l..r])\ge\text{pre}[l-1]$;單點改字元 = 後綴前綴和整段 $\pm2$,lazy segment tree 區間加、區間 min,$O((N+Q)\log N)$。也可以用普通線段樹存 (區間和, 區間最小前綴和) 合併。

```cpp
// seg:前綴和 pre[0..N] 的 lazy segtree(區間加、區間 min)
// 改字元:seg.apply(i + 1, N + 1, ±2);查詢 [l, r](1-indexed):
if (seg.prod(l - 1, r + 1) == seg.get(l - 1))
    puts("Yes");
else
    puts("No");  // 區間內最小前綴和不低於起點
```
:::

### [G. Wipeout](https://atcoder.jp/contests/abc473/tasks/abc473_g)
`機率期望` `多項式` `NTT` `AtC~1950`

::: info 題意
$N$ 張牌背面朝上排一列,寫著 $1..N$ 的均勻隨機排列。$x$ 從 $1$ 開始:每次翻一張牌,是 $x$ 就吃掉、$x$ 加一,否則蓋回去(但記得它的值)。你採取讓期望操作數最小的策略,**求**總操作數恰為 $K$ 的機率 mod $998244353$($N\le5\times10^5$、$N\le K\le10^9$)。

例:$N=2$:翻第一張,是 $1$(機率 $1/2$)就再翻另一張,共 2 次;是 $2$ 就先翻另一張吃掉 $1$、再翻回已知的 $2$,共 3 次。$K=2,3$ 各 $1/2$;公式 $\frac{(0x+1)(1x+1)}{2!}=\frac{1+x}2$ ✓。
:::

::: tip 作法
最優策略很單純:$x$ 的位置已知就翻它(必吃),否則隨便翻一張未知牌。操作數 $=N$(每張各吃一次)$+$「翻未知牌卻不是當下的 $x$」的次數。剩 $k$ 張未知牌時,翻一張未知牌剛好是 $x$ 的機率是 $1/k$,**跟已知了哪些牌無關**;而照這個策略走,每個 $k=N,\dots,1$ 都恰好經歷一次「未知牌剩 $k$ 張」的狀態。所以多餘次數的生成函數是

$$\prod_{k=1}^{N}\Bigl(\frac{k-1}{k}x+\frac1k\Bigr),\qquad\text{答案}=[x^{K-N}]\ (K>2N\text{ 直接 }0)$$

乘上 $N!$ 就是 $\prod_{k=1}^N((k-1)x+1)$,$N$ 個一次式的積用分治 + NTT,$O(N\log^2N)$(係數其實是第一類 Stirling 數)。

```cpp
if (K > 2 * N) return 0;
queue<Poly> q;
for (int k = 1; k <= N; k++) q.push({1, k - 1});  // (k-1) x + 1
while (q.size() >= 2) {                           // 分治乘:每次拿兩個最小的相乘丟回去
    auto a = q.front();
    q.pop();
    auto b = q.front();
    q.pop();
    q.push(convolution(a, b));
}
return q.front()[K - N] / fact(N);
```
:::
