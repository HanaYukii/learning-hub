# ABC476 — 學習重點

> A–E 熱身略過(E 為 AtC~950);只收 F;G(AtC~2500)超過收錄上限不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc476/editorial)整理,F 用與官方不同的旋轉座標寫法,以 $O(N^4)$ 暴力對拍過。

### [F. Chebyshev Cafe](https://atcoder.jp/contests/abc476/tasks/abc476_f)
`幾何` `數學` `差分` `AtC~1750`

::: info 題意
$N\times N$ 格子($N\le1500$),格 $(i,j)$ 住著 $(A_iB_j)\bmod M$ 個人。一個人從 $(s_r,s_c)$ 到 $(t_r,t_c)$ 的費用是 **Chebyshev 距離** $\max(|s_r-t_r|,|s_c-t_c|)$。$f(i,j)$ = 全部人集合到 $(i,j)$ 的總費用。**輸出**所有 $f(i,j)+(i-1)N+(j-1)$ 的 XOR。

例:位移 $(3,1)$ 的 Chebyshev 距離是 $3$;$(|3+1|+|3-1|)/2=(4+2)/2=3$ ✓。
:::

::: tip 作法
Chebyshev 直接做二維差分很繞(官方解是沿兩條對角線各做一次差分再二維前綴和)。**轉 45°** 乾淨得多:$\max(|dx|,|dy|)=\dfrac{|dx+dy|+|dx-dy|}{2}$。令 $u=r+c$、$v=r-c$,把每格人數分別累到桶 $cu[u]$、$cv[v]$(各 $2N-1$ 個),則

$$f(i,j)=\frac{g(i+j)+h(i-j)}{2},\qquad g(u)=\sum_{u'}cu[u']\,|u-u'|$$

$g,h$ 都是一維「加權距離和」,排好序用前綴和一次掃完。整體 $O(N^2)$,數值到 $7\times10^{15}$,64 位放得下。

```cpp
for (int s = 0; s < N; s++)
    for (int t = 0; t < N; t++) {
        long long c = A[s] * B[t] % M;
        cu[s + t] += c;
        cv[s - t + N - 1] += c;
    }
auto dist = [&](const vector<long long>& c) {  // g[u] = Σ c[u'] |u - u'|,前綴和一遍
    vector<long long> g(W);
    long long cntL = 0, sumL = 0, tot = 0, totS = 0;
    for (int u = 0; u < W; u++) {
        tot += c[u];
        totS += c[u] * u;
    }
    for (int u = 0; u < W; u++) {
        cntL += c[u];
        sumL += c[u] * u;
        g[u] = (cntL * u - sumL) + ((totS - sumL) - (tot - cntL) * u);
    }
    return g;
};
auto g = dist(cu), h = dist(cv);
for (int i = 0; i < N; i++)
    for (int j = 0; j < N; j++) ans ^= (g[i + j] + h[i - j + N - 1]) / 2 + (long long)i * N + j;
```
