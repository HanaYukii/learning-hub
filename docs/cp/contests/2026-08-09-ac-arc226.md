# ARC226 — 學習重點

> A(AtC~300)熱身略過;收 B、C。D 是互動題,官方解法是把它化成 output-only 的啟發式搜尋;E 為 AtC~3500,都不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/arc226/editorial)整理,B 的封閉式與 C 的公式都以小範圍暴力對拍過。

### [B. Bin-ary Packing](https://atcoder.jp/contests/arc226/tasks/arc226_b)
`貪心` `數學` `AtC~1200`

::: info 題意
$N$ 個袋子($N\le10^6$),重量 $2^i$ 的包裹各 $A_i$ 個($i<M\le40$、$A_i\le10^6$)。每個包裹放進一個袋子。**求**最重袋子重量的最小值。$T\le10^5$ 組,$\sum M\le2\times10^5$。

例:$N=2$、三個 $2$:總重下界 $\lceil6/2\rceil=3$,但 $2$ 的包裹拆不開,兩袋至少一袋裝兩個 → 4。$N=2$、三個 $1$ 加一個 $2$:$\lceil5/2\rceil=3$,以 $2$ 為單位只有 $1$ 個 → $2\cdot\lceil1/2\rceil=2$,答案 3($\{2,1\},\{1,1\}$)。
:::

::: tip 作法
令 $S_i=\sum_{j\ge i}A_j2^{j-i}$(重量 $\ge2^i$ 的包裹以 $2^i$ 為單位的總量)。答案就是

$$\max_{0\le i<M}\;2^i\Bigl\lceil\frac{S_i}{N}\Bigr\rceil .$$

**下界**:每個袋子裡「$\ge2^i$ 的部分」是 $2^i$ 的倍數且 $\le C$,所以 $S_i\le N\lfloor C/2^i\rfloor$。**可達**:從重到輕、每次放進目前最輕的袋子(交換論證的關鍵一步:用 $\le2^k$ 的 $2$ 冪湊出總量 $\ge2^k$,一定有恰好 $2^k$ 的部分和,所以可以整包對調)。官方寫法是二分答案 + 模擬:處理 $2^i$ 時,剩餘容量 $C$ 的袋子可以拆成 $\lfloor C/2^i\rfloor$ 個容量 $2^i$ 加一個 $C\bmod2^i$,容量種類永遠 $\le2$ 種,$O(M\log W)$。

```cpp
long long S = 0, ans = 0;
for (int i = M - 1; i >= 0; i--) {  // S_i = sum_{j >= i} A_j 2^{j-i},從高位往下累
    S = S * 2 + A[i];
    ans = max(ans, (1LL << i) * ((S + N - 1) / N));
}
```
:::

### [C. Square Corner Packing](https://atcoder.jp/contests/arc226/tasks/arc226_c)
`構造` `分類討論` `不變量` `AtC~2050`

::: info 題意
$H\times W$ 全白格子($H,W\le500$、$\sum HW\le2.5\times10^5$)。一次操作選 $r,c,s$,要求 $(r,c),(r+s,c),(r,c+s),(r+s,c+s)$ 四格皆白,把它們塗黑。**求**最多操作次數並輸出一組方案。

例:$3\times3$:任一個 $2\times2$ 的四角塗完後,其他正方形都缺角 → 1 次(5 格塗不到)。$4\times6$:六個 $2\times2$ 鋪滿 → 6 次。$5\times6$:鋪滿前四列 → 6 次,最後一列整列塗不到。
:::

::: tip 作法
轉成「最少剩幾格塗不到」$u$。一次操作在任一列或欄塗 $0$ 或 $2$ 格,所以 **$W$ 為奇數時每列至少剩 $1$ 格、$H$ 為奇數時每欄至少剩 $1$ 格**;塗掉的格數又是 $4$ 的倍數。於是:偶偶 $u=0$;偶奇 $u=H$、奇偶 $u=W$(都用 $2\times2$ 鋪,剩最後一欄或最後一列);奇奇時 $u$ 是 $\ge\max(H,W)$ 且 $HW-u\equiv0\pmod4$ 的最小值,也就是 $\max(H,W)$ 或再加 $2$。答案 $=(HW-u)/4$。

構造照著下界走:奇奇且 $H\ne W$ 時,多出來的兩列(或兩欄)用 $2\times2$ 削掉,每削一次剛好多剩 $2$ 格;方形 $H=W$ 用官方那張 $9\times9$ 的「框」:外圈用 $s=1$ 與 $s=4$ 的正方形塗到只剩 4 格,中間留下 $(H-4)\times(H-4)$ 遞迴,底層 $1\times1$ 剩 1 格、$3\times3$ 剩 5 格。實作就是把這幾種圖案疊起來輸出。
:::
