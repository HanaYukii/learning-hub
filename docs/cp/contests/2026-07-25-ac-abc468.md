### [D. Good Substrings](https://atcoder.jp/contests/abc468/tasks/abc468_d)
`字串` `AtC~700`

::: info 題意
一個小寫字串稱為 good ⟺ **最多改寫一個字元就能變成回文**(回文本身也算 good)。例如 `a`、`iwai`、`abcdcza` 是 good,`abcd`、`atcoder` 不是。

給定長度 $\le 10^4$ 的小寫字串 $S$,**求**它有幾個非空子字串是 good(不同位置取出的子字串即使內容相同也分開計)。

例:$S=$ `abcd` 共 10 個子字串,只有 `abcd` 本身不是 good(首尾 `a`≠`d`、中間 `b`≠`c`,兩對錯位要改兩個字);其餘 9 個都能改 $\le1$ 個字變回文 → 答案 9。
:::

::: tip 作法
先把 good 的定義換成可計算的量:一個字串要「改 $\le 1$ 個字元變回文」,等價於**它的「錯位對」數 $\le 1$**——把首尾往中間配對,不相等的對數就是必須改的字元數(每對只要改一邊)。所以問題變成:數有多少子字串的錯位對 $\le 1$。

接著用**回文中心擴張**的框架:固定中心(奇中心 $n$ 個、偶中心 $n-1$ 個)往兩邊擴,一邊擴一邊累計不相等的對數 `dif`。關鍵是**單調性——半徑越大,`dif` 只增不減**,所以一旦 `dif > 1` 就可以直接 break,不必再往外走。每個中心貢獻的合法子字串就是 break 之前走過的步數。

$n \le 10^4$ 讓 $O(n^2)$ 穩過,這也是本題把上限壓在 $10^4$ 而不是 $10^5$ 的原因;要做 $O(n\log n)$ 得換成雜湊 + 二分「第一個錯位」跳兩次,但這題沒必要。

```cpp
// 奇中心:l = r = i 起步(偶中心同理,l = i、r = i+1)
for (int i = 0; i < n; i++) {
    int l = i, r = i, dif = 0;
    while (l >= 0 && r < n) {
        if (l != r && s[l] != s[r]) dif++;
        if (dif > 1) break;          // dif 單調不減 → 直接收工
        ans++;                        // 這個半徑的子字串是 good
        l--; r++;
    }
}
```

### [E. Sum of Means](https://atcoder.jp/contests/abc468/tasks/abc468_e)
`組合計數` `貢獻` `AtC~1050`

::: info 題意
給定長度 $N \le 5\times10^5$ 的整數序列 $A$($0 \le A_i < 998244353$)。令 $f(l,r)$ 為 $A_l,\dots,A_r$ 的**算術平均**。

**求** $\displaystyle\sum_{1\le l\le r\le N} f(l,r)$ 對 $998244353$ 取模(有理數取模)。

例:$N=2$、$A=(1,3)$ → 三個區間的平均分別是 $1$、$\frac{1+3}{2}=2$、$3$,總和 $6$。
:::

::: tip 作法
區間有 $O(N^2)$ 個,不能逐一算。標準手法是**換成逐元素的貢獻**:$A_i$ 出現在所有 $l \le i \le r$ 的區間裡,每次貢獻 $\frac{A_i}{r-l+1}$,所以

$$\text{答案}=\sum_i A_i \cdot C_i,\qquad C_i=\sum_{l\le i}\sum_{r\ge i}\frac{1}{r-l+1}.$$

問題變成快速算每個 $C_i$。直接看 $C_i$ 仍是 $O(N^2)$,這裡的漂亮之處是**用容斥把它拆成三個前綴和**:把「所有長度 $m$ 的區間的 $\frac1m$ 」按左右端點分類,可以驗證

$$C_i = G(N) - G(N-i) - G(i-1),\qquad G(m)=\sum_{j=1}^{m}H_j,\quad H_j=\sum_{k=1}^{j}\frac1k .$$

也就是**調和數的前綴和的前綴和**——$H$ 是一層前綴和、$G$ 是第二層。兩層各 $O(N)$ 掃出來後,每個 $C_i$ 都是 $O(1)$ 查表。模逆元用線性遞推 `inv[i] = (mod - mod/i * inv[mod%i]) % mod` 一次算完 $1\dots N$,整體 $O(N)$。

```cpp
// inv[]:線性求逆元;pre1 = H(調和數前綴)、pre2 = G(H 的前綴)
for (int k = 1; k <= n; k++) pre1[k] = (pre1[k-1] + inv[k]) % mod;
for (int m = 1; m <= n; m++) pre2[m] = (pre2[m-1] + pre1[m]) % mod;
for (int i = 1; i <= n; i++) {
    ll C = ((pre2[n] - pre2[n-i] - pre2[i-1]) % mod + 2*mod) % mod;   // 容斥
    ans = (ans + A[i] % mod * C) % mod;
}
```

### [F. Two Increasing Chains](https://atcoder.jp/contests/abc468/tasks/abc468_f)
`貪心` `dp` `BIT` `AtC~1700`

::: info 題意
給定 $(1,\dots,N)$ 的排列 $P$($N \le 5\times10^5$)與三個變數 $x=y=c=0$。

對 $k=1,\dots,N$ **依序**擇一執行:**操作 1** — 若 $x<P_k$ 則 $c$ 加 1,然後 $x \leftarrow \max(x,P_k)$;**操作 2** — 對 $y$ 做同樣的事。

**求** $c$ 的最大可能值。

例:$P=(2,1,3)$ → 把 $2$ 給 $x$、$1$ 給 $y$、$3$ 給任一邊,三步都讓 $c$ 加 1 → 答案 3(暴力枚舉全部 $2^3$ 種分配確認)。
:::

::: tip 作法
先看清楚題目在問什麼:$x$、$y$ 各自只增不減,而「$c$ 加 1」的條件是新值**大於**該變數當前值。所以把每個元素分給 $x$ 或 $y$,**$c$ = 兩條鏈上各自「刷新最大值」的次數之和**——本質是把 $P$ 拆成兩個子序列,最大化兩者的**嚴格遞增前綴刷新次數**總和。等價地:每條鏈上有貢獻的元素形成一個遞增子序列,所以要最大化「兩個(不相交)遞增子序列的長度和」。

處理這種「兩條鏈」問題的訣竅是**把其中一條特殊化**:注意到只要把每個「當前全域最大值」丟給同一條鏈(設為 $x$),它必定每次都刷新、每個都算分——這條鏈的貢獻就是**前綴最大值(prefix maxima)的個數**,沿路數 `add++` 即可,完全不必決策。剩下的元素全歸另一條鏈 $y$,問題塌成單鏈的**最長遞增子序列**。

LIS 部分用值域 BIT 維護前綴 max:`update(x, query(x-1)+1)`。而遇到新的全域最大值時,那個位置對 $y$ 鏈而言相當於一個「可以從任何狀態接上」的斷點,程式碼裡以 `update(mx, query(n))` 把當前整體最佳值搬到舊最大值的位置——讓後續的 LIS 能無損接續。整體 $O(N\log N)$。

```cpp
int mx = 0, add = 0;                  // mx = 目前全域最大;add = 前綴最大值個數
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    if (x > mx) {                     // 刷新全域最大 → 固定給 x 鏈,必得分
        add++;
        update(mx, query(n));         // 斷點:把當前最佳接到舊最大值的位置
        mx = x;
    } else {
        update(x, query(x - 1) + 1);  // 否則進 y 鏈的 LIS
    }
}
cout << add + query(n) << '\n';
```

### [G. Prefix-Complete Permutations](https://atcoder.jp/contests/abc468/tasks/abc468_g)
`組合計數` `dp` `AtC~2000`

::: info 題意
給定 $N \le 2000$ 與長度 $N$ 的字串 $S$(字元為 `o`/`x`)。

**求**有幾個 $(1,\dots,N)$ 的排列 $P$ 滿足:對每個 $k$,「$S_k=$ `o`」⟺「$P$ 中存在一段**連續**子序列恰好是 $(1,\dots,k)$ 的某個排列」。答案對 $998244353$ 取模。

例:$N=3$、$S=$ `oxo` → 只有 $P=(2,3,1)$ 與 $(1,3,2)$ 合法(值 $1$ 單獨成段所以 $k=1$ 必 `o`;$k=2$ 要求 $1,2$ **不**相鄰;$k=3$ 全體必 `o`)→ 答案 2。
:::

::: tip 作法
先抓兩個邊界條件:$k=1$ 時「$\{1\}$ 自己就是一段」永遠成立、$k=N$ 時「整個 $P$」也永遠成立,所以 **$S_1=S_N=$ `o` 是必要條件**,否則直接輸出 0。

再看結構。稱 $k$ **完備**表示 $1..k$ 佔據一段連續區間。關鍵觀察:**完備的 $k$ 是巢狀的**——若 $k$ 完備、$k'>k$ 也完備,那 $1..k$ 的那段必定被 $1..k'$ 的段包住。所以整個排列的結構是「一層層往外包」的區塊,而 $S$ 裡的每個 `o` 就是一層邊界。於是**相鄰兩個 `o` 之間互相獨立**,答案是各段方案數的**乘積**。

剩下的就是單段:設相鄰兩個 `o` 距離 $d$(前一個完備在 $k$、下一個在 $k+d$),要把 $d$ 個新元素放進去,使得**中途沒有任何時刻提早完備**、放完才完備。令這個數為 $\mathrm{dp}[d]$,用**補集遞推**:

- 不管完備與否,把「已完備區塊」看成一個 token,連同 $d$ 個新元素共 $d+1$ 個物件排列 → $(d+1)!$;
- 扣掉「在第 $t$ 步($t<d$)就提早完備」的:前 $t$ 步的合法方式有 $\mathrm{dp}[t]$ 種,之後把新區塊當 token、剩 $d-t$ 個元素一起排 → $(d-t+1)!$。

$$\mathrm{dp}[d]=(d+1)!-\sum_{t=1}^{d-1}\mathrm{dp}[t]\cdot(d-t+1)!$$

$O(N^2)$ 遞推,$N\le2000$ 剛好。(小驗算:$\mathrm{dp}[1..5]=2,2,8,44,296$,而 $S=$ `oxxo`($d=3$)暴力數確實是 8。)

```cpp
if (s[0] != 'o' || s[n-1] != 'o') { cout << 0; return; }   // 邊界必為 o
for (int d = 1; d <= n; d++) {                              // 補集遞推
    ll v = fac[d + 1];
    for (int t = 1; t < d; t++) v -= fac[d - t + 1] * dp[t] % mod;
    dp[d] = (v % mod + mod) % mod;
}
ll ans = 1; int last = 1;
for (int k = 2; k <= n; k++)                                // 相鄰 o 的間距相乘
    if (s[k-1] == 'o') { ans = ans * dp[k - last] % mod; last = k; }
```
