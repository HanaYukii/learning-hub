# ABC477 — 學習重點

> A–E 熱身略過(E 為 AtC~1250);收 F、G。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc477/editorial)整理,兩題都以暴力對拍過(G 含 Mo 的完整實作)。

### [F. Count Cells in a Window](https://atcoder.jp/contests/abc477/tasks/abc477_f)
`掃描線` `離線` `線段樹` `AtC~1650`

::: info 題意
$N\times M$ 格子,第 $i$ 列的第 $L_i..R_i$ 欄是黑的。$Q$ 個詢問:矩形(列 $A..B$、欄 $C..D$)內有幾個黑格。$N,M,Q\le2\times10^5$。

例:列 1 黑 $[1,3]$、列 2 黑 $[2,4]$,問列 $1..2$ 欄 $2..3$:列 1 貢獻 $2$、列 2 貢獻 $2$ → 4。
:::

::: tip 作法
矩形拆成兩個前綴差:$S(B,C,D)-S(A-1,C,D)$,$S(X,\cdot)$ = 前 $X$ 列。把詢問依 $X$ 排好**掃列**:加入第 $x$ 列就是對欄 $[L_x,R_x]$ 整段 $+1$,問一段欄的和 → 區間加、區間和(lazy segtree 或兩個 BIT)。$O((N+Q)\log M)$。

```cpp
for (int x = 0; x <= N; x++) {
    if (x) bit.rangeAdd(L[x], R[x], 1);                                        // 加入第 x 列的黑段
    for (auto [c, d, id, sign] : at[x]) ans[id] += sign * bit.rangeSum(c, d);  // (B, +1) 與 (A-1, -1)
}
```
:::

### [G. Frequency Query on Tree](https://atcoder.jp/contests/abc477/tasks/abc477_g)
`根號` `樹` `離線` `AtC~2250`

::: info 題意
$N$ 點樹,點 $i$ 寫著 $x_i$。$Q$ 個詢問 $(s,t,a,b)$:路徑 $s\to t$ 上,出現次數 $f$ 落在 $[a,b]$ 的數值 $y$ 有幾種。$N,Q\le2\times10^5$。

例:路徑上的值是 $1,2,2,1,3$,問 $[2,2]$:$1$ 出現 $2$ 次、$2$ 出現 $2$ 次、$3$ 出現 $1$ 次 → 2。
:::

::: tip 作法
**Mo's algorithm on tree**:做進出都記錄的 Euler tour $E$(長 $2N$)。$t_{in}[s]\le t_{in}[t]$ 時,子陣列 $E[t_{in}[s]+1..t_{in}[t]]$ 裡**出現奇數次**的點恰好是路徑 $s\to t$ 去掉 LCA——路徑外的點進出各一次被抵消。所以每個詢問變成序列上的區間,Mo 移動指標時翻轉點的奇偶、加減它的顏色;回答時暫時加進 LCA。

區間內要維護「頻率在 $[a,b]$ 的顏色數」:同時維護 $g_i=\#\{y:f_y\ge i\}$,顏色頻率 $c\to c{+}1$ 只動 $g_{c+1}$,答案 $=g_a-g_{b+1}$,$O(1)$。整體 $O(N\sqrt Q+Q\log N)$。

// 詢問 (s, t):tin[s] <= tin[t] → 區間 [tin[s] + 1, tin[t]],另記 lca(s, t)
auto toggle = [&](int v) { par[v] ^= 1; if (par[v]) addColor(x[v]); else removeColor(x[v]); };
auto addColor = [&](int c) { f[c]++; g[f[c]]++; };  // g[i] = #{y : f_y >= i}
auto removeColor = [&](int c) { g[f[c]]--; f[c]--; };
// Mo 移動 L、R 時對 E[pos] 做 toggle;回答:
toggle(lca);
