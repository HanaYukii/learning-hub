# ARC231 — 學習重點

> 收 A、B、C;D(AtC~2450)、E(AtC~2400)、F 超過上限不收。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/arc231/editorial)整理,A、C 以暴力對拍,B 的構造對隨機 $A,B,C\le1000$ 驗過三個 mex。

### [A. Two Dimensional Invader](https://atcoder.jp/contests/arc231/tasks/arc231_a)
`dp` `貢獻` `AtC~1650`

::: info 題意
從 $(0,0)$ 出發,依序來 $N$ 隻怪($N\le2.5\times10^5$),第 $i$ 隻在 $(X_i,Y_i)$(座標 $<500$)。用劍:移動到該點,費用 = 移動的**平方**歐氏距離;用魔法:不動,費用 $Z_i$。**求**總費用最小值。

例:兩隻怪 $(1,0)$、$(1,3)$,$Z$ 都是 $5$:劍、劍 $=1+9$;劍、魔法 $=1+5=6$;魔法、魔法 $=10$ → 6。
:::

::: tip 作法
先把 $\sum Z_i$ 加進答案,用劍改成「省 $Z_i$」。關鍵是**平方距離可拆**:$(x_1-x_2)^2+(y_1-y_2)^2$ = 先只動 $x$ 再只動 $y$。於是狀態 $dp[x][y]$(目前在 $(x,y)$)只需兩種轉移:怪 $(X,Y)$ 來時,**沿第 $Y$ 列 pull**($\min_{x'}dp[x'][Y]+(x'-X)^2$,再減 $Z$)得到用劍的費用,然後**沿第 $X$ 欄 push** 到所有 $(X,y)$ 加 $(y-Y)^2$。每隻怪 $O(X+Y)$,起點 $dp[0][y]=y^2$,總 $O(N(X+Y)+XY)$。

```cpp
for (auto [X, Y, Z] : monsters) {
    long long c = INF;
    for (int xp = 0; xp < W; xp++) c = min(c, dp[xp][Y] + (long long)(xp - X) * (xp - X));  // pull:沿列
    c -= Z;
    for (int y = 0; y < H; y++) dp[X][y] = min(dp[X][y], c + (long long)(y - Y) * (y - Y));  // push:沿欄
}
ans = sumZ + min over dp;  // 含 dp[0][0] = 0(全用魔法)
```

### [B. Three Mex](https://atcoder.jp/contests/arc231/tasks/arc231_b)
`構造` `位元` `AtC~1400`

::: info 題意
給 $A,B,C\le1000$,**構造**非負整數集合 $X,Y$(元素 $\le2026$)使 $\operatorname{mex}X=A$、$\operatorname{mex}Y=B$、$\operatorname{mex}\{x\oplus y\}=C$,或判 No。

例:$A=B=2$、$C=1$:$0\in X$、$1\in Y$ 逼出 $0\oplus1=1=C\in Z$ → No。$A=B=C=1$:$X=Y=\{0,1024\}$,$Z=\{0,1024\}$,mex $=1$ ✓。
:::

::: tip 作法
$X\supseteq\{0..A-1\}$、$Y\supseteq\{0..B-1\}$ 是逼出來的,所以若有 $x<A,y<B$ 使 $x\oplus y=C$ 就 No($O(AB)$ 直接查)。否則用**高位隔離**:$X=\{0..A-1\}\cup\{1024\}$、$Y=\{0..B-1\}\cup\{1024+k:k<C\}$。小配小的 XOR 不含 $C$(剛查過);小配大 $\ge1024>C$;大配大恰好給出 $0..C-1$。mex 都對,元素 $\le2023$。
:::

### [C. One Sky, Many Stars](https://atcoder.jp/contests/arc231/tasks/arc231_c)
`分類討論` `貪心` `AtC~2250`

::: info 題意
$N$ 人在數線上 $x_1<\dots<x_N$,人 $i$ 說「離我最近的星距離 $d_i$」。$Q$ 次單點修改 $d$,每次**判定**有沒有星星配置與所有證詞相容。$N,Q\le1.5\times10^5$。

例:$x=(0,5)$、$d=(2,1)$:人 1 要 $\{-2,2\}$ 有星且 $(-2,2)$ 內沒星;人 2 要 $\{4,6\}$ 有星且 $(4,6)$ 內沒星。放 $-2$ 與 $4$ → Yes。改成 $d=(4,1)$:人 1 的兩個候選 $-4,4$,$4$ 落在 $(4,6)$ 外面 ✓ → 仍 Yes;改 $d=(5,1)$:$-5,5$,$5\in(4,6)$ 不行但 $-5$ 可以 → Yes。
:::

::: tip 作法
證詞 $i$ = 開區間 $(x_i-d_i,x_i+d_i)$ 內無星、兩端至少一顆有星。星可以放在所有「不在任何開區間內」的點,所以可行 $\iff$ **每個 $i$ 的兩個端點至少有一個不在任何人的開區間內**。這是 $O(N^2)$;關鍵觀察是**只要看鄰居 $i\pm1$ 的開區間就夠**:若 $x_i-d_i$ 隨 $i$ 不單調,鄰居立刻就擋住兩個端點;單調時,左端點只可能被 $j<i$ 蓋住、而 $x_j+d_j$ 在 $j=i-1$ 最大。於是維護「兩端都被鄰居蓋住」的壞人集合,改 $d_p$ 只重算 $p-1,p,p+1$。$O(N+Q)$。

```cpp
bool goodCoord(ll c, int i) {  // c 不在鄰居的開區間內?
    for (int j : {i - 1, i + 1})
        if (1 <= j && j <= N && x[j] - d[j] < c && c < x[j] + d[j]) return false;
    return true;
}
bool isBad(int i) { return !goodCoord(x[i] - d[i], i) && !goodCoord(x[i] + d[i], i); }
// 修改 d[p] 後:對 q ∈ {p-1, p, p+1} 重算 isBad,維護壞人集合;Yes ⟺ 集合為空
```
