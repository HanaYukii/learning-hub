### [A1. Floor of MEX (Easy Version)](https://codeforces.com/contest/2262/problem/A1)
`差分` `貪心` `~1500`

::: info 題意
定義 $f(S,x)=\operatorname{mex}\{\lfloor y/x\rfloor : y\in S\}$。有個隱藏集合 $A\subseteq\{0,\dots,n-1\}$,給你 $a_k=f(A,k)$($k=1..n$)。**求**任一個 $B\subseteq\{0,\dots,n-1\}$ 使 $f(B,k)=a_k$ 對所有 $k$ 成立(保證存在)。$n\le10^5$。

例:$a=[2,1,1,1,1]$。$k=1$ 要 $\operatorname{mex}\{y\}=2$:$0,1$ 必在、$2$ 必不在;$k=2$ 要 $\operatorname{mex}\{\lfloor y/2\rfloor\}=1$:$[2,3]$ 沒有元素;$k=3,4,5$ 同理禁掉 $[3,5],[4,7],[5,9]$。禁區以外只剩 $\{0,1\}$,就是答案。
:::

::: tip 作法
$f(A,k)=x$ 只說兩件事:每個 $j<x$ 的區塊 $[jk,\ jk+k-1]$ 至少有一個元素、區塊 $[xk,\ xk+k-1]$ 是空的。**所有「必須為空」區塊的聯集是禁區,禁區以外全拿**就是一個解:多拿元素只會讓每個「必須非空」的區塊更容易非空,又不會碰到任何禁區;題目保證解存在,所以每個必須非空的區塊裡一定有禁區外的數字。禁區用差分,$O(n)$。

```cpp
vector<int> d(n + 2, 0);
for (int k = 1; k <= n; k++) {  // f(A,k) = a[k]:區塊 [a[k]*k, (a[k]+1)*k - 1] 必須是空的
    long long l = (long long)a[k] * k, r = (long long)(a[k] + 1) * k - 1;
    d[min<long long>(n, l)]++;
    d[min<long long>(n, r + 1)]--;
}
vector<int> B;
for (int i = 0, c = 0; i < n; i++) {
    c += d[i];
    if (c == 0) B.push_back(i);  // 禁區以外全拿
}
```
:::

### [A2. Floor of MEX (Hard Version)](https://codeforces.com/contest/2262/problem/A2)
`dp` `差分` `~2100`

::: info 題意
同 A1,改成**數**有幾個 $B$ 滿足條件,mod $10^9+7$。

例:$a=[0,3,2,2,2,1]$。禁區只有 $\{0\}$($k=1$、$a_1=0$)。必須非空的區塊裡,最小的幾個是 $[0,1]$、$[2,3]$、$[4,5]$、$[5,9]$:$0$ 被禁所以 $1$ 必選,$[5,9]$ 裡只有 $5$ 可用所以 $5$ 必選,$[2,3]$ 三種選法,$4$ 自由 → $3\times2=6$。
:::

::: tip 作法
條件變成一堆「必須非空」的區塊(共 $\sum_k a_k\le\sum_k n/k=O(n\log n)$ 個)加上禁區。**包含別的區塊的區塊可以丟掉**(裡面那個滿足了、外面自動滿足),剩下的區塊左右端點都嚴格遞增。

由小到大掃允許的數字 $i$,狀態 $t$ = 「最小的還沒滿足的區塊編號」。選 $i$ 會把所有 $l\le i$ 的未滿足區塊一口氣滿足(它們的 $r\ge i$,因為錯過的狀態已經剔除),所以**所有活著的狀態都轉到同一個新狀態** $r(i)=\#\{\text{區塊}:l\le i\}$;不選 $i$ 則狀態不變。維護活狀態總和 $\text{poss}$,每個 $i$ 做 $\text{dp}[r]\mathrel{+}=\text{poss}$、$\text{poss}\times2$,並把 $r<i$ 的區塊對應的狀態剔除。區塊 $O(n\log n)$ 個,排序後 $O(n\log^2n)$。

```cpp
// iv:去掉「包含別的區塊」後的必須非空區塊,l、r 皆遞增;gnums:禁區以外的數字(遞增)
vector<long long> dp(m + 1, 0);  // dp[t] = 前 t 個區塊已滿足、第 t 個還沒
dp[0] = 1;
long long poss = 1;  // 活著的狀態總和
int l = 0, r = 0;
for (int i : gnums) {
    while (l < m && iv[l].second < i) poss = (poss - dp[l++] + MOD) % MOD;  // 區塊 l 已經錯過:狀態 l 死掉
    while (r < m && iv[r].first <= i) r++;                                  // 選 i 會一路滿足到區塊 r-1
    dp[r] = (dp[r] + poss) % MOD;                                           // 選 i:所有活狀態都跳到 r
    poss = poss * 2 % MOD;                                                  // 不選 i:狀態不變;總和翻倍
}
return dp[m];
```
:::

### [B. Culling Game](https://codeforces.com/contest/2262/problem/B)
`資料結構` `BIT` `離線` `~2000`

::: info 題意
$n$ 個人排成一列,技能 $a_i$。最左邊的人當擂主,依序遇到右邊每個人:擂主技能 $s<$ 對手 $x$ 就**棄權**、對手成為新擂主(技能 $x$);否則擂主贏、技能變成 $s+x$。依排列 $p$ 依序移除 $p_1,p_2,\dots$;對每個 $i=0..n-1$,**求**移除前 $i$ 個人後跑一輪有幾次棄權。$n\le2\times10^5$。

例:$a=[1,2,4,3]$、$p=[1,2,3,4]$。不移除:$1$ 輸給 $2$、$2$ 輸給 $4$、$4$ 贏 $3$ → 2;移除 $1$ 後 $[2,4,3]$ → 1;$[4,3]$、$[3]$ → 0。答案 `2 1 0 0`。
:::

::: tip 作法
**倒過來做:移除變成插入**。維護「棄權點」集合 $S$(每個棄權點是一位新擂主的起點,最左邊的人也算),答案 $=|S|-1$。插入位置 $k$ 時,找 $S$ 裡 $k$ 左邊最近的 $j$:擂主走到 $k$ 時的技能就是 $[j,k)$ 內在場者的技能和(BIT),小於 $a_k$ 就把 $k$ 加進 $S$。

插入之後,$k$ 右邊的擂主技能只會變大,所以只要往右檢查後面的棄權點 $j'$:若「從當前擂主起點到 $j'-1$ 的和」$\ge a_{j'}$,$j'$ 就不再是棄權點、拿掉,繼續往右直到卡住。每個位置至多被拿掉一次(每次插入至多新增一個),整體 $O(n\log n)$。

```cpp
reverse(p.begin(), p.end());  // 移除 → 倒序插入;bit.sum(x) = 位置 < x 的在場者技能和
set<int> S;                   // 棄權點(含最左邊的第一個擂主)
for (int i = 0; i < n; i++) {
    int k = p[i];
    auto it = S.upper_bound(k);
    int from;  // 擂主走到 k 時,技能從哪個位置開始累加
    if (it == S.begin() || bit.sum(k) - bit.sum(*prev(it)) < a[k]) {
        S.insert(k);
        from = k;
    } else
        from = *prev(it);
    bit.add(k, a[k]);
    for (auto jt = S.upper_bound(k); jt != S.end(); jt = S.upper_bound(k)) {  // 右邊的棄權點被吃掉?
        if (bit.sum(*jt) - bit.sum(from) >= a[*jt])
            S.erase(jt);
        else
            break;
    }
    ans[i] = S.size() - 1;
}
reverse(ans.begin(), ans.end());
```

### [C. Traveling the World](https://codeforces.com/contest/2262/problem/C)
`分類討論` `組合計數` `~2300`

::: info 題意
$n\ge4$ 個島,值 $a$ 嚴格遞增且 $a_1=0$。重排成 $b$;從位置 $i$ 能走到 $j$ $\iff b_i+b_j=\max(b_i,\dots,b_n)$(從 $i$ 起的後綴最大值)。$b$ 是 good 若存在一條走遍所有位置各一次的路徑。**求** good 重排的個數 mod $10^9+7$。

例:$a=[0,1,3,4]$,$M=4$、$k=2$。$x=M-3=1$:$\{0,1\}\cup\{4,3\}$ 剛好是 $a$ ✓;$x=M-1=3$:$\{0,3\}\cup\{4,1\}$ ✓。各 $2!\cdot0!=2$ 種 → 4。
:::

::: tip 作法
每個位置最多一條出邊(往值 $s_i-b_i$ 的位置),所以 good $\iff$ 這張函數圖裡有一條長 $n$ 的路。用出邊的結構逼出形狀:**後綴最大值恰好兩個**——只有一個時每條邊都是 $x\to M-x\to x$ 兩點打轉;三個以上時至少三條邊指向 $0$,一條路只能用其中一條,邊數就超過點數。兩個後綴最大值必是 $M$ 與最後一個 $b_n$;再推出 $0$ 必在 $M$ 前面、路徑以 $b_n\to0\to M$ 收尾,往回推整條路交替為 $M,0,M-x,x,M-2x,2x,\dots$($x=M-b_n$)。

因此 good $\iff$ 排序後的值恰為 $\{0,x,\dots,(k-1)x\}\cup\{M,M-x,\dots,M-(n-k-1)x\}$,$k=\lfloor n/2\rfloor$;$M$ 前面那組任意排($k!$),$M$ 後面那組除了 $b_n$ 固定在最後也任意排($(n-k-2)!$)。$x$ 只需試 $M-a_{n-1}$ 與 $M-a_{n-2}$:否則 $a_{n-1},a_{n-2}$ 都得是 $x$ 的倍數,卻相差不到 $x$。$O(n\log n)$。

```cpp
int k = n / 2;
long long ways = fact[k] * fact[n - k - 2] % MOD;
long long ans = 0;
for (long long x : set<long long>{a[n - 1] - a[n - 2], a[n - 1] - a[n - 3]}) {
    vector<long long> b;
    for (int i = 0; i < k; i++) b.push_back(i * x);                 // M 之前:0, x, ..., (k-1)x
    for (int i = 0; i < n - k; i++) b.push_back(a[n - 1] - i * x);  // M 之後:M, M-x, ..., M-(n-k-1)x
    sort(b.begin(), b.end());
    if (b == a) ans = (ans + ways) % MOD;
}
```
