### [F. Increment All Divisors](https://atcoder.jp/contests/abc474/tasks/abc474_f)
`數論` `數學` `AtC~1900`

::: info 題意
給長度 $N$ 的整數序列 $A$($N\le2\times10^5$、$A_i\le10^9$)。一次操作選一個 $i$,對 $i$ 的**每個正因數** $j$ 把 $A_j$ 加 $1$。**求**把所有元素變成相等的最少操作次數;做不到輸出 $-1$。

例:$A=(4,7,4)$。選 $i=3$ 三次,每次 $A_1$、$A_3$ 各 $+1$ → $(7,7,7)$,3 次。
:::

::: tip 作法
設最後全部等於 $x$、選 $i$ 的次數為 $C_i$。$A'_i=A_i+\sum_{i\mid k}C_k=x$,而 $C_i$ 只受 $C_{2i},C_{3i},\dots$ 影響,**從 $i=N$ 往下推**每個 $C_i$ 都是 $x$ 的一次式 $C_i=\alpha_i x+\beta_i$,調和級數 $O(N\log N)$。$C_i\ge0$ 是一組關於 $x$ 的一次不等式,解出 $x$ 的可行區間;沒有整數解就 $-1$。

總操作數不用另外算:**每次操作都會加到 $A_1$**($1$ 是所有數的因數),所以總次數 $=x-A_1$,取可行的最小 $x$ 即可。

要小心的坑:直覺上「對齊到 $\max A$」就好,但 $\alpha_i=M(\lfloor N/i\rfloor)$(Mertens 函數)在 $N\ge94$ 時可能為正,代表 $x$ 變大反而讓某些 $C_i$ 從負變非負。官方附了 $N=94$ 的 hack 資料,最小可行的 $x$ 是 $\max A+21739130$。

```cpp
// C_i = al[i] * x + be[i]:從 i = N 往下推,C_i 只受 C_{2i}, C_{3i}, ... 影響(調和級數 O(N log N))
for (int i = n; i >= 1; i--) {
    long long a = 1, b = -A[i];
    for (int k = 2 * i; k <= n; k += i) {
        a -= al[k];
        b -= be[k];
    }
    al[i] = a;
    be[i] = b;
}
long long lo = -INF, hi = INF;  // C_i >= 0 給 x 的上下界
for (int i = 1; i <= n; i++) {
    if (al[i] > 0)
        lo = max(lo, ceildiv(-be[i], al[i]));
    else if (al[i] < 0)
        hi = min(hi, floordiv(be[i], -al[i]));
    else if (be[i] < 0)
        return -1;
}
return lo > hi ? -1 : lo - A[1];  // 每次操作都會加到 A_1:總操作數 = x - A_1
```
:::

### [G. LRUD Moving 2](https://atcoder.jp/contests/abc474/tasks/abc474_g)
`構造` `分類討論` `AtC~2300`

::: info 題意
$N\times N$ 格子($N\le10^3$、$\sum N^2\le10^6$),棋子從 $(1,1)$ 出發,走 $N^2-1$ 步、每格恰好經過一次、終點 $(N,N)$。**求**是否存在**恰好 $K$ 次向右**的走法,存在就輸出一組(L/R/U/D 字串)。

例:$N=3$:$K=2$ 走 `DDRUURDD`,$K=4$ 走 `RRDLLDRR`;$K=3$(奇數)或 $K=0$($<N-1$)都是 No。
:::

::: tip 作法
三個必要條件:**$N$ 為奇數**(每步翻轉 $r+c$ 的奇偶,$(1,1)$ 到 $(N,N)$ 要走 $N^2-1$ 步)、**$N-1\le K\le\frac{N^2-1}2$**($R-L=D-U=N-1$,四種步數加總 $N^2-1$)、**$K$ 為偶數**(非顯然:把路徑的第 $2i-1,2i$ 步配成骨牌,骨牌覆蓋對應的排列逆序數加上「左黑右白的橫骨牌數」是覆蓋方式的不變量;或用 Pick 定理,細節見官方題解)。

三個都滿足就一定做得到,構造分兩段。令 $M=\frac{N-1}2$,取非遞增的 $T_1\ge\dots\ge T_M$(每個 $\le M$)使 $\sum T_i=\frac{K-N+1}2$(平均分配即可)。**左半蛇形**:對 $i=1..M$ 依序走 $\mathrm R^{2T_i}\,\mathrm D\,\mathrm L^{2T_i}\,\mathrm D$,每兩列覆蓋第 $1..2T_i+1$ 欄,走完停在 $(N,1)$。**右半階梯**:剩下的是右上角缺、往下變寬的階梯,對 $j=1..M$ 走 $\mathrm R\,\mathrm U^{d}\,\mathrm R\,\mathrm D^{d}$,$d=2\cdot\#\{i:T_i<j\}$,一欄往上填、一欄往下填。向右步數 $=\sum2T_i+2M=K$。

```cpp
int m = (n - 1) / 2, s = (k - (n - 1)) / 2;
vector<int> t(m);
for (int i = 0; i < m; i++) t[i] = (s + m - 1 - i) / m;  // 非遞增、和為 s、每個 <= m
string ans;
for (int v : t) {
    ans += string(2 * v, 'R');
    ans += 'D';
    ans += string(2 * v, 'L');
    ans += 'D';
}                               // 左半蛇形
for (int j = 1; j <= m; j++) {  // 右半階梯
    int d = 0;
    for (int v : t)
        if (v < j) d++;
    d *= 2;
    ans += 'R';
    ans += string(d, 'U');
    ans += 'R';
    ans += string(d, 'D');
}
```
:::
