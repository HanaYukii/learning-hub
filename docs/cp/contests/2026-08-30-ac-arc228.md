# ARC228 — 學習重點

> 這場是 ARC++(加難場):A 估 AtC~2750、C 以上更高,超過收錄上限,只收 B。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/arc228/editorial)整理,B 以 $N\le6$ 枚舉所有合法樹對拍過。

### [B. Minimize Topological Order](https://atcoder.jp/contests/arc228/tasks/arc228_b)
`貪心` `樹` `線段樹` `AtC~1250`

::: info 題意
給排列 $P$ 與正整數 $A$($N\le2\times10^5$)。對 $N$ 點有根樹 $T$,$f(T)$ 是**字典序最小的拓撲序**(父先於子);樹的成本 $\sum_iA_ic_i^2$,$c_i$ 是 $i$ 的子節點數。**求** $f(T)=P$ 的樹的最小成本。

例:$P=(1,3,2)$、$A=(1,1,1)$:$2$ 的父只能是 $3$——若掛在 $1$ 下,放完 $1$ 之後 $2$、$3$ 都可選,字典序會先選 $2$。所以只能是鏈 $1\to3\to2$,成本 $A_1+A_3=2$。
:::

::: tip 作法
$f(T)=P$ 的條件:根是 $P_1$;$P_i$ 的父在 $P_1..P_{i-1}$ 之中;而且**若前面有比 $P_i$ 大的元素,取最近的一個 $P_{L_i}$,父必須落在 $P_{L_i}..P_{i-1}$**(否則 lex-min 會提早選到 $P_i$)。這些條件也充分。於是問題變成:每個 $i\ge2$ 在區間 $[L_i,i-1]$ 挑一個位置 $j$ 當父、$c_j$ 加一,最小化 $\sum A_{P_j}c_j^2$。

兩個關鍵。**(1) 這些區間兩兩不交或包含**(laminar):假設交叉 $L_x<L_y\le x-1<y-1$,由 $L$ 的定義推出 $P_x<P_y$、$P_{L_y}<P_x$、$P_{L_y}>P_y$ 三者矛盾。**(2) $c^2$ 是凸的**,第 $k$ 個孩子的邊際成本是 $(2k-1)A$。於是**從窄到寬處理區間,每次挑區間內目前邊際成本最小的位置**就是最優:若某個窄區間放棄了最小值 $m$、而 $m$ 後來被更寬的區間用掉,兩區間相交,laminar 保證是包含,兩者對調不會變差。$L$ 用單調 stack $O(N)$,貪心用線段樹維護每個位置的下一個邊際成本,$O(N\log N)$。

```cpp
// L[i] = 最大的 j < i 使 P[j] > P[i](沒有就 1);區間 [L[i], i-1] 依長度由短到長處理
sort(ord.begin(), ord.end(), [&](int x, int y) { return (x - 1 - L[x]) < (y - 1 - L[y]); });
// seg:位置 j 目前的邊際成本 (2 * cnt[j] + 1) * A[P[j]],初始 A[P[j]]
for (int i : ord) {
    auto [cost, j] = seg.min(L[i], i - 1);  // 區間內最便宜的位置當父
    total += cost;
    cnt[j]++;
    seg.set(j, (2 * cnt[j] + 1) * A[P[j]]);
}
```
:::
