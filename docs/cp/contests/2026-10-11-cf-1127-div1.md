### [A. Lavencia Oranges](https://codeforces.com/contest/2273/problem/A)
`二分` `貪心` `構造` `~1500`

::: info 題意
$n$ 顆橘子放進 $n$ 個袋子($a_i$ = 第 $i$ 顆放哪袋)。檢查員選一個大小 $s$,沒收所有恰好裝 $s$ 顆的袋子,挑讓她拿最多的 $s$;陣列的成本 $=\max_i\,i\cdot c_i$($c_i$ = 恰好 $i$ 顆的袋數)。**求**成本最小的 $a$ 並輸出。

例:$n=5$:兩袋 $\{2,3\}$,成本 $\max(2,3)=3$;成本 $2$ 最多只能放 $2$ 個 $1$ 顆、$1$ 個 $2$ 顆 $=4$ 顆,不夠。
:::

::: tip 作法
對成本 $x$ 二分:成本 $\le x$ 時**最多能裝幾顆**?每種大小 $i$ 最多 $\lfloor x/i\rfloor$ 袋,全塞滿得 $L(x)=\sum_i\lfloor x/i\rfloor\cdot i\approx\frac{\pi^2}{12}x^2$,所以 $x\le\sim510$。$L(x)\ge n$ 就可行:從塞滿的配置出發,每次從**最小的袋子**拿走一顆(那一袋降到大小 $s-1$,而原本沒有 $s-1$ 的袋子,成本 $s-1\le x$),直到剩 $n$ 顆。$O(n\log n)$。

```cpp
auto L = [&](long long x) { long long s = 0; for (long long i = 1; i <= x; i++) s += (x / i) * i; return s; };
long long x = 二分最小使 L(x) >= n;
multiset<long long> bags;
for (i = 1..x) 放 x / i 袋大小 i;
while (total > n) {
    s = *bags.begin();
拿掉一顆:
    大小變 s - 1(s = 1 時整袋消失);
    total--;
}  // 成本不升
```
:::

### [B. Robot Championship](https://codeforces.com/contest/2273/problem/B)
`構造` `不變量` `數學` `~1800`

::: info 題意
$n\times n$ 棋盤上有一個看不見、對抗性的機器人。每秒你先沿一條對角線 $r+c=v$ 射雷射(碰到就贏),之後它往上、往右或往左下 $(r-1,c-1)$ 移動一步。**輸出**至多 $3n$ 發的固定序列,保證無論起點與走法都會被打到。

例:$n=2$:$3,3,3$ 可行——$(1,1)$ 下一步必到對角線 $3$;$(2,2)$ 只能走 $(1,1)$ 再上對角線 $3$。
:::

::: tip 作法
令 $d=r+c$。上、右各 $+1$,左下 $-2\equiv+1\pmod3$ → **每秒 $d\bmod3$ 必定 $+1$**,起點決定了它每一秒的餘數類。把三個餘數類各用一段連續時間處理:在該段起始秒 $s$,這群機器人的 $d\equiv\rho+s-1$,第一發打該類中最大的對角線 $V\le2n$,之後**每秒 $-2$**($-2\equiv+1$,恰好跟著餘數類走)直到 $\ge2$ 最小者。令 $g=d-v$:永遠是 $3$ 的倍數,且只會 $+3$(機器人往上/右)或不變(左下),從 $\le0$ 走到 $\ge0$ 必經 $0$ → 必被打中。每段 $\le n$ 發。

```cpp
int s = 1;                           // 目前秒數
for (int rho = 0; rho < 3; rho++) {  // 一個餘數類一段
    int want = (rho + s - 1) % 3;    // 這一秒該類機器人的 d mod 3
    int V = 2 * n;
    while (V % 3 != want) V--;  // 該類最大的對角線
    for (int v = V; v >= 2; v -= 2) {
        shots.push_back(v);
        s++;
    }  // 每秒 -2 ≡ +1 (mod 3)
}
```

### [C. Matrix Puzzle](https://codeforces.com/contest/2273/problem/C)
`矩陣` `不變量` `BIT` `~2000`

::: info 題意
$n\times n$ 矩陣 $a,b$($n\le1000$)。子矩陣 matchable $\iff$ 能選每列 $h_i$、每欄 $w_j$ 使 $a_{ij}+h_i+w_j=b_{ij}$ 在子矩陣內成立。$q\le2\times10^4$ 個操作:子矩陣整體 $+x$,或問某子矩陣是否 matchable。

例:$a=\begin{bmatrix}6&1&1\\2&2&2\end{bmatrix}$、$b=\begin{bmatrix}2&3&4\\6&7&8\end{bmatrix}$:$C=a-b$ 的左上 $2\times2$ 區塊 $4+(-5)-(-2)-(-4)=5\ne0$ → NO。
:::

::: tip 作法
令 $C=a-b$。$C_{ij}=X_i+Y_j$ 的充要條件是**每個 $2\times2$ 區塊的** $M_{ij}=C_{ij}+C_{i+1,j+1}-C_{i,j+1}-C_{i+1,j}=0$(必要:代入即得;充分:$M\equiv0$ 讓相鄰欄差在每列相同,沿路徑 telescoping 得 $C_{ij}=C_{i,b}+C_{a,j}-C_{a,b}$)。對一個矩形 $+x$,內部與跨邊的區塊都正負抵消,**只有四個角落的區塊會變**。所以維護 $X_{ij}=[M_{ij}\ne0]$ 的二維 BIT:更新改 4 個點,查詢問矩形 $[r_1,r_2{-}1]\times[c_1,c_2{-}1]$ 的和是否為 $0$。$O(n^2+q\log^2n)$。

```cpp
// 更新 (r1,c1,r2,c2,+x) 後只有角落的四個 2x2 區塊會變
for (int i : {r1 - 1, r2})
    for (int j : {c1 - 1, c2}) refresh(i, j);  // 重算 M(i,j)、同步 X 到 2D BIT
// 查詢:bit.rect(r1, c1, r2 - 1, c2 - 1) == 0 ⟺ YES
```
:::

### [E. Six-Seven Bags](https://codeforces.com/contest/2273/problem/E)
`互動` `構造` `數學` `~2300`

::: info 題意
$n$ 袋硬幣,袋 $i$ 有 $a_i$ 枚;恰一袋是 6 克幣、其餘 7 克。一次詢問從各袋各拿 $b_i\le a_i$ 枚秤總重。**用最少次數**($f(a)$ 次,須自行算出)找出 6 克那袋,互動器 adaptive。

例:$a=(1,1,2,2,2)$:排序後第 $5$ 袋需要 $(2+1)^k\ge5$ → $k=2$;給五袋 $(0,0),(0,1),(1,0),(1,1),(0,2)$,兩次秤重就讀出藏著的那袋的向量。
:::

::: tip 作法
秤重回傳 $7\sum b_i-b_h$,等於**直接告訴你 $b_h$**。給每袋一個相異的 $k$ 維向量 $v_i$(每維 $\le a_i$),第 $j$ 次詢問拿 $v_{i,j}$ 枚,$k$ 次後讀出藏袋的整個向量。**下界**:排序 $a_1\le\dots\le a_n$,最小的 $i$ 袋每袋最多 $(a_i+1)^k$ 種向量,必須 $(a_i+1)^k\ge i$,所以 $k=\max_i\lceil\log_{a_i+1}i\rceil$。**構造**:向量依「最大分量 $m$」分層($(m+1)^k-m^k$ 個一層),第 $i$ 個向量的最大分量是最小的 $m$ 使 $(m+1)^k\ge i$,恰好 $\le a_i$。$O(nk)$。

```cpp
sort bags by a;  k = smallest k with (a_i + 1)^k >= i for all i (1-indexed)
// 依最大分量 m = 0, 1, 2, ... 列舉 k 維向量,取前 n 個,第 i 個給第 i 小的袋子
// 第 j 次詢問:b_i = v[i][j];回傳 7 * Σ b - b_h → 得到 v[h][j];k 次後對照向量表
```
:::
