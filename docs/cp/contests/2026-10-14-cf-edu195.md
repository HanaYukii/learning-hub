> 懶人包:每題「**題意 + 核心作法**」。收 A–E;F(排列著色博弈,分類加 $O(k^3)$ DP,估 ~2500 以上)、G(淘汰賽計數)不收。官方 rating 未出,難度 `~` 為題位估計。作法依[官方題解全文](https://codeforces.com/blog/entry/157752)整理,A–E 的 code 都以暴力對拍過。

### [A. Perfect Sandwiches](https://codeforces.com/contest/2276/problem/A)
`貪心` `數學` `~800`

::: info 題意
$a$ 片起司、$b$ 片香腸全部用完,每個三明治至少各一片且**起司嚴格多於香腸**。**求**最多幾個三明治,做不到 $-1$。

例:$a=6,b=4$:每個至少多一片起司 → $k\le a-b=2$;$k=2$ 可行(各 $3+2$)。
:::

::: tip 作法
$b\ge a$ 無解。否則每個三明治吃掉至少一片香腸($k\le b$)、至少一片「多出來的」起司($k\le a-b$),答案 $\min(b,a-b)$;先每個放 $2$ 起司 $1$ 香腸,剩下的照配對或單片起司塞回去即可。
:::

### [B. Replace and Compress](https://codeforces.com/contest/2276/problem/B)
`字串` `不變量` `~1100`

::: info 題意
01 字串($|s|\le3\times10^5$),至多翻一個**非首尾**字元,然後把每個極大同字元段壓成一個字元。**求**能得到幾種相異結果。

例:`100111011` → 不翻 `10101`;翻第 5 個得 `1010101`;翻第 7 個得 `101` → 3 種。
:::

::: tip 作法
首尾不動,壓縮後的字串由**長度**唯一決定(交替、首字元固定)。翻一個字元最多改變兩對相鄰關係,長度變化 $\in\{0,\pm2\}$(奇偶不變)。$+2$ 需要把 `000`/`111` 的中間翻掉;$-2$ 需要翻 `010`/`101` 的中間。答案 $1+[\exists\,000|111]+[\exists\,010|101]$。
:::

### [C. Subarrays](https://codeforces.com/contest/2276/problem/C)
`數論` `貪心` `~1300`

::: info 題意
正整數陣列與 $k<n\le2\times10^5$。子陣列 $k$-balanced $\iff$ 和被 $k$ 整除且**長度 $>k$**。**求**個數。

例:$[2,1,3,1,4]$、$k=2$:$[2,1,3]$ 和 $6$、$[3,1,4]$ 和 $8$ → 2(長度 $\ge3$ 才算)。
:::

::: tip 作法
前綴和 mod $k$ 相等且下標差 $>k$ 的配對數。雙指標:第二個指標落後第一個 $k+1$ 格,走到 $i$ 時先把 $p'_{i-k-1}$ 計入 `cnt`,再加 `cnt[p'_i]`。$O(n)$。

```cpp
for (int i = k + 1; i <= n; i++) {  // p'[0..n]:前綴和 mod k
    cnt[p[i - k - 1]]++;            // 只有距離 > k 的左端點進得了 cnt
    ans += cnt[p[i]];
}
```
:::

### [D. Caveman](https://codeforces.com/contest/2276/problem/D)
`圖論` `分類討論` `~1500`

::: info 題意
$n$ 點 $m$ 邊簡單圖($n,m\le3\times10^5$)。把點塗紅藍,要求**每個點都有至少一個異色鄰居**。**回答**合法塗法數是 $1$、$2$、「Many」($>2$)還是 $0$(Brain Melt)。

例:路徑 $1$-$2$-$3$-$4$:RBRB、BRBR、RBBR、BRRB 都合法 → Many;星圖 $1$-$2,1$-$3$:只有中心定色、葉子反色的兩種 → 2。
:::

::: tip 作法
孤立點 → $0$。否則任一連通分量都塗得出來(選一條邊兩端異色,再沿鄰接往外反色),而且塗法成對出現(紅藍互換)→ **不可能是 $1$**。多個分量 → 乘積 $>2$;含 4 點路徑 → 那條路徑本身就有 4 種;含環 → 也 $>2$(三角形 6 種)。剩下的只有**直徑 $\le2$ 的樹 = 星圖**,恰好 2 種。檢查最大度 $=n-1$ 且其餘度數全為 $1$。$O(n+m)$。
:::

### [E. Good Substrings](https://codeforces.com/contest/2276/problem/E)
`字串` `差分` `貪心` `~2000`

::: info 題意
數字字串 $s$($n\le3\times10^5$)。子串是 bad $\iff$ 含 `2025` 為子序列**且不含** `2026` 為子序列;否則 good。**對每個位置 $i$ 輸出**包含 $i$ 的 good 子串數。

例:`20256`:含 $i$ 的子串共 $5,8,9,8,5$ 個;唯一的 bad 子串是 `2025`(位置 $1..4$),整串因為有 `2026` 子序列而 good → 答案 $4,7,8,7,5$。
:::

::: tip 作法
固定左端 $l$,令 $r_{25}$ = 最小的 $r$ 使 $s[l..r]$ 含 `2025` 子序列、$r_{26}$ 同理(用 `nxt[i][d]` 貪心跳四步)。右端 $r$ 從 $l$ 掃過去:$[l,r_{25})$ good、$[r_{25},r_{26})$ **bad**、$[r_{26},n)$ 又 good(2026 一出現就永遠 good);$r_{25}\ge r_{26}$ 時全部 good。

位置 $i\ge l$ 從左端 $l$ 得到的貢獻 $=\#\{\text{good } r\ge i\}$,在每一段上都是**$i$ 的一次函數**(斜率 $-1$ 或 $0$)。用兩個差分陣列分別累加常數項與斜率,一次掃描還原。$O(n\cdot|2025|)$。

```cpp
for (int l = 0; l < n; l++) {
    int r25 = l, r26 = l;  // 用 nxt 貪心跳四步;跳不到就停在 n
    for (int t = 0; t < 4 && r25 < n; t++) r25 = nxt[r25][s25[t] - '0'];
    for (int t = 0; t < 4 && r26 < n; t++) r26 = nxt[r26][s26[t] - '0'];
    d[l] += n - l;
    dd[l + 1]--;      // 全部 good:i = l 起 n-l, n-l-1, ...
    if (r25 < r26) {  // 扣掉 bad 段 [r25, r26) 的貢獻
        d[l] -= r26 - r25;
        dd[r25 + 1]++;
        if (r26 < n) dd[r26 + 1]--;
    }
}
for (int i = 0; i < n; i++) {
    sum += d[i];
    add += dd[i];
    sum += add;
    ans[i] = sum;
}
```
