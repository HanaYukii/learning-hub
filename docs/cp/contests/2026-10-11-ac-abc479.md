### [F. Narrow Passage](https://atcoder.jp/contests/abc479/tasks/abc479_f)
`逆序對` `BIT` `貢獻` `AtC~1950`

::: info 題意
$N$ 個人在數線上相異整數點 $S_i$($\le10^9$),操作:選一個人往左或右移一格,目的地有人就**兩人交換**。**求**讓每個人 $i$ 到達 $T_i$(相異)的最少操作數。

例:人 1 在 $0$、人 2 在 $2$,目標 $1\to1$、$2\to3$:各走一步 → 2。公式:人–人配對依 $T$ 排序後 $S$ 名次 $(0,1)$ 無逆序;人–空位:人 1 左邊的空位數從 $0$ 變 $1$、人 2 從 $1$ 變 $2$ → $1+1$。合計 2。
:::

::: tip 作法
把數線看成長 $10^9{+}1$ 的陣列(人或空位),操作就是**相鄰交換**,最少次數 = 把 $A$ 排成 $B$ 的逆序對數(空位之間依序配對)。陣列太長不能直接數,但逆序對只有三種:

- **空位–空位**:依序配對,貢獻 $0$。
- **人–空位**:人 $x$ 在 $A$ 裡左邊的空位數 $=S_x-\text{rank}_S(x)$、在 $B$ 裡 $=T_x-\text{rank}_T(x)$,貢獻 $|$兩者之差$|$。
- **人–人**:依 $T$ 排序後,$S$ 名次序列的逆序對,BIT $O(N\log N)$。

```cpp
// rS[x]、rT[x]:人 x 的 S、T 名次(0-indexed)
for (int x = 0; x < N; x++) ans += llabs((S[x] - rS[x]) - (T[x] - rT[x]));  // 人–空位
for (int k = 0; k < N; k++) {                                               // 人–人:依 T 排序,數 S 名次的逆序對
    int x = ordT[k];
    ans += k - bit.query(rS[x]);  // 前面已放、名次比我大的
    bit.add(rS[x]);
}
```
