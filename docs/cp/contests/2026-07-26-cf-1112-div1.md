### [A. Rank Subsequence](https://codeforces.com/contest/2249/problem/A)
`貪心` `分類討論` `~1300`

::: info 題意
$n$ 個元素排成一列,刪掉一些後剩下長度 $m$ 的子序列;第 $j$ 個的左名次是 $j$、右名次是 $m-j+1$。元素 $i$ 合法 $\iff$ 左名次 $\notin[l_i,r_i]$ 且右名次 $\notin[u_i,v_i]$。**求**全部元素都合法的最長子序列長度(可為 $0$)。$n\le5000$。

例:元素 1 禁左名次 $2$、右名次 $1$;元素 2 禁左名次 $1$、右名次 $2$。單獨留哪個都不行(左名次 $1$ 或右名次 $1$ 會踩到),兩個都留時名次是 $(1,2),(2,1)$ 都合法 → 2。
:::

::: tip 作法
右名次依賴最終長度 $m$,所以**枚舉 $m$**(從大到小,第一個可行的就是答案)。固定 $m$ 後每個位置 $j$ 的合法條件就固定了,從左到右貪心:遇到能放在位置 $j$ 的元素就立刻放——換成更早的合法元素不會讓後面更難(交換論證)。$O(n^2)$。

```cpp
auto check = [&](int m) {  // 能否湊出長度恰 m 的合法子序列
    int j = 1;
    for (int i = 0; i < n && j <= m; i++) {
        int x = m - j + 1;                                          // 右名次
        if ((j < l[i] || j > r[i]) && (x < u[i] || x > v[i])) j++;  // 能放就放
    }
    return j == m + 1;
};
for (int m = n; m >= 1; m--)
    if (check(m)) return m;
return 0;
```
:::

### [B. Permutation Cuts](https://codeforces.com/contest/2249/problem/B)
`組合計數` `分類討論` `~1700`

::: info 題意
長 $n$ 排列 $p$,$v_i=\min(\max_{j\le i}p_j,\ \max_{j>i}p_j)$。給 $a_1..a_{n-1}$,**數**有幾個排列的 $v=a$,mod $998244353$。$n\le10^6$。

例:$n=4$、$a=(2,3,3)$:$p_1$ 必須是 $2$(右邊含 $4$,所以 $v_1$ 就是 $p_1$);$p_2\in\{3,4\}$,得 $(2,3,1,4)$ 與 $(2,4,1,3)$ 兩個。
:::

::: tip 作法
$n$ 落在切點的某一側,對面那側的最大值就是 $v_i$,所以 $a_i\ne n$;以 $n$ 的位置為界,**左邊的 $a$ 非遞減、右邊非遞增**,兩邊都非空時交界處 $a_c\ne a_{c+1}$(同一個值不能同時是兩側的最大)。候選分界只有常數個:同時屬於前綴非遞減段與後綴非遞增段的下標是一段等值區間,內部相鄰相等的不能當交界。

固定分界後,把左半與**反轉的右半**歸併成一個非遞減序列,逐個看值 $x$:第一次出現的 $x$ 位置被釘死(該側的最大值就在這裡變成 $x$);重複出現的可以填任何還沒用過、比 $x$ 小的值,已用掉 $i-1$ 個 → $x-i+1$ 種。各分界的方案加總,$O(n)$。

```cpp
// l = a[1..cut],r = 反轉的 a[cut+1..n-1];歸併成非遞減序列逐值處理
while (x < l.size() || y < r.size()) {
    int w = pick smaller of l[x], r[y];  // 相等 → 整題 0
    if (!vis[w])
        vis[w] = 1;  // 第一次出現:位置釘死
    else
        ways = ways * max(0, w - used) % MOD;  // 再出現:填任一未用且 < w 的值
    used++;
}
```

### [C. Double-Rift Dial](https://codeforces.com/contest/2249/problem/C)
`線段樹` `離線` `貢獻` `~2000`

::: info 題意
環形排列 $p$,從起點 $s$ 順時針讀一圈得 $q$;$q$ 每個非空前綴的值集合切成極大連續整數段(block)。$s$ 是 good $\iff$ 每個前綴的 block 數 $\le2$。**求** good 起點的個數。$n\le2\times10^5$。

例:$p=(1,3,5,2,4)$:從位置 1 讀前三個得 $\{1,3,5\}$,三個 block,不 good;其他 4 個起點都 good。
:::

::: tip 作法
把排列複製兩倍,起點 $s$ 的前綴就是普通區間 $[s,s+k]$。右端 $r$ 從左往右掃,插入值 $x$ 時受影響的起點是 $[\max(1,r-n+1),\min(r,n)]$;block 數的變化 $\Delta=1-[x-1\text{ 已在區間內}]-[x+1\text{ 已在區間內}]$,而「$x-1$ 在 $[l,r-1]$ 內」$\iff\text{last}_{x-1}\ge l$。所以只要**三次區間加減**(全段 $+1$、$\text{last}_{x-1}$ 以前 $-1$、$\text{last}_{x+1}$ 以前 $-1$),lazy 線段樹維護每個起點目前的 block 數與全域最大值。一旦某個起點超過 2 就**永久出局**(之後再降也救不回那個前綴),把它的值設成 $-\infty$。每個起點至多刪一次,$O(n\log n)$。

```cpp
for (int r = 1; r < 2 * n; r++) {
    int L = max(1, r - n + 1), R = min(r, n), x = p[(r - 1) % n + 1];  // 受影響的起點區間
    add(L, R, +1);                                                     // x 自成一段
    if (x > 1 && last[x - 1] >= L) add(L, min(R, last[x - 1]), -1);    // 這些起點已含 x-1:併段
    if (x < n && last[x + 1] >= L) add(L, min(R, last[x + 1]), -1);
    last[x] = r;
    while (globalMax() > 2) {
        kill(findBad());
        ans--;
    }  // 超過 2 段的起點永久出局
}
```

### [D. Xor Permutation Matrix](https://codeforces.com/contest/2249/problem/D)
`構造` `XOR` `位元` `~2300`

::: info 題意
造 $n\times n$ 矩陣,每列、每欄都是 $0..n-1$ 的排列,且每個相鄰 $2\times2$ 子矩陣四數的 XOR 都等於 $x$($n\le2500$、$0\le x<n$)。**輸出**任一解或判定無解。

例:$n=4$、$x=0$:$A_{i,j}=i\oplus j$。$n=2$、$x=1$ 無解($2\times2$ 拉丁方每個值出現兩次,XOR 恆為 $0$);$n=3$ 一律無解。
:::

::: tip 作法
相鄰兩列的差 $d_i(j)=A_{i,j}\oplus A_{i+1,j}$ 隨欄的奇偶交替($d(j+1)=d(j)\oplus x$),所以同奇偶的列彼此是「整列 XOR 某個 $h$」的關係,需要至少 $\lceil n/2\rceil$ 個相異的 $h$ 使 $S\oplus h=S$($S=\{0..n-1\}$)。而 **$S$ 的 XOR 穩定子恰好是 $\{0,\dots,\mathrm{lowbit}(n)-1\}$**:$h$ 有更高位時會把長 $\mathrm{lowbit}(n)$ 的區塊兩兩配對,但區塊數 $n/\mathrm{lowbit}(n)$ 是奇數,配不完。$\mathrm{lowbit}(n)\ge\lceil n/2\rceil$ 只在 $n$ 是 2 的冪時成立;$n=2$、$x>0$ 另外無解。

構造:$x=0$ 用 $A_{i,j}=i\oplus j$。$x>0$、$n\ge4$:把 $y\leftrightarrow y\oplus x$ 配成 $n/2$ 對,拿 $n/4$ 對當集合 $O$、其餘當 $E$(兩者都在 $\oplus x$ 下封閉),排列 $p$ 把 $E$ 放偶數位、$O$ 放奇數位,令 $A_{i,j}=p_i\oplus p_j\oplus[i,j\text{ 皆奇}]\,x$:偶數列是 $p$ 的平移;奇數列偶數欄是 $p_i\oplus E$、奇數欄是 $p_i\oplus(O\oplus x)=p_i\oplus O$,合起來仍是 $S$;$2\times2$ 內 $p$ 兩兩抵消,四個奇偶組合恰有一個 $(奇,奇)$ 留下 $x$。$O(n^2)$。

```cpp
if ((n & (n - 1)) || (x && n < 4)) return -1;  // 只有 2 的冪;n = 2 只允許 x = 0
if (!x)
    A[i][j] = i ^ j;
else {
    // 配對 y <-> y^x;前 n/4 對進 O,其餘進 E;p:E 放偶數位、O 放奇數位
    A[i][j] = p[i] ^ p[j] ^ (((i & 1) && (j & 1)) ? x : 0);
}
```
