### [A. K Is Important](https://codeforces.com/contest/2268/problem/A)
`貪心` `分類討論` `~1200`

::: info 題意
長 $n$ 的正整數陣列與參數 $k$($k\le n\le10^5$)。只要陣列長度 $m\ge k$ 就必須操作一次:刪掉**左數第 $k$ 個**或**右數第 $k$ 個**(即 $a_{m-k+1}$),得到它的值。**求**總得分的最大值。

例:$a=[1,4,8,2,6,3]$、$k=3$:中間的 $a_3,a_4=8,2$ 一定會被刪(加 $10$);配對 $(1,3)\to3$、$(4,6)\to6$ → $19$。
:::

::: tip 作法
$2k\le n$ 時,中間段 $[k,\ n-k+1]$ 的元素**不管怎麼操作最後都會被刪**(它們總會落到左數或右數第 $k$ 個),全部收進答案。剩下左右各 $k-1$ 個:當陣列縮到長度 $k+i-1$ 時,左數第 $k$ 與右數第 $k$ 恰好是原來的 $a_{n-i+1}$ 與 $a_i$,**必須二選一刪**,所以每對 $(a_i,a_{n-i+1})$ 貪心取 $\max$。$2k>n$ 時角色互換:中間 $[n-k+2,\ k-1]$ 在長度掉到 $k$ 以下前永遠碰不到,安全;兩端 $i\le n-k+1$ 的配對同樣取 $\max$。雙指標 $O(n)$。

```cpp
long long sum = 0;
vector<long long> vec;
for (int i = 1; i <= n; i++) {
    if (i >= k && i <= n - k + 1)
        sum += a[i];  // 中間段:必刪
    else
        vec.push_back(a[i]);
}
int pairs = max(0, (int)vec.size() - (k - 1));  // 2k <= n 時 k-1 對;2k > n 時 n-k+1 對
for (int l = 0, r = vec.size() - 1; pairs--; l++, r--) sum += max(vec[l], vec[r]);
```

### [B. What a SauSaGe! It's All Meat](https://codeforces.com/contest/2268/problem/B)
`位元` `不變量` `~1500`

::: info 題意
$a_i<16$。操作:選相鄰的 $i,i+1$ 與 $k\in[1,5]$,兩者**同時** XOR $3k$。All-Meat = 值被 $3$ 整除。$q$ 次單點修改($\sum n,\sum q\le2\times10^5$),每個狀態**問**最多能有幾個 All-Meat。

例:$[10,3]$:$10=1010_2$、$3=0011_2$ 都是偶 popcount → 2(對 $(1,2)$ XOR $3$ 得 $[9,0]$)。$[1,2,3,4]$:只有 $3$ 是偶 popcount → 1。
:::

::: tip 作法
mask $3,6,9,12,15=0011,0110,1001,1100,1111$ **全是偶 popcount**,所以每個元素 popcount 的奇偶不變;而 $<16$ 的 $3$ 的倍數 $0,3,6,9,12,15$ 也全是偶 popcount → 奇 popcount 的元素永遠當不了 All-Meat,上界 $=\#\{\text{偶 popcount}\}$。

上界可達:沿 $i,i+1,\dots,j$ 一路做同一個 mask,中間的被 XOR 兩次抵消,等於**對任意兩個元素同時 XOR**;偶 popcount 的 4 位 mask 共 8 個,$5=3\oplus6$、$10=3\oplus9$,所以兩個元素可以同時 XOR 任何偶 popcount 的值。有奇 popcount 元素時拿它當 buffer,每個偶元素跟 buffer 一起 XOR 自己 → 歸零(buffer 仍是奇)。全偶時拿 $a_1$ 當 buffer 把其他全歸零,剩 $x=\bigoplus a_i$(偶 popcount);$x\in\{5,10\}$ 時對前兩個再 XOR $3$ 得 $(6,3)$ 或 $(9,3)$。答案就是偶 popcount 的個數,修改 $O(1)$。
:::

### [C. KiaKio and Energy Intervals](https://codeforces.com/contest/2268/problem/C)
`位元` `XOR` `分治` `樹` `~2300`

::: info 題意
$a_1..a_n$($n\le2\times10^5$、$a_i<2^{18}$)。選 $l<r$,令 $m=\max(a_l..a_r)$,能量 $=(a_l\&m)\oplus\cdots\oplus(a_r\&m)$。**求**最大能量。

例:$[1,7,3,7,2]$:取 $l=1,r=2$,$m=7$,$(1\&7)\oplus(7\&7)=1\oplus7=6$,是最大。
:::

::: tip 作法
AND 對 XOR 可分配:能量 $=(p_{l-1}\oplus p_r)\&m$,$p$ 是 prefix XOR。區間 max 由**最大笛卡兒樹**給:$\text{LCA}(l,r)=v$ 的區間的 $m$ 就是 $a_v$,而且 $v$ 的子樹對應連續段 $[L,R]$、$l-1\in[L-1,v-1]$、$r\in[v,R]$。

答案**逐位貪心**:高位已定、試加某位得候選 $M$,可行 $\iff$ 存在區間能量 $\supseteq M$ $\iff$ 存在節點 $v$ 使 $a_v\&M=M$,且 $s_{l-1}\oplus s_r=M$($s_i=p_i\&M$)。在笛卡兒樹上**啟發式合併**:大的一側留在計數陣列,掃小的一側逐個查 $s_x\oplus M$ 存不存在;要排除 $(v-1,v)$ 這一對——它對應長度 1 的區間 $[v,v]$,且 $a_v\&M=M$ 時必定命中,是假陽性。每個 index 被掃 $O(\log n)$ 次,一次檢查 $O(n\log n)$,18 位共 $O(18\,n\log n)$。

int mid = getmx(l, r);
if (r - mid > mid - l) {  // 右側大:留右側,掃左側端點 x = l-1..mid-1

} else { /* 鏡像:留左側(含 pref[l-1]),掃右側 y = mid..r */
