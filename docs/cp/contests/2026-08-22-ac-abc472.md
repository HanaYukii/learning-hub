# ABC472 — 學習重點

> A–E 熱身略過(E 為 AtC~1050);收 F、G。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc472/editorial)整理,兩題都以暴力對拍過(F 對隨機凸包所有切片、G 對小格子枚舉所有合法格局)。

### [F. Centroid of a Slice](https://atcoder.jp/contests/abc472/tasks/abc472_f)
`幾何` `數學` `AtC~1700`

::: info 題意
凸 $N$ 邊形($N\le3\times10^4$,頂點逆時針給),$Q\le2\times10^5$ 個詢問 $(u,v)$(不相鄰)。線段 $uv$ 把多邊形切成兩塊,取**在有向線 $u\to v$ 右側**的那塊,**輸出**它的幾何中心(均勻薄板的質心),誤差 $10^{-6}$。

例:正方形 $(0,0),(1,0),(1,1),(0,1)$,詢問 $u=1,v=3$:右側是三角形 $(0,0),(1,0),(1,1)$,質心 $(2/3,\,1/3)$。
:::

::: tip 作法
逆時針凸多邊形裡,$u\to v$ 右側那塊就是頂點 $u,u+1,\dots,v$(循環)。面積與**一次矩**(面積 $\times$ 質心)都可加:以原點 $O$ 為基準,多邊形 $=\sum$ 三角形 $OP_iP_{i+1}$(帶號)加上封口的 $OP_vP_u$,質心 $=\sum m/\sum\text{area}$。把 $2\,\text{area}(OP_iP_{i+1})=x_iy_{i+1}-x_{i+1}y_i$ 與 $6\,m=(x_i+x_{i+1})\cdot(\text{那個叉積})$($y$ 同理)做前綴和(陣列複製兩倍處理循環),每個詢問 $O(1)$。

**前綴和要用整數**——浮點數在相減時會把精度抵消掉,直接 WA;題解證明 $6m$ 的區段和 $\le8R^3=10^{18}$,64 位剛好放得下,最後才做一次浮點除法。$O(N+Q)$。

```cpp
// 頂點陣列複製兩倍;ca = 2*area(O P_i P_{i+1})、mx/my = 6*一次矩 的前綴和(全部 long long)
int l = u, r = v < u ? v + N : v;         // 右側那塊 = 頂點 u..v(逆時針)
long long c = x[r] * y[l] - x[l] * y[r];  // 封口三角形 O P_v P_u
long long A = ca[r] - ca[l] + c;
long long MX = mx[r] - mx[l] + (x[r] + x[l]) * c;
long long MY = my[r] - my[l] + (y[r] + y[l]) * c;
printf("%.10f %.10f\n", (double)MX / (3.0 * A), (double)MY / (3.0 * A));
```
:::

### [G. Cascading Grid](https://atcoder.jp/contests/abc472/tasks/abc472_g)
`flow` `dp` `狀壓` `AtC~2000`

::: info 題意
$H\times W$ 格子($\le30$),每格是 `+`、`-` 或 `#`。操作:選一個非 `#` 的格子,把「從它出發只往**左、右、下**走、不穿過 `#` 能到的所有格子」全部變成 `#`。**求**操作後「`+` 的格數 $-$ `-` 的格數」的最大值。

例:`+` 在上、`-` 在下(2×1):選 `-` 那格只會塗掉自己,答案 1;倒過來 `-` 在上、`+` 在下,想丟掉 `-` 會連下面的 `+` 一起吞掉,答案 0。
:::

::: tip 作法
操作後的格局只受兩條限制:同一列左右相連(中間不隔 `#`)的格子**要嘛全留要嘛全塗**;下面那格留著則上面那格也得留著(塗了上面就一定塗到下面)。反過來滿足這兩條的任何格局都做得到。這正是**閉包 / 最小割**的形狀:留 $=S$ 側、塗 $=T$ 側,「$u$ 留 $\Rightarrow v$ 留」連 $u\to v$ 容量 $\infty$;先假設拿滿所有 `+`,塗掉一個 `+` 損失 1($s\to v$ 容量 1)、留下一個 `-` 損失 1($v\to t$ 容量 1),答案 $=\#(\texttt{+})-\text{最小割}$。點、邊都 $O(HW)$,Dinic 秒過。

另一條路:每列的 `#` 把格子切成至多 $\lceil W/2\rceil\le15$ 段,每段整段留或塗;狀壓 $dp[\text{列}][\text{段的留塗}]$,上一列被塗的段會強迫下一列跟它相交的段也塗,對上一列的 dp 做 superset max(zeta 變換)就能 $O(1)$ 轉移,$O(HW\cdot2^{W/2})$。

```cpp
// 每個非 # 格一個點;留 = S 側、塗 = T 側
for (int i = 0; i < h; i++)
    for (int j = 0; j < w; j++) {
        if (a[i][j] == '#') continue;
        int v = i * w + j;
        if (a[i][j] == '+') {
            add(s, v, 1);
            plus++;
        }  // 塗掉 + 損失 1
        else
            add(v, t, 1);  // 留下 - 損失 1
        if (j + 1 < w && a[i][j + 1] != '#') {
            add(v, v + 1, INF);
            add(v + 1, v, INF);
        }                                                         // 左右同留同塗
        if (i + 1 < h && a[i + 1][j] != '#') add(v + w, v, INF);  // 下面留 ⇒ 上面留
    }
answer = plus - maxflow(s, t);
```
:::
