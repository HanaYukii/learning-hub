# ABC470 — 學習重點

> A–D 熱身略過(C 為 AtC~1000、D 為 AtC~800);收 E、F、G。難度 `AtC~` 為 kenkoooo 原值。作法依[官方 editorial](https://atcoder.jp/contests/abc470/editorial)整理,E 以 $N\le3$ 的完整 expectimax 對拍、F 以偶數步 BFS 對拍、G 以 $O(N^3)$ 暴力對拍。

### [E. Concentration](https://atcoder.jp/contests/abc470/tasks/abc470_e)
`機率期望` `dp` `AtC~2100`

::: info 題意
$2N$ 張牌,數字 $A_1,\dots,A_N$ 各兩張,洗勻後蓋著;生命 $L$($N,L\le200$)。每回合翻兩張:相同就拿走、得分加該數字;不同就蓋回去(記得它們)、生命減一。生命歸零或牌拿完就結束。**求**最佳策略下最終得分的期望。

例:$N=2$、$L=1$:第一張翻開後,第二張猜中搭檔的機率 $1/3$,中了就再拿最後一對,共兩對;猜錯生命歸零。期望對數 $2/3$,期望得分 $\frac23\cdot\frac{A_1+A_2}2=\frac{A_1+A_2}3$。
:::

::: tip 作法
兩個觀察把牌面數字甩掉:**有已知的一對就先拿**(不扣命只賺),第一張翻到已知牌的搭檔就配它;**其餘情況一律翻未知牌**(翻已知牌沒有資訊)。所以策略與數字無關,答案 $=X\cdot\frac{\sum A_i}N$,$X$ 是期望拿到的對數。

$f(L,C_0,C_1)$ = 生命 $L$、場上還有 $C_0$ 對完全未知、$C_1$ 張已知單身(搭檔未知)時,之後還能拿到的期望對數。一回合四種結果:第一張是某已知牌的搭檔(直接配);第一張來自未知對而第二張剛好是它的搭檔;第二張來自另一個未知對(失敗,兩張都變已知);第二張是某已知牌的搭檔(失敗,但下回合白拿一對)。$2C_0+C_1$ 嚴格遞減,$O(LN^2)$ 個狀態、常數個轉移。

```cpp
double f(int L, int C0, int C1) {  // 未知牌 U = 2*C0 + C1 張
    if (L == 0 || C0 + C1 == 0) return 0;
    if (C0 == 0) return C1;                                                    // 剩下的全是已知牌的搭檔,免費收完
    double U = 2 * C0 + C1, res = C1 / U * (1 + f(L, C0, C1 - 1));             // 第一張是已知牌的搭檔
    double rest = 1 / (U - 1) * (1 + f(L, C0 - 1, C1));                        // 第二張剛好是搭檔
    if (C0 >= 2) rest += (2.0 * C0 - 2) / (U - 1) * f(L - 1, C0 - 2, C1 + 2);  // 撞到另一對:失敗,兩張變已知
    rest += C1 / (U - 1) * (L - 1 >= 1 ? 1 + f(L - 1, C0 - 1, C1) : 0);        // 第二張是已知牌的搭檔:失敗,下回合白拿
    return res + 2 * C0 / U * rest;
}
// 答案 = f(L, N, 0) * sum(A) / N
```
:::

### [F. Googol Swaps](https://atcoder.jp/contests/abc470/tasks/abc470_f)
`組合計數` `排列` `AtC~1600`

::: info 題意
長 $N$ 的小寫字串 $S$,$M$ 條允許交換的位置對 $(A_i,B_i)$($N,M\le2\times10^5$)。**恰好**做 $10^{100}$ 次交換(每次任選一條),**求**能得到的字串種數 mod $998244353$。

例:$S=$`abc`、可交換 $(1,2),(2,3)$:三個位置連通,6 種排列裡只准偶排列的 3 種(`abc`、`bca`、`cab`)。若 $S=$`aab`,交換兩個 `a` 可以白白翻一次奇偶,$\frac{3!}{2!}=3$ 種全到得了。
:::

::: tip 作法
位置連邊成圖,每個連通分量內任意排列都做得到(至多 $N^2$ 步),但總步數固定是偶數 → 位置的置換必須是**偶排列**。某個分量裡有重複字母時,交換那兩個相同字母不改字串卻翻奇偶,所以所有排法都到得了;沒有任何分量有重複字母時,排法與置換一一對應,恰好一半是偶排列。答案 $=\prod_{\text{分量}}\frac{\text{size}!}{\prod_c\text{cnt}_c!}$,再視情況除以 $2$。$O((N+M)\alpha)$。

```cpp
bool rep = false;  // 有沒有分量含重複字母
for (int i = 0; i < N; i++) {
    int r = dsu.find(i);
    if (++cnt[r][s[i]] >= 2) rep = true;
}
long long ans = 1;
for (int r = 0; r < N; r++) {
    if (sz[r] == 0) continue;
    ans = ans * fact[sz[r]] % MOD;
    for (auto [c, k] : cnt[r]) ans = ans * inv(fact[k]) % MOD;  // 多項式係數
}
if (!rep) ans = ans * inv(2) % MOD;  // 只有偶排列那一半
```
:::

### [G. ΣШX](https://atcoder.jp/contests/abc470/tasks/abc470_g)
`貢獻` `線段樹` `AtC~2100`

::: info 題意
長 $N$ 的非負整數序列($N\le3\times10^5$、$A_i\le N$)。**求**所有子陣列的 $\operatorname{mex}$ 總和。

例:$A=(0,1,0)$:六個子陣列的 mex 是 $1,0,1,2,2,2$ → 8。
:::

::: tip 作法
$\operatorname{mex}\ge k+1\iff$ 區間含 $0..k$ 全部,所以 $\sum\operatorname{mex}=\sum_k|S_k|$,$S_k$ = 含 $0..k$ 的區間集合。對左端 $l$ 令 $\text{maxnext}_k[l]=\max_{m\le k}\text{next}_m[l]$(從 $l$ 起各值第一次出現位置的最大值),則 $[l,r]\in S_k\iff r\ge\text{maxnext}_k[l]$,$|S_k|=\sum_l(N+1-\text{maxnext}_k[l])$。

$k$ 遞增時 maxnext 只做「區間 chmax $\text{next}_k$」:值 $k$ 出現在 $x_1<\dots<x_c$,對 $l\in(x_{i-1},x_i]$ 做 chmax $x_i$。關鍵是 **maxnext 對 $l$ 單調不減**,所以 chmax 等於「二分找到第一個 $\ge x_i$ 的位置,把它前面整段賦值成 $x_i$」——區間賦值 + 全體和的 lazy 線段樹,或像 ODT 一樣用 map 存等值段,均攤 $O(N\log N)$。

```cpp
// maxnext 單調不減;k 由小到大,值 k 的出現位置 x_1 < ... < x_c(補 x_0 = 0、x_{c+1} = N+1)
for (int i = 1; i <= c + 1; i++) {  // l ∈ (x_{i-1}, x_i] 做 chmax x_i
    int lo = x[i - 1] + 1, hi = x[i];
    int p = firstGE(lo, hi, x[i]);  // 單調 → 二分:第一個 maxnext[p] >= x_i
    assign(lo, p - 1, x[i]);        // 前面整段賦值成 x_i
}
ans += (long long)N * (N + 1) - sum(1, N);  // |S_k| = Σ_l (N + 1 - maxnext[l])
```
:::
