> 懶人包:每題「**題意 + 核心作法**」。收 A–E(D1 併進 D2);F1/F2(run-twice 通訊構造)、G、H 超過 ~2500 上限不收。官方 rating 未出,難度 `~` 為題位估計。作法依[官方題解全文](https://codeforces.com/blog/entry/157917)整理,五題都以暴力對拍過(A 用 4、6 回合的 minimax、D2 用枚舉所有新偵測器組合、E 用 BFS)。

### [A. Hey, It's Me, Souvlakity](https://codeforces.com/contest/2261/problem/A)
`博弈` `不變量` `~900`

::: info 題意
$1..n$ 分給兩人(01 字串),$10^{100}$ 回合輪流把自己的一個整數**送給對方**,Souvlakity 先手。結束後他的分數 = 他手上整數的 $\max-\min$;他想最大、對方想最小。**求**最終分數。

例:`1100` → 他有 $\{1,2\}$,兩個時對方永遠把剛收到的還回來,分數 $1$;`111` → 三個以上,送中間的、對方還回來,維持 $\max-\min=2$。
:::

::: tip 作法
每兩回合他送一個、收一個,**持有個數 $k$ 不變**。$k=1$ → $0$;$k=2$ → 對方總能還他剛送出的那個相鄰數,$1$;$k\ge3$ → 他永遠送非極值、對方只能原樣奉還,分數 $=\max(S)-\min(S)$。$O(n)$。
:::

### [B. What's the Capital of France?](https://codeforces.com/contest/2261/problem/B)
`位元` `貪心` `~1300`

::: info 題意
一排餐廳評分 $a_i$。操作:選相鄰兩家,**較低的那家 $+1$**(相等則無事)。**求**所有評分 OR 的最大值。

例:$[4,6]$:$4\to5$ 得 $5|6=7$;$[1,2]$:不動就是 $3$;$[8,8,8]$ 永遠動不了 → $8$。
:::

::: tip 作法
最大值永遠不會變,所以答案的最高位就是 $\max$ 的最高位。令 $k=\text{msb}(\max\oplus\min)$:比 $k$ 高的位元 $\max,\min$ 相同、動不了;第 $k$ 位 $\max$ 是 $1$、$\min$ 是 $0$,把最小的那家一路加到 $2^k-1$ 以下的位全滿(每次都有更大的鄰居可以靠)→ 答案 $\max\,|\,(2^{k+1}-1)$;$\max=\min$ 時就是 $\max$。$O(n)$。
:::

### [C. I Know About a Million Things](https://codeforces.com/contest/2261/problem/C)
`博弈` `分類討論` `~1500`

::: info 題意
陣列正整數,輪流移除一個非空子集:要嘛**恰一個**元素,要嘛**總和為偶數**。面對空陣列的人輸。**判定**先手(Moggity)是否必勝。

例:$[2,3]$:不能一次拿完(和 $5$ 奇),拿一個後對方拿剩下的 → 後手勝。$[7]$:先手直接拿完。
:::

::: tip 作法
只有**偶數個數 $E$、奇數個數 $O$** 重要。奇數個數 $O$ 為偶 → 全拿;$O=1$:$E=0$ 全拿,$E=1$ 是必敗態 $(1,1)$,$E\ge2$ 拿走 $E-1$ 個偶數把 $(1,1)$ 丟給對方;$O=3$:$E=0$ 必敗 $(0,3)$,否則拿光偶數丟 $(0,3)$;$O\ge5$ 奇 → 拿光偶數和 $O-3$ 個奇數。所以**後手贏 $\iff(E,O)\in\{(1,1),(0,3)\}$**。$O(n)$。
:::

### [D2. Come Be My Friend, Don't Be So Scared](https://codeforces.com/contest/2261/problem/D2)
`構造` `離線` `貪心` `~2200`

::: info 題意
$n$ 個藏身點排成一列,已有 $m$ 個偵測器(各覆蓋一段)。要再裝最少幾個偵測器,使**任何藏身點的回報向量都互不相同**,並輸出方案。D1 是 $m=0$ 的特例。

例:$n=5,m=0$:三個偵測器 $[1,3],[2,4],[3,5]$ 讓五個點的回報分別是 $100,110,111,011,001$,兩兩不同;兩個不夠(見作法的下界)。
:::

::: tip 作法
**D1 的下界**:每個偵測器是一段區間,從左到右回報最多變兩次;相鄰兩點要能區分至少要 $n-1$ 次變化,而且頭尾不能都是全 $0$,再多一次 → $k\ge\lceil n/2\rceil$;構造偵測器 $i$ 蓋 $[i,i+k-1]$,前 $k$ 個點各「開」一個、後面各「關」一個。

**D2**:先用隨機 XOR hash 算出每個點的既有回報 $h_i$。$h_i=h_j$ 的相鄰同值對 $(i,\text{nxt}_i)$ 之間必須落下一個新的邊界(偵測器端點);這些區間**兩兩不交或包含**(交叉會逼出某個既有偵測器不連續),只留**極小**的 $q$ 個(兩兩不交),每個放一個邊界、貪心放在右端點前。$q$ 個邊界配成 $\lceil q/2\rceil$ 個偵測器,用 D1 的「開 $k$ 個再關 $k$ 個」配法:邊界排序後第 $i$ 個偵測器蓋 $(c_i,c_{i+k}]$。$q$ 奇數補一個邊界在最左;$q$ 偶數但**最左區塊與最右區塊有共同的既有回報**時,要在兩端各補一個(多一個偵測器),否則那兩塊的新回報都全 $0$ 分不開。期望 $O(n+m)$。

// h[i] = 覆蓋 i 的既有偵測器的 XOR hash;nxt[i] = 下一個同 hash 的位置
// 極小區間 (i, nxt_i):內部沒有任何 j 有 nxt_j(laminar → 等價)
for (int i = 1; i <= n; i++)

### [E. What Does the Cow Say?](https://codeforces.com/contest/2261/problem/E)
`貪心` `分類討論` `~2300`

::: info 題意
長 $n$ 的合法括號序列,操作至多 $k$ 次:刪掉一組相鄰的 `()`,再把整串包一層 `( … )`。**求**操作後「連續 `(` 的最長長度」的最大值。

例:`()()()`、$k=2$:刪第一組得 `(()())`,再刪得 `((()))` → 3。
:::

::: tip 作法
令 $c_i$ = 第 $i$ 個 `)` 前面緊接的 `(` 個數。一次操作刪掉一個 `)`、把它前後兩段 `(` **合併**,並把一個 `(` 送到最前面。最後的最長段只有兩種形狀:**前綴**——對前 $i-1$ 個 `)` 各做一次,前綴長 $c_1+\dots+c_i$,剩下的操作每次再送一個 `(` 到前面($+1$,上限 $m=n/2$);或**中間的視窗** $[l,r]$($l>1$)——需 $r-l$ 次操作,每次送走一個 `(`,長度 $\sum_{j=l}^{r}(c_j-1)+1$。後者對 $c_j-1$ 的前綴和用寬 $k+1$ 的**滑窗最小值**,$O(n)$。

```cpp
// c[1..m]:第 i 個 ')' 前的 '(' 數
for (int i = 1; i <= m; i++) {
    cur += c[i];
    if (i - 1 <= k) mx = max(mx, min(m, cur + k - (i - 1)));
}                               // 前綴型
for (int y = 1; y <= m; y++) {  // 視窗型:pre[j] = Σ (c - 1)
    int x = y - 1;
    while (!dq.empty() && pre[dq.back()] >= pre[x]) dq.pop_back();
    dq.push_back(x);
    while (dq.front() < y - (k + 1)) dq.pop_front();  // 視窗長 <= k+1
    mx = max(mx, min(m, pre[y] - pre[dq.front()] + 1));
}
```
