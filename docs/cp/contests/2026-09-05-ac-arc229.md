# ARC229 — 學習重點

> 依本地 A–D 程式碼整理，對照[官方題解](https://atcoder.jp/contests/arc229/editorial)補上推導與邊界；並非提交結果紀錄。難度 `AtC~` 為整理時的 kenkoooo 估值，可能隨模型更新。

### [A. AtCoder Reverse Contest](https://atcoder.jp/contests/arc229/tasks/arc229_a)
`構造` `逆序對` `AtC~1050`

::: info 題意
字串每次可以把一段連續的 `ARC` 替換成 `CRA`，令 $f(S)$ 為最多能操作幾次。

給定 $0\le X\le600$，**輸出一個長度介於 1 到 100 的大寫字串**，使 $f(S)=X$。

例：`ARARC → ARCRA → CRARA`，恰好能操作兩次。
:::

::: tip 作法
**把 `R` 固定在分隔位置，`ARC → CRA` 就是把相鄰的 `A,C` 交換成 `C,A`。** 每次恰好消掉一個「A 在 C 前面」的逆序對，直到所有 C 都在 A 前面，因此只需構造恰好 $X$ 個逆序對。

令 $X=30q+r$，輸出 `(AR)` 重複 $r$ 次；若 $r>0$ 才接 `CR`，再接 `(AR)` 重複 $30-r$ 次，最後接 $q$ 個 `CR`。中間的 C 貢獻 $r$，尾端各個 C 貢獻 30，總計 $r+30q=X$。

```cpp
int q = x / 30, r = x % 30;
string ans;
for (int i = 0; i < r; i++) ans += "AR";
if (r > 0) ans += "CR";
for (int i = r; i < 30; i++) ans += "AR";
for (int i = 0; i < q; i++) ans += "CR";
cout << ans << '\n';
```

**餘數為 0 時，不要放那個額外的 `CR`。** 此時長度為 $60+2q\le100$；餘數非零時 $q\le19$，長度為 $62+2q\le100$。上面採用作者補充、已通過的修正版，$X=600$ 恰好長 100。官方解法則從 25 個 A、25 個 C 的 625 個逆序對出發，逐次相鄰交換減到 $X$。
:::

### [B. Halving Subtraction](https://atcoder.jp/contests/arc229/tasks/arc229_b)
`位元` `不變量` `AtC~1400`

::: info 題意
給定 $N\le30$ 個非負整數 $A_i\le10^9$。一次操作選正整數 $x$，依序從 $A_1,A_2,\ldots$ 減去 $x,\lfloor x/2\rfloor,\lfloor x/4\rfloor,\ldots$。

**求讓所有元素變成 0 的最少操作次數**；做不到輸出 $-1$。

例：$(10,4)$ 可分別選 $x=3,7$，減去 $(3,1)$ 與 $(7,3)$，兩次歸零。
:::

::: tip 作法
取 $D_i=A_i-2A_{i+1}$（只取 $i<N$）。一次操作對 $D_i$ 的減量，就是 $x$ 的第 $i-1$ 個位元，**只能是 0 或 1**。所以有負的 $D_i$ 就無解，否則至少要 $\max D_i$ 次；非全零時還要至少一次。

這個下界可以同時達成：令 $K=\max(1,\max D_i)$，對每個位元 $i-1$，把該位設在前 $D_i$ 個操作數上；再把 $A_N2^{N-1}$ 加進第一個操作數。各層差分與最後一項都吻合，因此總減量正好是原陣列。不需真的構造這些可能很大的操作數。

$$
\mathrm{ans}=\begin{cases}
0 & A_i\text{ 全為 }0,\\
-1 & \exists i<N:\ A_i<2A_{i+1},\\
\max(1,\max_{i<N}(A_i-2A_{i+1})) & \text{其他情況}.
\end{cases}
$$

掃一次即可，時間 $O(N)$。$N=1$ 且非零時答案是 1，不要把不存在的差分當成必須減 $A_1$ 次。
:::

### [C. Sum of Average 2](https://atcoder.jp/contests/arc229/tasks/arc229_c)
`數學` `貪心` `分類討論` `AtC~1300`

::: info 題意
給定 $2\le N\le2\times10^5$ 個正整數 $A_i\le10^9$，可以任意重排。

**求相鄰兩數平均值向下取整的總和** $\sum_{i=1}^{N-1}\lfloor(A_i+A_{i+1})/2\rfloor$ 最小值；所有測資的 $N$ 總和不超過 $2\times10^5$。

例：$(1,2,3,4)$ 排成 $(3,2,1,4)$，總和是 $2+1+2=5$。
:::

::: tip 作法
令 $t$ 為相鄰元素奇偶不同的次數。**把重複計算的內部元素收回總和，重排的自由度就只剩端點與奇偶切換：**

$$
\sum_{i=1}^{N-1}\left\lfloor\frac{A_i+A_{i+1}}2\right\rfloor
=\sum_i A_i-\frac{A_1+A_N+t}{2}.
$$

枚舉端點為偶偶、奇奇、奇偶。同一種奇偶端點直接選該類最大的兩個；不同類則各取最大。令偶數、奇數個數分別為 $e,o$，最大切換次數如下：

| 端點 | 可用條件 | 最大 $t$ |
| --- | --- | --- |
| 偶偶 | $e\ge2$ | $2\min(e-1,o)$ |
| 奇奇 | $o\ge2$ | $2\min(o-1,e)$ |
| 奇偶 | $e,o\ge1$ | $2\min(e-1,o-1)+1$ |

例如偶偶端點，中間每個奇數區塊都貢獻兩次切換，最多插入 $\min(e-1,o)$ 塊；多出的同類元素塞回既有區塊即可。取最大的 $A_1+A_N+t$ 後代回原式。

本地實作分奇偶排序，時間 $O(N\log N)$；只保留兩類各自最大的兩個值，也能做到 $O(N)$。總和用 64 位元。
:::

### [D. Nim_k ?](https://atcoder.jp/contests/arc229/tasks/arc229_d)
`博弈` `不變量` `AtC~1900`

::: info 題意
有 $K+1$ 堆石頭，每堆初始 $1\le A_i\le10^9$，Alice 先手。每回合必須**恰好做 $K$ 次操作**：選非空的一堆，取走至少一顆；同一回合可以重複選同一堆。

無法完成一整回合的人輸。給定 $K\le2\times10^5$ 與各堆數量，**輸出雙方最佳策略下的勝者**；所有測資的 $K$ 總和不超過 $2\times10^5$。

例：$K=2$、$(2,2,3)$ 是 Bob 勝；$K=2$、$(1,2,3)$ 時 Alice 可清空後兩堆，只剩一顆，Bob 無法做滿兩次。
:::

::: tip 作法
令 $m=\min A_i$。**必敗態不是 XOR，而是「底層對齊 $K$，上方剩不到 $K$ 顆」：**

$$m\equiv0\pmod K\quad\land\quad\sum_i(A_i-m)<K.$$

一回合至多改變 $K$ 堆，因此至少一堆不動。必敗態的各堆都落在同一區間 $[qK,(q+1)K)$；若走到另一個必敗態，不動的堆迫使底層仍為 $qK$，但底層上方不到 $K$ 顆，無法做滿 $K$ 次操作。

反過來，設 $m=qK+r$。若 $r>0$，保留一個最小堆，其餘 $K$ 堆各降到 $qK$；若 $r=0$ 且非必敗態，保留一個最小堆，其餘堆降到 $m$。後者至少需移除 $K$ 顆、涉及至多 $K$ 堆，可以拆成恰好 $K$ 次操作。兩者都能走到必敗態。

本地程式等價地計算 $R=\sum A_i-\lfloor m/K\rfloor K(K+1)$，$R<K$ 輸出 Bob，否則 Alice。時間 $O(K)$，加總與乘法使用 64 位元。
:::
