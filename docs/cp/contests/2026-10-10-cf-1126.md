### [A. Robot Odd Moves](https://codeforces.com/contest/2271/problem/A)
`數學` `構造` `~800`

::: info 題意
機器人從 $(0,0)$ 出發,一次操作 = 先上或下一格、再右一格;途中經過的點都算「拜訪」。**求**拜訪 $(a,b)$ 的最少操作數,不可能 $-1$。

例:$(2,3)$:兩步到 $(2,2)$,第三步先往上經過 $(2,3)$ → 3;$(0,2)$ 永遠到不了 → $-1$。
:::

::: tip 作法
做完 $z$ 步 $x=z$,且 $x,y$ 同奇偶、$|y|\le x$;同奇偶的 $(a,b)$ 恰 $a$ 步到(先一路上,再上下交替)。奇偶不同就先到 $(a,b-1)$,下一步的垂直移動經過 $(a,b)$ → $a+1$。$b>a+1$ 不可能。
:::

### [B. MEX Game](https://codeforces.com/contest/2271/problem/B)
`博弈` `分類討論` `~1200`

::: info 題意
$\operatorname{mex}_k(S)$ = 在 $S$ 中出現**少於 $k$ 次**的最小非負整數。$n$ 張牌(偶數),Alice、Bob 輪流拿,各拿一半;Alice 贏 $\iff$ 兩人的 $\operatorname{mex}_k$ 不同。**判定**雙方最佳下誰贏。

例:$k=2$、牌 $0,0,1,1,2,2$:每個值都剛好 $2=2k-2$ 張,Bob 鏡像拿同值 → 兩人都是 $\operatorname{mex}_2=0$ → NO。牌 $0,0,0,1,1,2$:$\text{cnt}[0]=3=2k-1$ → YES。
:::

::: tip 作法
看第一個 $\text{cnt}[x]<2k$ 的 $x$。**$\text{cnt}[x]=2k-1$ 時兩人不可能同 mex**:若共同 mex $y<x$,兩人各少於 $k$ 張 $y$,但 $\text{cnt}[y]\ge2k$;$y=x$ 時同理 $2k-1$ 張分不出兩個 $<k$;$y>x$ 需各 $\ge k$ 張 $x$,但只有 $2k-1$。否則($\le2k-2$)Bob 把同值的牌配對、Alice 拿哪張他就拿配對的那張,兩人每個值各拿 $\lfloor\text{cnt}/2\rfloor$ 或 $\lceil\cdot\rceil$,mex 都是 $x$。$O(n)$。
:::

### [C. XOR Problem](https://codeforces.com/contest/2271/problem/C)
`XOR` `構造` `~1500`

::: info 題意
陣列元素 $\in[0,n]$,美麗值 = 長度 $-$(XOR 為 $0$ 的子陣列數)。**構造**美麗值最大者中**最長**的。

例:$n=2$:美麗值最大 $3$,最長 $7$,如 $[2,2,1,0,2,0,1]$(XOR 為 $0$ 的子陣列 4 個)。
:::

::: tip 作法
看 prefix XOR $p_0..p_m$:子陣列 XOR 為 $0$ $\iff p_{l-1}=p_r$。元素 $\le n<2x$($x$ 是 $\le n$ 的最大 2 冪)→ 所有 $p_i\in[0,2x)$。每加一個新 $p_i$:**第一次出現**美麗值 $+1$、第二次 $+0$、第三次起變負 → 美麗值 $\le2x-1$,要最長就讓每個值**恰出現兩次**,長度 $4x-1$。構造 prefix:$0,1,\dots,x{-}1,x{-}1,\dots,0,\ x,\dots,2x{-}1,2x{-}1,\dots,x$,相鄰 XOR 都 $\le x\le n$(同一半內最高位抵消;唯一跨越 $0\to x$ 恰為 $x$)。

```cpp
int x = 1;
while (2 * x <= n) x *= 2;
vector<int> p;  // 先建 prefix XOR,再還原 a[i] = p[i] ^ p[i-1]
for (int i = 0; i < x; i++) p.push_back(i);
for (int i = x - 1; i >= 0; i--) p.push_back(i);
for (int i = x; i < 2 * x; i++) p.push_back(i);
for (int i = 2 * x - 1; i >= x; i--) p.push_back(i);
for (size_t i = 1; i < p.size(); i++) a.push_back(p[i] ^ p[i - 1]);  // 長度 4x - 1
```

### [D. Target Infection](https://codeforces.com/contest/2271/problem/D)
`二分` `貪心` `~1800`

::: info 題意
數線上 $n$ 個互不相鄰的感染區間 $[l_i,r_i]$($\le10^{15}$)。$m$ 個人站在 $s..s+m-1$,$f(s)$ = 被感染的人數。**求**任一個 $f(s)=k$ 的 $s$,或 $-1$。

例:區間 $[1,3],[5,6],[8,8]$、$m=5$、$k=4$:$s=2$ 蓋 $2..6$,感染 $2,3,5,6$ → 4 ✓。
:::

::: tip 作法
$s\to s+1$ 只少一個位置、多一個位置,所以 **$|f(s+1)-f(s)|\le1$**。最大值一定在某個 $l_i$(往左移到區間開頭不會變差),掃一遍得 $(\text{pos},mx)$。$k>mx$ 無解、$k=mx$ 直接回。$k<mx$ 時,$f(\text{pos})>k$ 而 $f(10^{15}+1)=0\le k$,**步差 $\le1$ 保證中間有 $f=k$**:維持「左端 $>k$、右端 $\le k$」二分到相鄰,右端就是答案——$f$ 不單調也沒關係,只要離散的中間值定理成立。$O(n\log n+\log V\cdot\log n)$。

```cpp
long long lo = pos, hi = 1000000000000001LL;  // f(lo) > k,f(hi) = 0 <= k
while (hi - lo > 1) {
    long long mid = (lo + hi) / 2;
    if (f(mid) > k)
        lo = mid;
    else
        hi = mid;  // 保持兩端的不變量
}
return hi;  // 相鄰且 f 步差 <= 1 → f(hi) == k
```

### [E. Array Emptying](https://codeforces.com/contest/2271/problem/E)
`貪心` `二分` `資料結構` `~2100`

::: info 題意
陣列 $a$($a_i\le n$)與門檻 $k$。一次操作選 $x$:$x\le k$ 就刪掉,否則刪掉並放入兩個 $\lceil x/2\rceil$;每次操作後 $k$ 加 $1$。**求**清空的最少操作數。

例:$a=[4,4,1,4]$、$k=0$:拆一個 $4\to2,2$,然後刪 $1,2,2,4,4$($k$ 一路漲到足夠)→ 6 次;不拆的話 $4$ 在 $k<4$ 時刪不掉,$k$ 漲到 4 需要先做 4 次操作,拆開反而省。
:::

::: tip 作法
先解放寬版(任何元素都可拆):拆 $c$ 次就要刪 $n+c$ 次,總 $n+2c$,且**拆可以全部挪到最前面**(交換論證)。二分 $c$,判定時**倒著處理刪除**:最後一次刪除時 $k=S=k_0+n+2c-1$,看目前最大的 $H$——$H>S$ 必須拆(更早的 $k$ 更小,更刪不掉),否則刪 $H$ 最優(交換論證:換成刪更小的 $y$、拆 $H$,不會比刪 $H$、拆 $y$ 好)。用計數陣列模擬,$O(n)$ 一次判定。最後觀察:貪心只在 $H>S\ge$ 當時的 $k$ 時才拆,所以每次拆在原題也合法,放寬版答案 $=$ 原題答案 $=n+2c$。

```cpp
auto ok = [&](int c) {  // c 次拆夠不夠
    vector<int> cnt = freq;
    int alive = n, used = 0, H = mx;
    long long S = k + n + 2LL * c - 1;
    while (alive > 0) {
        while (cnt[H] == 0) H--;
        if (H <= S) {
            cnt[H]--;
            alive--;
            S--;
        }  // 倒序:刪掉目前最大,k 退一格
        else {
            if (used == c) return false;
            cnt[H]--;
            cnt[(H + 1) / 2] += 2;
            alive++;
            used++;
        }  // 必須拆
    }
    return true;
};
```

### [F. Beautiful Pillers](https://codeforces.com/contest/2271/problem/F)
`貪心` `分類討論` `資料結構` `~2300`

::: info 題意
$(l,r)$ 是 good pair $\iff b_l=b_r$ 且中間沒有 $\ge b_l$ 的元素;陣列 beautiful $\iff$ 每個位置都被某個 good pair 覆蓋。操作:把某個 $a_i$ 改成任意值。**求**最少操作數並輸出操作。

例:$[1,2,3]$ 沒有 good pair;把 $a_1$ 改成 $3$ 得 $[3,2,3]$,$(1,3)$ 覆蓋全部 → 1。$[5,3,2,5,1,7,9,9]$:$(1,4)$、$(7,8)$ 已蓋住兩端,把 $a_5$ 改成 $7$ 讓 $(5,6)$ 補上中間 → 1。
:::

::: tip 作法
把 $a_1,a_n$ 都改成 $10^9$ 一定行 → 答案 $\le2$。先 $O(n)$ 判是否已 beautiful(單調堆疊找每個 $i$ 左邊第一個 $\ge a_i$ 的位置,相等就差分覆蓋)。若答案為 $1$,**只需試三個操作**:$a_1=mx$、$a_n=mx$、$a_{pos}=1$($pos$ 是某個最大值位置)。前兩個分別把 $mx$ 左側、右側全部蓋住;都不行表示兩側都有空洞,一次操作要同時補兩側只能**降低一個最大值**讓 good pair 跨過它,而改成 $X$ 行的話改成 $1$ 也行(跨過它的 pair 更容易成立,兩段 $X\ldots X\ldots X$ 合成一段更大的 pair)。$O(n)$。

```cpp
if (beautiful(a)) return 0;
int pos = argmax(a), mx = a[pos];
for (auto [i, x] : {pair{0, mx}, pair{n - 1, mx}, pair{pos, 1}})  // 三個候選,改回來再試下一個
    if (tryAssign(i, x)) return 1;
return 2;  // a[0] = a[n-1] = mx
```
:::
